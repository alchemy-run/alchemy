# Cloudflare + SpacetimeDB Todo

One Alchemy stack wires:

| Resource | Role |
| --- | --- |
| `SpacetimeDB.Database` | Publishes `./spacetimedb` to Maincloud (`deploy`) or local (`alchemy dev`) |
| `SpacetimeDB.Generate` | Regenerates `src/module_bindings` for the SPA |
| `Cloudflare.R2.Bucket` | Optional attachment blobs (external file-storage pattern) |
| `Cloudflare.Worker` | `PUT /upload` → R2; `GET /file/:key` |
| `Cloudflare.Website.Vite` | React SPA; `VITE_SPACETIMEDB_*` inlined from stack outputs |

The browser connects **directly** to SpacetimeDB (Zen: the client is a live
replica). The Worker only handles blob upload.

## Prerequisites

```bash
# SpacetimeDB CLI — https://spacetimedb.com/install
curl -sSf https://install.spacetimedb.com | sh -s -- -y
export PATH="$HOME/.local/bin:$PATH"
spacetime --version

# Local server (alchemy dev also starts one via spacetime dev --server-only)
spacetime start --listen-addr 127.0.0.1:3000

# Maincloud token for deploy
export SPACETIMEDB_TOKEN=$(spacetime login show --token)
# Cloudflare credentials via `alchemy login` / env as usual
```

## Commands

```bash
bun i
bun run generate          # spacetime generate → src/module_bindings
# From monorepo root, run alchemy with bun so it picks up .ts source:
npm_config_user_agent=bun/1 bun --tsconfig-override=../../packages/alchemy/tsconfig.json \
  ../../packages/alchemy/bin/alchemy.ts dev alchemy.run.ts --profile default

# or after alchemy is built:
bun run dev
bun run deploy            # Maincloud + Cloudflare
bun run destroy
```

## Verified local endpoints

After a successful `alchemy dev`:

| Service | URL |
| --- | --- |
| Vite SPA | http://localhost:1338 |
| API (R2 upload) | http://localhost:1337/health |
| SpacetimeDB WS | ws://127.0.0.1:3000 |
| Database name | `alchemy-todo` |
| **Maincloud dashboard** | https://spacetimedb.com/alchemy-todo (only when deployed to Maincloud) |

Local standalone has no browser dashboard. The SPA only shows the dashboard
link when `dashboardUrl` is set (Maincloud). Query locally with:

```bash
spacetime sql alchemy-todo --server local "SELECT * FROM todo"
spacetime logs alchemy-todo --server local
```

## Layout

```
alchemy.run.ts          # the whole stack
spacetimedb/src/        # module (tables + reducers)
src/                    # Vite React SPA
worker/api.ts           # R2 upload helper
src/module_bindings/    # generated by `bun run generate`
```
