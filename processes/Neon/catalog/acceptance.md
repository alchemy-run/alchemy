# Neon implementation acceptance contract

This catalog implements the approved Neon backend plan; it does not redefine its scope. Assessment date: 2026-09-17. All status entries are initial assessment snapshots, not claims about work another owner may subsequently add.

## Scope and ownership

The mandatory inventory is 12 resource contracts, the AIGateway construct, 10 runtime binding contracts, two event sources, and all 13 Website constructors. Project and Branch are **partial**; the remaining 36 items are **missing** at assessment. Shared infrastructure already exists but does not count as Neon implementation. Standalone Endpoint is conditional, only if Branch endpoint ownership cannot express the required behavior; it is not a new mandatory surface. Billing, organizations, historical database administration, user/session IaC, queues, S3 website hosting, enforced lifecycle/versioning, and invented AI gateway CRUD remain out of scope.

Catalog ownership is only `processes/Neon/catalog/`. One separate SDK owner controls the entire `submodules/distilled/packages/neon/src/services/neon.ts`, mirror, patches and regeneration. No catalog/preflight action mutates Neon. Project/Branch fixes, storage/credentials, Function runtime/events, Auth/DataApi/AI, and Website implementation remain their assigned owners' work. The coordinator owns cross-cutting edits, installation, typechecks/builds and final verification. Prisma #1683 is merged at head `1503d1777d22a2a0e4dccbc3d59ae11c507412fa`; see preflight for exact merge evidence. Do not merge unrelated main to obtain its artifacts.

## Shared scope contract

Branch-scoped resources take exactly one of `branch: Branch | { projectId, branchId }` or `project: Project | { projectId }`. The latter selects the observed project default branch, not a hardcoded `main`. References such as Function, Bucket, and Auth infer their scope; explicit contradictory scope is rejected before mutation. Props use plain nested types; Resource machinery supplies deep Input/Output support. Changing resolved project/branch identity replaces the scoped resource. No child declaration transfers ownership of its referenced parent.

Generated physical identifiers are deterministic per stack/stage/logical ID/instance. Names are not ownership proof. Re-observe live state and return `Unowned` for foreign or inherited objects unless explicit adoption authorizes child-local ownership. Never silently select the first ambiguous same-name candidate. Where tags are supported, merge protected internal tags and use `diffTags` against observed tags. Where provenance cannot be established, require adoption rather than fabricating tags or lineage metadata.

## Execution budget and evidence handling

Use `timeout 240 pnpm test test/Neon/<focused-suite>.test.ts --profile testing --retry 0`; ordinary per-test timeouts are 90–120 seconds. At most 8–10 typed retry/poll attempts, total backoff under 60 seconds. Partition suites rather than extending an unbounded wait. A timeout is a failure to diagnose. After roughly three platform-blocked iterations record the exact typed rejection and gate only the affected behavior; lifecycle probes must remain active. Do not capture arbitrary application logs, credential files, user records or response bodies in the catalog. Route sanitized SDK contract gaps to the sole SDK owner.

Baseline and cleanup are project/branch/stage isolated, not account-wide. Never nuke, upgrade an account, purchase AI credits, delete arbitrary search matches or assume the ambient key belongs to a disposable account. See `preflight.md` for the safe census procedure and current blockers.
