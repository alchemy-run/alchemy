# Pipelines local implementation

Actual deployed fixture `test/Cloudflare/Pipelines/Pipelines.local.test.ts`: 2 passed in4.7seconds, `.audit/cloudflare/pipelines-local.log`. A real local Worker sends via its native Pipelines binding, then reads actual local R2 objects to verify structured schema rejection, SQL projections and scalar filters, two sinks, gzip content, and pipeline replacement refreshing an existing Worker. Unsupported CTE SQL deployment fails. No mocked provider tests.

Three dual resource providers (Stream, Sink, Pipeline) use the local sidecar registry. Their immutable changes replace; changing Worker ingestion enabled updates Stream. Generated names use SQL identifier syntax. Registry recovery on no-op evaluation reconstructs definitions; resource changes restart dependent Workers, whose suspended binding hooks rebuild SQL routes from current state. Live implementations retain the complete upstream resource contracts and parent-added Sink schema/JSON format options.

Supported local runtime: JSON object ingestion through Worker `send()`, scalar structured fields int32/int64/float32/float64/string/bool/json with required validation and sqlName, unstructured records, INSERT INTO/SELECT projection or *, aliases, one WHERE comparison or IS [NOT] NULL, multiple statements, local R2 destinations, NDJSON and gzip, UUIDv7 filenames, path/prefix/suffix, UTC strftime %Y%m%d%H%M%S%%. Each send flushes one file per matching sink; no downstream event is accepted with no route.

Explicit unsupported configurations fail: HTTP ingestion/auth/CORS, metadata-derived fields, binary/timestamp schema/conversion, SQL CTEs/joins/aggregates/computed expressions, remote R2 buckets in local sinks, sink schema conversion, timed/size rolling, Parquet and Iceberg/Data Catalog, external Vite child reconstruction without sidecar state. These are gaps in local emulation, not claimed parity. Cloudflare itself is still required for distributed delivery, durability/SLA, and these formats/features.

Known limits requiring further work: in-memory control-plane registries are reconstructed by reevaluation; they are not standalone durable APIs. Fanout writes validate all rows before writing but cannot atomically commit across multiple R2 sinks. Local batches are flushed synchronously and do not emulate service batching/backpressure. Explicit unsupported validation is source reviewed; only the CTE failure currently has its own deployed negative fixture.
