Hetzner Cloud rents virtual machines by the hour, at a fraction of the price of the large clouds. Around its Servers it offers just what servers need: network disks, private networks, firewalls, load balancers, IP addresses and DNS. There are no managed functions or queues: you run your own programs on your own machines.

## A taste

A Server is a declaration:

```typescript title="src/server.ts"
import * as Hetzner from "@alchemy.run/hetzner";

export const Box = Hetzner.Server("Box", { serverType: "cx22", image: "ubuntu-24.04", location: "nbg1" });
```

A Service is your program on it:

```typescript title="src/api.ts"
import * as Hetzner from "@alchemy.run/hetzner";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/http/HttpServerResponse";
import { Box } from "./server.ts";

export default class Api extends Hetzner.Service<Api>()(
  "Api",
  { server: Box, main: import.meta.url, port: 3000 },
  Effect.gen(function* () {
    return {
      fetch: Effect.succeed(HttpServerResponse.text("hello from Hetzner")),
    };
  }),
) {}
```

And the Stack deploys both to your project:

```typescript title="alchemy.run.ts"
import * as Alchemy from "alchemy";
import * as Hetzner from "@alchemy.run/hetzner";
import * as Effect from "effect/Effect";
import Api from "./src/api.ts";

export default Alchemy.Stack(
  "MyApp",
  { providers: Hetzner.providers(), state: Alchemy.localState() },
  Effect.gen(function* () {
    const api = yield* Api;
    return { url: api.url };
  }),
);
```

**New to Hetzner?** [What is Hetzner?](/hetzner/what-is-hetzner) walks through projects, locations, Servers, Volumes, networks, firewalls, load balancers and DNS, once each, and shows how Alchemy models every one.

**Want to build one?** The [tutorial](/hetzner/tutorial/part-1) goes from an empty directory to a Server running an HTTP Service with a Volume and a firewall, one step at a time. Start with [Setup](/hetzner/setup) to connect your project.

**Want the whole picture?** The chapters follow the shape of Hetzner itself. Start with the machine and what runs on it: [Servers](/hetzner/compute/servers) and [Services](/hetzner/compute/services). Then what it keeps: [Volumes](/hetzner/data/volumes) and [Drizzle + Postgres](/hetzner/data/drizzle-postgres). Then how it's reached: [Networks, firewalls & load balancers](/hetzner/networking) and [DNS](/hetzner/networking/dns).

**Building a website?** [Websites](/hetzner/frontend/websites) covers every supported framework as a Service on a Server. Several sites can share one.

Every resource is in the generated [API reference](/providers).
