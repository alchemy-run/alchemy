Kubernetes runs containers on a group of machines and keeps them running. You describe what should exist, three copies of this server, a job every night, an address in front of them, and the cluster works continuously to make it so, restarting what crashes and moving what was on a machine that died. It runs anywhere: on your laptop, on your own servers, or as a managed service like EKS, GKE or AKS.

## A taste

A cluster to deploy to. `LocalCluster` starts one on your machine, so you can try everything without a hosted cluster:

```typescript title="alchemy.run.ts"
const cluster = yield* Kubernetes.LocalCluster("Cluster", { name: "alchemy" });
```

A replicated server from a public image, with a Service in front of it:

```typescript title="alchemy.run.ts"
const web = yield* Kubernetes.Deployment("Web", {
  cluster,
  image: "ghcr.io/stefanprodan/podinfo:6.15.0",
  port: 9898,
  replicas: 2,
});
```

And the Stack that holds them:

```typescript title="alchemy.run.ts"
import * as Alchemy from "alchemy";
import * as Kubernetes from "@alchemy.run/kubernetes";
import * as Effect from "effect/Effect";

export default Alchemy.Stack(
  "MyApp",
  { providers: Kubernetes.providers(), state: Alchemy.localState() },
  Effect.gen(function* () {
    const cluster = yield* Kubernetes.LocalCluster("Cluster", { name: "alchemy" });
    const web = yield* Kubernetes.Deployment("Web", {
      cluster,
      image: "ghcr.io/stefanprodan/podinfo:6.15.0",
      port: 9898,
      replicas: 2,
    });
    return { service: web.serviceName };
  }),
);
```

When you're ready, point the same resources at a real cluster.
