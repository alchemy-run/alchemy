title: ACME
description: Issue TLS certificates with an ACME certificate authority and DNS-01 validation.

ACME (Automatic Certificate Management Environment) issues TLS certificates
through certificate authorities such as Let's Encrypt and ZeroSSL. Alchemy
manages the account, private keys, and certificate lifecycle independently of
the service that will use the certificate.

## Configure providers

Combine `ACME.providers()` with your DNS provider. Cloudflare currently supplies
the built-in DNS-01 solver.

```typescript
import * as ACME from "alchemy/ACME";
import * as Cloudflare from "alchemy/Cloudflare";
import * as Layer from "effect/Layer";

const providers = Layer.mergeAll(ACME.providers(), Cloudflare.providers());
```

Pass `providers` to your Stack configuration. Configure Cloudflare credentials
as described in [Cloudflare setup](/cloudflare/setup).

## Create an account

Inside the Stack's Effect, create an account with the selected certificate authority.

```typescript
const account = yield* ACME.Account("LetsEncrypt", {
  ca: ACME.LetsEncryptStaging,
  contact: ["mailto:ops@example.com"],
  termsOfServiceAgreed: true,
});
```

Staging certificates are not trusted by browsers. Switch to `ACME.LetsEncrypt`
for production. ZeroSSL and Google Trust Services require external account
binding credentials; see [Account](/providers/acme/account).

## Issue a certificate

Resolve your Cloudflare `Zone` resource and pass it to the DNS solver.

```typescript
const zone = yield* Zone;
const certificate = yield* ACME.Certificate("Wildcard", {
  account,
  identifiers: ["example.com", "*.example.com"],
  solver: Cloudflare.DNS.acmeSolver(zone),
});
```

The solver publishes the challenge TXT records, waits for propagation, and removes
them after validation. Cloudflare waits 60 seconds before validation to allow
cached challenge values to expire. The certificate exposes `certificate` (leaf
PEM), `chain` (full PEM chain), and a redacted `privateKey`.

## Deploy and renew

Pass the chain and key to the service terminating TLS. For example, the
[Fly certificate guide](/fly/networking#issue-a-certificate-independently)
uploads them with `Fly.Certificate`.

A deployment renews certificates that expire within 30 days by default. There
is no background renewal process: schedule deployments or implement runtime
renewal. Set `revokeOnDelete: true` if destroying a certificate resource should
also revoke it; otherwise destruction removes its state without revoking it.

Private account and certificate keys are persisted in stack state. Redaction
protects ordinary logs, not the storage backend. Restrict access to the state
store and protect its backups.

## Issue from an application

[`IssueCertificate`](/providers/acme/issuecertificate) binds an account into a
Worker or Service. Provide
[`IssueCertificateHttp`](/providers/acme/issuecertificatehttp) on the host Effect
and pass a runtime DNS solver when calling `issue`.

The application owns renewal, revocation, and cleanup of runtime-issued
certificates. Verify that the selected certificate authority is reachable from
your hosting environment. See the binding reference for runtime examples and
rate-limit handling.
