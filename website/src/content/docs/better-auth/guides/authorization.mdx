## Check the caller before returning a profile

```typescript
// worker.ts
import { BetterAuth } from "@alchemy.run/better-auth";
import { CloudflareD1 } from "@alchemy.run/better-auth/CloudflareD1";
import * as Cloudflare from "alchemy/Cloudflare";
import * as Context from "effect/Context";
import * as Data from "effect/Data";
import * as Effect from "effect/Effect";
import * as Result from "effect/Result";
import { HttpServerRequest } from "effect/unstable/http/HttpServerRequest";
import * as HttpServerResponse from "effect/unstable/http/HttpServerResponse";

class CurrentUser extends Context.Service<
  CurrentUser,
  { readonly id: string; readonly name: string; readonly email: string }
>()("app/CurrentUser") {}

class Forbidden extends Data.TaggedError("Forbidden") {}
class AuthenticationUnavailable extends Data.TaggedError("AuthenticationUnavailable") {}

const requireOwner = Effect.fn(function* (ownerId: string) {
  const user = yield* CurrentUser;
  if (user.id !== ownerId) return yield* Effect.fail(new Forbidden());
  return user;
});

const AuthDb = Cloudflare.D1.Database("AuthDb");

export default class AuthApi extends Cloudflare.Worker<AuthApi>()(
  "AuthApi",
  { main: import.meta.url, compatibility: { flags: ["nodejs_compat"] } },
  Effect.gen(function* () {
    const auth = yield* BetterAuth({
      basePath: "/api/auth",
      emailAndPassword: { enabled: true },
      session: { cookieCache: { enabled: false } },
    });
    return {
      fetch: Effect.gen(function* () {
        const request = yield* HttpServerRequest;
        const path = request.url.split("?")[0];
        if (path === "/api/auth" || path.startsWith("/api/auth/")) {
          return yield* auth.fetch;
        }
        if (!path.startsWith("/api/users/")) {
          return HttpServerResponse.text("Not found", { status: 404 });
        }
        if (request.method !== "GET") {
          return HttpServerResponse.text("Method not allowed", { status: 405 });
        }
        const session = yield* auth.getSession().pipe(
          Effect.mapError(() => new AuthenticationUnavailable()),
          Effect.catchDefect(() => Effect.fail(new AuthenticationUnavailable())),
          Effect.result,
        );
        if (Result.isFailure(session)) {
          return yield* HttpServerResponse.json(
            { _tag: "AuthenticationUnavailable" }, { status: 503 },
          );
        }
        if (session.success === null) {
          return yield* HttpServerResponse.json(
            { _tag: "Unauthorized" }, { status: 401 },
          );
        }
        const user = session.success.user;
        return yield* requireOwner(path.slice("/api/users/".length)).pipe(
          Effect.provideService(CurrentUser, {
            id: user.id,
            name: user.name,
            email: user.email,
          }),
          Effect.flatMap((profile) => HttpServerResponse.json(profile)),
          Effect.catchTag("Forbidden", () =>
            HttpServerResponse.json({ _tag: "Forbidden" }, { status: 403 }),
          ),
        );
      }),
    };
  }).pipe(Effect.provide(CloudflareD1(AuthDb))),
) {}
```

`GET /api/users/:userId` returns only the caller's own profile. The path chooses the requested profile, but the identity being compared comes from a verified server session, never a client-supplied owner claim.

`CurrentUser` is supplied within the request after session resolution succeeds. The reusable `requireOwner` helper requires that service and cannot silently fall back to an anonymous user.

An absent session returns `401`, an authenticated wrong-owner request returns `403`, and a session-service failure returns `503`. The failure boundary surrounds only the lookup, leaving downstream application defects distinct.

Cookie caching is disabled here, so authorization consults server-side session state. Better Auth's routes remain public and forward their own response cookies through `auth.fetch`.

## Run this example independently

```typescript
// alchemy.run.ts
import * as Alchemy from "alchemy";
import * as Cloudflare from "alchemy/Cloudflare";
import * as Effect from "effect/Effect";
import AuthApi from "./worker.ts";

export default Alchemy.Stack(
  "AuthAuthorization",
  { providers: Cloudflare.providers(), state: Alchemy.localState() },
  Effect.gen(function* () {
    const api = yield* AuthApi;
    return { url: api.url };
  }),
);
```

Use Bun, matching `alchemy` and `@alchemy.run/better-auth` releases, Better Auth 1.7.5, Effect 4, and `kysely`, with Cloudflare credentials configured. The stack owns its D1 database, migrations, and stable signing secret; retain the local state directory.

```sh
bunx alchemy dev
```

In another shell, enter the printed origin without a trailing slash after `read`. This anonymous call must return `401`, not a permission denial or a successful profile:

```sh
read -r BASE_URL
curl -i "$BASE_URL/api/users/not-the-current-user"
```

With a valid session cookie, requesting its user's ID returns the profile and requesting another ID returns `403`. Sign up and sign in through `/api/auth/sign-up/email` and `/api/auth/sign-in/email`; the API accepts standard Better Auth JSON requests and sets browser cookies.

## Authorize application records using stored ownership

For a project, document, or order, first load its owner ID from your application database, then pass that stored ID to `requireOwner` before reading or changing protected data. Unlike this self-profile endpoint, accepting an `ownerId` from the request would not establish ownership of a separate record.

Use stable user IDs as relationship keys; names and email addresses are not roles. Query authoritative membership or permission data when an operation needs current access rights, and make the check and mutation transactional when concurrent ownership changes matter.

For a native Effect HTTP API, the same request-scoped service can be provided by authentication middleware. The [middleware guide](/better-auth/guides/http-api-middleware) shows that alternative integration in full; it is not needed to run this Worker.
