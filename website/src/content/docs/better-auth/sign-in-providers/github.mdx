```sh
mkdir github-auth
cd github-auth
bun init -y
bun add alchemy @alchemy.run/better-auth better-auth@1.7.5 "effect@4.0.0-rc.115" kysely
mkdir -p src public
```

Use [Bun](https://bun.sh), matching Alchemy integration releases, and a [configured Cloudflare profile](/cloudflare/setup). This page defines the entire application; no tutorial files are required.

## Define the Auth service and Worker

```typescript
// src/worker.ts
import { BetterAuth } from "@alchemy.run/better-auth";
import { CloudflareD1 } from "@alchemy.run/better-auth/CloudflareD1";
import * as Cloudflare from "alchemy/Cloudflare";
import * as Config from "effect/Config";
import * as Context from "effect/Context";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import * as Option from "effect/Option";
import * as Redacted from "effect/Redacted";
import { HttpServerRequest } from "effect/unstable/http/HttpServerRequest";
import * as HttpServerResponse from "effect/unstable/http/HttpServerResponse";

const AuthDb = Cloudflare.D1.Database("AuthDb");
const makeAuth = Effect.gen(function* () {
  const baseURL = yield* Config.String("AUTH_BASE_URL").pipe(Config.option);
  const enabled = yield* Config.Boolean("GITHUB_ENABLED").pipe(
    Config.withDefault(false),
  );
  const github = enabled
    ? {
        clientId: yield* Config.String("GITHUB_CLIENT_ID"),
        clientSecret: Redacted.value(
          yield* Config.Redacted("GITHUB_CLIENT_SECRET"),
        ),
      }
    : undefined;

  return yield* BetterAuth({
    basePath: "/api/auth",
    baseURL: Option.getOrUndefined(baseURL),
    socialProviders: github ? { github } : {},
    account: { accountLinking: { disableImplicitLinking: true } },
  });
});

export class Auth extends Context.Service<
  Auth,
  Effect.Success<typeof makeAuth>
>()("app/Auth") {
  static readonly layer = Layer.effect(Auth, makeAuth);
}

export default class AuthWorker extends Cloudflare.Worker<AuthWorker>()(
  "AuthWorker",
  {
    main: import.meta.url,
    compatibility: { flags: ["nodejs_compat"] },
    assets: { directory: "./public", runWorkerFirst: ["/api/*"] },
  },
  Effect.gen(function* () {
    const auth = yield* Auth;
    return {
      fetch: Effect.gen(function* () {
        const request = yield* HttpServerRequest;
        const path = request.url.split("?")[0];
        if (path === "/api/auth" || path.startsWith("/api/auth/")) {
          return yield* auth.fetch;
        }
        if (path === "/api/me") {
          return yield* auth.getSession().pipe(
            Effect.match({
              onFailure: () => HttpServerResponse.text("Session lookup failed", {
                status: 503, headers: { "Cache-Control": "no-store" },
              }),
              onSuccess: (session) => HttpServerResponse.text(
                session ? `Signed in as ${session.user.name}` : "Sign in required",
                { status: session ? 200 : 401, headers: { "Cache-Control": "no-store" } },
              ),
            }),
          );
        }
        return HttpServerResponse.text("Not found", { status: 404 });
      }),
    };
  }).pipe(Effect.provide(Auth.layer.pipe(Layer.provide(CloudflareD1(AuthDb))))),
) {}
```

The host supplies D1, and Alchemy provisions the stable signing secret and supported schema migrations automatically. Config is read during service construction, with the client secret unwrapped only for Better Auth.

GitHub starts disabled so you can discover the local URL before registering a callback. Without `AUTH_BASE_URL`, Better Auth derives its origin from the request.

## Define the stack

```typescript
// alchemy.run.ts
import * as Alchemy from "alchemy";
import * as Cloudflare from "alchemy/Cloudflare";
import * as Effect from "effect/Effect";
import AuthWorker from "./src/worker.ts";

export default Alchemy.Stack(
  "GitHubAuth",
  { providers: Cloudflare.providers(), state: Alchemy.localState() },
  Effect.gen(function* () {
    const worker = yield* AuthWorker;
    return { url: worker.url };
  }),
);
```

Preserve the local state directory so resource identities and the signing secret survive subsequent deployments.

## Define the browser actions

```typescript
// src/client.ts
import { createAuthClient } from "better-auth/client";

const authClient = createAuthClient();
const status = document.createElement("p");
status.setAttribute("role", "status");
document.body.append(status);

async function readAccount(): Promise<string> {
  const { data, error } = await authClient.getSession();
  if (error) return "Could not check your session. Try again.";
  if (!data) return "Sign in to continue.";
  const accounts = await authClient.listAccounts();
  if (accounts.error) return "Signed in, but linked accounts could not be checked.";
  return `Signed in as ${data.user.name}. Linked providers: ${
    accounts.data?.map((account) => account.providerId).join(", ") ?? "none"
  }.`;
}

async function startOAuth(link: boolean): Promise<string> {
  if (link) {
    const session = await authClient.getSession();
    if (session.error || !session.data) return "Sign in with your existing account first.";
  }
  const options = { provider: "github" as const, callbackURL: "/", disableRedirect: true };
  const { data, error } = link
    ? await authClient.linkSocial(options)
    : await authClient.signIn.social(options);
  if (error) return "Could not start GitHub authorization. Check your account and retry.";
  if (!data?.url) return "No authorization URL was returned.";
  window.location.assign(data.url);
  return "Redirecting to GitHub…";
}

async function run(action: () => Promise<string>) {
  try {
    status.textContent = await action();
  } catch {
    status.textContent = "Could not reach the server. Try again.";
  }
}

function button(label: string, action: () => Promise<string>) {
  const element = document.createElement("button");
  element.textContent = label;
  element.addEventListener("click", () => void run(action));
  document.body.append(element);
}

button("Sign in with GitHub", () => startOAuth(false));
button("Link GitHub to this account", () => startOAuth(true));
button("Check session and linked accounts", readAccount);
button("Sign out", async () => {
  const { error } = await authClient.signOut();
  return error ? "Could not sign out. Try again." : "Signed out.";
});
void run(readAccount);
```

This same-origin client calls `/api/auth`; it imports no server configuration. Successful OAuth returns to `/`, where the module checks the session and lists linked providers instead of assuming that a redirect proves authentication.

## Discover the local origin

```sh
bun build ./src/client.ts --target browser --outdir ./public
bunx alchemy dev --stage github-guide
```

Alchemy allocates an available port and prints the URL; open that URL, but do not start sign-in until GitHub is configured. Rebuild the browser module after editing it.

## Register the OAuth App

```text
/api/auth/callback/github
```

Append this path to the printed origin for GitHub's **Authorization callback URL**. In GitHub **Settings → Developer settings → OAuth Apps → New OAuth App**, enter a name and use the same origin for **Homepage URL**.

Leave device flow disabled for this browser authorization-code flow. Follow GitHub's [OAuth App registration instructions](https://docs.github.com/en/apps/oauth-apps/building-oauth-apps/creating-an-oauth-app), then copy **Client ID** and generate a **Client secret**.

## Supply server configuration

```dotenv
# .env.local
GITHUB_ENABLED=true
GITHUB_CLIENT_ID=replace-with-your-client-id
GITHUB_CLIENT_SECRET=replace-with-your-client-secret
```

Keep this file gitignored and replace both values with the matching OAuth App credentials. Stop the first dev process and restart with these server-side values:

```sh
bunx alchemy dev --stage github-guide --env-file .env.local
```

If the printed origin changes, update the OAuth App's homepage and callback before signing in. An optional `AUTH_BASE_URL` must match that exact origin, without a trailing slash or `/api/auth`.

For production, use separate OAuth credentials and set `AUTH_BASE_URL` to the actual HTTPS Worker origin. For example, a Worker served at `https://auth.example.com` needs `https://auth.example.com/api/auth/callback/github`; setting `baseURL` does not attach a domain to the Worker.

Never expose the secret through `VITE_*`, browser bundles, source control, or logs. Better Auth requests `read:user` and `user:email` by default, including private email verification status; ordinary sign-in needs neither repository scopes nor a personal access token.

## Keep account linking explicit

The Link button calls `linkSocial` only after finding a session, and the callback returns to the same account view. When adding other methods to this Auth service, have existing users authenticate with their original method before linking GitHub.

Keep `disableImplicitLinking: true`, verified-email checks, and the same-email restriction. Do not add `trustedProviders`, enable `allowDifferentEmails`, or merge database rows to suppress an account collision.

Resolve missing or unverified email on the GitHub account instead of bypassing verification. Keep a working sign-in method before unlinking an account.

## Diagnose failures

Better Auth handles callback failures on its built-in `/api/auth/error` page; no custom query flag or error route is needed. Keep state, PKCE, origin, and CSRF checks enabled.

For a callback mismatch, compare the exact scheme, hostname, port, and callback path with the app registration and any `AUTH_BASE_URL` override. For a client error, check the credential pair and whether organization OAuth restrictions require approval.

Restart sign-in after correcting settings instead of replaying an authorization code. Never log full callback URLs, provider tokens, or client secrets.
