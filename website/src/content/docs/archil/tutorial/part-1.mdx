Build an API that runs commands against a repository. The slow setup runs once, when you deploy: a disk with the repository cloned onto it. While the app runs, every command starts in a fresh microVM with that disk mounted, already set up.

The finished code is in [`examples/archil-sandbox`](https://github.com/alchemy-run/alchemy/tree/main/examples/archil-sandbox).

## Prerequisites

- [Node.js](https://nodejs.org) 24.11.1+ or [Bun](https://bun.sh)
- An Archil API key in an Alchemy profile ([Setup](/archil/setup))

## Declare the disk

```typescript title="src/Storage.ts"
import * as Archil from "@alchemy.run/archil";
import * as Effect from "effect/Effect";

export const Repo = Archil.Disk("Repo", {});
```

A disk is a filesystem stored in object storage. `Repo` holds the shared base.

## Seed it at deploy

```typescript title="src/Storage.ts"
export const Base = Effect.gen(function* () {
  const repo = yield* Repo;
  return yield* Archil.Checkpoint("Base", {
    disk: repo.diskId,
    run: ["test -d is || git clone --depth 1 https://github.com/sindresorhus/is is"],
  });
});
```

At deploy, Alchemy runs the commands in a serverless microVM with `Repo` mounted, then takes a checkpoint of what they produced. The commands run on the same disk every time they change, so each one skips work that's already done.

## Create the Stack

```typescript title="alchemy.run.ts"
import * as Archil from "@alchemy.run/archil";
import * as Alchemy from "alchemy";
import * as Effect from "effect/Effect";
import { Base } from "./src/Storage.ts";

export default Alchemy.Stack(
  "ArchilSandboxExample",
  { providers: Archil.providers(), state: Alchemy.localState() },
  Effect.gen(function* () {
    const base = yield* Base;
    return { checkpoint: base.name };
  }),
);
```

`Archil.providers()` reads your key from your Alchemy profile, and `Base` creates `Repo` first.

## Deploy

<PackageManagers run="alchemy deploy" />

The disk shows up under **Disks** in the [Archil console](https://console.archil.com), with the repository on it.
