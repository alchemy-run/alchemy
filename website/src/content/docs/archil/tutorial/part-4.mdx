## Add a command

Clone a second repository onto the disk:

```diff lang="typescript"
// src/Storage.ts
  return yield* Archil.Checkpoint("Base", {
    disk: repo.diskId,
    run: [
      "test -d is || git clone --depth 1 https://github.com/sindresorhus/is is",
+      "test -d slugify || git clone --depth 1 https://github.com/sindresorhus/slugify slugify",
    ],
  });
```

## Deploy the new base

<PackageManagers run="alchemy deploy" />

The commands changed, so Alchemy runs them again against `Repo` and takes a new checkpoint. `is` is already there and is skipped; `slugify` is cloned. The program is unchanged and isn't redeployed.

<PackageManagers script={`curl -X POST "$URL/run" -d 'ls ..'`} />

## Existing copies keep theirs

Every command `POST /run` starts mounts `Repo`, so it sees `slugify` right away. A user's disk is a copy taken on their first request, so users who already have one keep it, with their changes and without `slugify`. Users who arrive after the deploy copy the new base. To move a user onto it, delete their disk; their next request copies it again.
