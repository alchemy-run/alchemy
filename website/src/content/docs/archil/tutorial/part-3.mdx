## Copy the seeded disk onto a user's disk

```diff lang="typescript"
// src/Api.ts
    const exec = yield* Archil.ExecDisks();
+    const disks = yield* Archil.CreateDisk();
+
+    const userDisk = Effect.fn("userDisk")(function* (user: string) {
+      const existing = yield* disks.get(`user-${user}`);
+      if (existing !== undefined) return existing;
+      const home = yield* disks.create(`user-${user}`);
+      yield* exec.exec({
+        disks: { base: { disk: yield* repoId, readOnly: true }, home: home.diskId },
+        command: "cp -a /mnt/archil/base/. /mnt/archil/home/",
+      });
+      return home;
+    });
```

Provide `Archil.CreateDiskHttp` next to `Archil.ExecDisksHttp`, with `Layer.mergeAll`. A user's first request creates a disk for them and copies `Repo` onto it, in one microVM with both disks mounted. `disks.get` finds it again on their next request.

## Their changes stay on their disk

```diff lang="typescript"
// src/Api.ts
+        const runFor = /^\/users\/([a-z0-9-]+)\/run$/.exec(url.pathname)?.[1];
+        if (request.method === "POST" && runFor !== undefined) {
+          const home = yield* userDisk(runFor);
+          return yield* HttpServerResponse.json(yield* home.exec(`cd /mnt/archil/is && ${yield* request.text}`));
+        }
+        const match = /^\/users\/([a-z0-9-]+)\/files\/(.+)$/.exec(url.pathname);
+        if (match !== null) {
+          const home = yield* userDisk(match[1]!);
+          if (request.method === "PUT") yield* home.put(`is/${match[2]}`, yield* request.text);
+          return yield* HttpServerResponse.json({ content: yield* home.getText(`is/${match[2]}`) });
+        }
```

Commands run against the user's own disk, read-write, and files go onto it straight from the program, with no microVM. `Repo` never changes, so the next user's copy doesn't see their edits.

## Delete a user's disk

```diff lang="typescript"
// src/Api.ts
+        const user = /^\/users\/([a-z0-9-]+)$/.exec(url.pathname)?.[1];
+        if (request.method === "DELETE" && user !== undefined) {
+          yield* disks.delete(`user-${user}`);
+          return HttpServerResponse.empty({ status: 204 });
+        }
```

Disks the program creates aren't deleted with the Stack, so delete them when their owner goes away.
