## Write the program

```typescript title="src/Api.ts"
import * as Archil from "@alchemy.run/archil";
import * as Effect from "effect/Effect";
import { Repo } from "./Storage.ts";

export default class Api extends Archil.Sandbox<Api>()(
  "Api",
  { main: import.meta.url, port: 3000 },
  Effect.gen(function* () {
    const repo = yield* Repo;
    const repoId = yield* repo.diskId;
    const exec = yield* Archil.ExecDisks();
    return {};
  }).pipe(Effect.provide(Archil.ExecDisksHttp)),
) {}
```

`Api` is a program Alchemy runs in an Archil sandbox of its own, at a public URL. `ExecDisks` runs commands against disks named while it runs. `repoId` reads `Repo`'s id when the program runs.

## Run a command in a fresh microVM

```diff lang="typescript"
// src/Api.ts
    const exec = yield* Archil.ExecDisks();
+
+    const run = Effect.fn("run")(function* (command: string) {
+      return yield* exec.exec({
+        disks: { base: { disk: yield* repoId, readOnly: true } },
+        command: `cd /mnt/archil/base/is && ${command}`,
+      });
+    });
```

Each call boots a microVM with `Repo` mounted at `/mnt/archil/base`, runs the command, and shuts it down. The repository is already there. The disk is mounted read-only, so no command can change it.

## Serve it

```diff lang="typescript"
// src/Api.ts
-    return {};
+    return {
+      fetch: Effect.gen(function* () {
+        const request = yield* HttpServerRequest;
+        const url = new URL(request.url, "http://api");
+        if (request.method === "POST" && url.pathname === "/run") {
+          return yield* HttpServerResponse.json(yield* run(yield* request.text));
+        }
+        return HttpServerResponse.text("not found", { status: 404 });
+      }).pipe(Effect.orDie),
+    };
```

## Deploy it

```diff lang="typescript"
// alchemy.run.ts
  Effect.gen(function* () {
    const base = yield* Base;
-    return { checkpoint: base.name };
+    const api = yield* Api;
+    return { checkpoint: base.name, url: api.url };
```
