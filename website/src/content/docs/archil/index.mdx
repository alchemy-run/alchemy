Archil runs code against your data. A disk is a POSIX filesystem backed by object storage. Archil runs a shell command, a process or a whole program against it serverlessly: each call boots a Firecracker microVM with the disk mounted, runs to completion and shuts down, so you pay only for the call. Sandboxes are the long-lived form: microVMs that keep disks mounted, pause when idle and wake on the next request with their memory intact.

The same disks mount on your own hosts in about 50 ms, keep recent data on fast storage in front of Archil's bucket or your own, and branch from checkpoints in milliseconds whatever their size.

**New to Archil?** Start with [What is Archil?](/archil/what-is-archil).

## A quick example

A disk is seeded once, at deploy: a checkpoint runs commands against it in a microVM, here cloning a repository:

```typescript title="src/Storage.ts"
import * as Archil from "@alchemy.run/archil";
import * as Effect from "effect/Effect";

export const Repo = Archil.Disk("Repo", {});

export const Base = Effect.gen(function* () {
  const repo = yield* Repo;
  return yield* Archil.Checkpoint("Base", {
    disk: repo.diskId,
    run: ["test -d is || git clone --depth 1 https://github.com/sindresorhus/is is"],
  });
});
```

A Worker runs each command it's sent in a fresh microVM with `Repo` mounted, the repository already there. The [tutorial](/archil/tutorial/part-2) mounts it read-only, and gives each user a copy:

```typescript title="src/Api.ts"
import * as Archil from "@alchemy.run/archil";
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Effect from "effect/Effect";
import { HttpServerRequest } from "effect/http/HttpServerRequest";
import * as HttpServerResponse from "effect/http/HttpServerResponse";
import { Repo } from "./Storage.ts";

export default class Api extends Cloudflare.Worker<Api>()(
  "Api",
  { main: import.meta.url },
  Effect.gen(function* () {
    const repo = yield* Archil.ExecDisk(Repo);
    return {
      fetch: Effect.gen(function* () {
        const request = yield* HttpServerRequest;
        const result = yield* repo.exec(`cd /mnt/archil/is && ${yield* request.text}`);
        return yield* HttpServerResponse.json(result);
      }).pipe(Effect.orDie),
    };
  }).pipe(Effect.provide(Archil.ExecDiskHttp)),
) {}
```

And the Stack deploys them:

```typescript title="alchemy.run.ts"
import * as Archil from "@alchemy.run/archil";
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Alchemy from "alchemy";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import Api from "./src/Api.ts";
import { Base } from "./src/Storage.ts";

export default Alchemy.Stack(
  "MyApp",
  {
    providers: Layer.mergeAll(Cloudflare.providers(), Archil.providers()),
    state: Cloudflare.state(),
  },
  Effect.gen(function* () {
    const base = yield* Base;
    const api = yield* Api;
    return { checkpoint: base.name, url: api.url.as<string>() };
  }),
);
```
