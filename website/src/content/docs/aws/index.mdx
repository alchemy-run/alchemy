An Alchemy app on AWS is one **runtime** — usually a Lambda
Function — plus the **building blocks** it talks to: tables,
buckets, queues, streams. You wire them together with typed
**bindings**: call `S3.PutObject(bucket)` in your code and
Alchemy attaches the matching least-privilege IAM statement to
the function's role. The code is the policy.

New here? [Set up credentials](/aws/setup) first, then deploy
your first [Lambda](/aws/lambda).

## Pick your runtime

- **[Lambda](/aws/lambda)** — serverless, event-driven functions
  with public Function URLs. The primary documented path: every
  building block and event source in this section is shown
  running on Lambda.
- **[ECS](/aws/ecs)** — long-running containers on Fargate.
  Alchemy bundles your Effect program into a Docker image and
  runs it as a Cluster + Service + Task.
- **[EC2](/aws/ec2)** — full-control virtual machines, with the
  complete VPC networking toolkit around them.

Not sure which? See
[Choosing a runtime](/aws/choosing-a-runtime).

## Building blocks

- **[DynamoDB](/aws/dynamodb)** — key/value tables with
  `GetItem`/`PutItem` bindings and change-data-capture Streams.
- **[S3](/aws/s3)** — object storage with `GetObject`/`PutObject`
  bindings and bucket event notifications.
- **[SQS](/aws/sqs)** — queues with a `SendMessage` binding and a
  `Stream`-shaped Lambda consumer.
- **[Kinesis](/aws/kinesis)** — ordered, sharded data streams
  with a `PutRecord` binding and the same `Stream` consumer
  surface.
- **[VPC & networking](/aws/networking)** — the `Network` helper
  and the VPC primitives, for when ECS or EC2 needs explicit
  networking.

## What are you building?

| You're building                       | Reach for                                                                     |
| ------------------------------------- | ----------------------------------------------------------------------------- |
| An HTTP API                           | [Lambda](/aws/lambda) + Function URL + [DynamoDB](/aws/dynamodb)              |
| A REST API with stages/custom domains | [API Gateway](/aws/guides/api-gateway)                                        |
| An event pipeline                     | [Kinesis](/aws/kinesis) → Lambda                                              |
| Background jobs                       | [SQS](/aws/sqs) + Lambda                                                      |
| Object processing                     | [S3 events](/aws/guides/s3-events)                                            |
| Change data capture                   | [DynamoDB Streams](/aws/guides/dynamodb-streams)                              |
