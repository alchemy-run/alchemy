`AWS.Website.Octane` deploys an [OctaneJS](https://octanejs.com) app
to AWS. Octane's server runs on a Lambda Function URL with response
streaming; client assets are served from a private S3 bucket through
CloudFront. Configure the AWS adapter in your `octane.config.ts`:

```typescript
// octane.config.ts
import { aws } from "@alchemy.run/web-frameworks/octane/aws-adapter";
import { defineConfig } from "octane";

export default defineConfig({
  adapter: aws(),
});
```

## Deploy an Octane app

```typescript
// alchemy.run.ts
import * as Alchemy from "alchemy";
import * as AWS from "alchemy/AWS";
import * as Effect from "effect/Effect";

export default Alchemy.Stack(
  "MyOctaneApp",
  {
    providers: AWS.providers(),
    state: AWS.state(),
  },
  Effect.gen(function* () {
    const site = yield* AWS.Website.Octane("Web");
    return { url: site.url };
  }),
);
```

## Local dev

`alchemy dev` runs Octane's own Vite dev server (native HMR) instead
of deploying; `site.url` is the local address and no AWS resources
are created. Wrap the site in `Alchemy.remote()` to deploy the real
infrastructure even during dev.

## Custom domain

```typescript
const site = yield* AWS.Website.Octane("Web", {
  domain: {
    name: "app.example.com",
    hostedZoneId: zone.hostedZoneId,
  },
});
```
