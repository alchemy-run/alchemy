`AWS.Website.Vinext` deploys a [vinext](https://vinext.dev) app to
AWS: the RSC server on a streaming Lambda Function URL, static
assets in S3, and a CloudFront distribution whose edge router
serves uploaded files from S3 and forwards everything else to the
server.

This is **not** `AWS.Website.Nextjs` (OpenNext) and **not**
`Cloudflare.Website.Vinext` (Workers). The build runs `vinext
build` and wraps the App Router entry as a Lambda handler. Server
components and route handlers read `process.env`.

ISR / `"use cache"` on AWS is S3, not Cloudflare KV.
`AWS.Website.Vinext` provisions a dedicated cache bucket, sets
`CACHE_BUCKET_NAME`, and grants the Lambda Get/Put/Delete.

```typescript
import { s3Adapter } from "@alchemy.run/frontend-frameworks/vinext/cache/s3";
import { defineConfig } from "vite";
import vinext from "vinext";

export default defineConfig({
  plugins: [vinext({ cache: { data: s3Adapter() } })],
});
```

Missing `CACHE_BUCKET_NAME` (local `vinext start`) falls back to
memory.

## Declare the Website

```typescript
import * as AWS from "alchemy/AWS";

export const Website = AWS.Website.Vinext("Website", {
  env: {
    GREETING: "Hello from vinext on AWS!",
  },
});
```

```typescript
// app/page.tsx
export const dynamic = "force-dynamic";

export default function Home() {
  return <h1>{process.env.GREETING ?? "Hello!"}</h1>;
}
```

```typescript
// app/api/hello/route.ts
export function GET() {
  return Response.json({ hello: "world" });
}
```

`alchemy dev` runs `vinext dev`; wrap the site in `Alchemy.remote()`
to deploy the live Lambda + CloudFront path during dev.
