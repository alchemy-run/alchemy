`@alchemy.run/rivet` runs Durable Objects outside Cloudflare. A Durable Object is a class with one instance per name: a chat room, a game, a user's session. Each instance keeps its own data, in key-value storage and a SQL database, and can set an alarm to wake itself later.

You run Rivet yourself. A control plane stores every instance's data and routes calls to it. A pool of nodes runs your code. Both deploy in the same Stack as the rest of your app, on Docker, AWS, GCP, Kubernetes, Fly or Hetzner.

## A taste

A Durable Object declares what each instance can do:

```typescript title="src/room.ts"
export default class Room extends Rivet.DurableObject<Room>()(
  "Room",
  { main: import.meta.url },
  Effect.gen(function* () {
    return Effect.gen(function* () {
      const state = yield* Rivet.DurableObjectState;
      return {
        join: () =>
          Effect.gen(function* () {
            const visitors = ((yield* state.storage.get<number>("visitors")) ?? 0) + 1;
            yield* state.storage.put("visitors", visitors);
            return visitors;
          }),
      };
    });
  }).pipe(Effect.provide(Default)),
) {}
```

`Default` is the pool it runs on, given the control plane it joins:

```typescript title="src/cluster.ts"
export const Cluster = RivetDocker.ControlPlane("Rivet");

export const Default = RivetDocker.Pool("Default").pipe(Layer.provide(Cluster));
```

And any runtime calls a room by its name:

```typescript title="src/api.ts"
const rooms = yield* Room;
const visitors = yield* rooms.getByName("lobby").join();
```

Swap `RivetDocker` for `RivetHetzner`, `RivetAWS` or any other cloud, and the room doesn't change.
