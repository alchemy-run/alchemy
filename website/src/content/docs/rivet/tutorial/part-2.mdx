Each room has its own SQLite database. Store its messages there.

## Create the table

```diff lang="typescript"
// src/room.ts
    return Effect.gen(function* () {
      const state = yield* Rivet.DurableObjectState;
+      const sql = state.storage.sql;
+
+      yield* (yield* sql.exec(
+        "CREATE TABLE IF NOT EXISTS messages (author TEXT NOT NULL, text TEXT NOT NULL)",
+      )).toArray();

      return {
```

This runs once per room, before its first call. `exec` returns a cursor, and `toArray` runs the statement to the end.

## Post a message

```diff lang="typescript"
// src/room.ts
      return {
        join: () =>
          Effect.gen(function* () {
            const visitors = ((yield* state.storage.get<number>("visitors")) ?? 0) + 1;
            yield* state.storage.put("visitors", visitors);
            return visitors;
          }),
+        post: (author: string, text: string) =>
+          Effect.gen(function* () {
+            yield* (yield* sql.exec(
+              "INSERT INTO messages (author, text) VALUES (?, ?)",
+              author,
+              text,
+            )).toArray();
+          }),
      };
```

Pass values after the query. Each `?` takes the next one.

## Read the messages

```diff lang="typescript"
// src/room.ts
+        messages: () =>
+          Effect.gen(function* () {
+            const rows = yield* sql.exec<{ author: string; text: string }>(
+              "SELECT author, text FROM messages",
+            );
+            return yield* rows.toArray();
+          }),
      };
```

The type argument describes each row.

## Describe a message

```diff lang="typescript"
// src/api.ts
import * as HttpServerResponse from "effect/http/HttpServerResponse";
+import * as Schema from "effect/Schema";
import { Cluster } from "./cluster.ts";
import Room from "./room.ts";
+
+const Message = Schema.Struct({ author: Schema.String, text: Schema.String });
```

The API checks every posted message against this schema.

## Accept posts

```diff lang="typescript"
// src/api.ts
        if (action === "join") {
          return yield* HttpServerResponse.json({ visitors: yield* room.join() });
        }
+        if (action === "messages" && request.method === "POST") {
+          return yield* HttpServerRequest.schemaBodyJson(Message).pipe(
+            Effect.flatMap((message) => room.post(message.author, message.text)),
+            Effect.as(HttpServerResponse.empty({ status: 201 })),
+            Effect.catchTag("SchemaError", () =>
+              Effect.succeed(HttpServerResponse.empty({ status: 400 })),
+            ),
+          );
+        }
        return HttpServerResponse.empty({ status: 404 });
```

A body that doesn't match `Message` gets a 400.

## Talk in a room

```sh
curl -X POST localhost:3000/lobby/messages \
  -H 'content-type: application/json' \
  -d '{"author":"sam","text":"hello"}'
curl localhost:3000/lobby/messages
# [{"author":"sam","text":"hello"}]
curl localhost:3000/kitchen/messages
# []
```

Each room only sees its own messages.
