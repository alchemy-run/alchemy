title: Rivet Cloud
description: Use Rivet Cloud as the control plane, sign in to it from the alchemy CLI or CI, and run your pools of nodes on any cloud.
---

Let [Rivet Cloud](https://rivet.dev) run the control plane, and you keep only the nodes: a pool on any cloud, connecting out to Rivet. There are no engines, disks or buckets of your own to look after.

```typescript title="src/cluster.ts"
import * as RivetAWS from "@alchemy.run/rivet/AWS";
import * as RivetCloud from "@alchemy.run/rivet/Cloud";
import * as Layer from "effect/Layer";

export const Cluster = RivetCloud.ControlPlane("Rivet");

export const Default = RivetAWS.EcsPool("Default").pipe(Layer.provide(Cluster));
```

Each stage gets a namespace of its own on the cluster, the same as on a control plane you run.

## Sign in

Create a cluster in the [Rivet dashboard](https://dashboard.rivet.dev), then add Rivet Cloud to your profile:

```sh
alchemy profile edit --add RivetCloud
```

The dashboard opens and asks you to approve a code. Once you do, the profile keeps the session and refreshes it, and remembers the cluster you chose. Deploys read the cluster's address and admin token with it.

Self-hosted control planes never ask for this: only `RivetCloud.ControlPlane` signs in.

## Sign in from CI

CI can't approve a code. Create a cluster token in the Rivet dashboard with the `rivet:cluster:read`, `rivet:cluster:engine:read` and `rivet:cluster:engine:write` scopes and no expiry, and give it to the job with the cluster's name:

```sh title=".env"
RIVET_CLOUD_TOKEN=...
RIVET_CLOUD_CLUSTER=my-cluster
```

The same token can go in a profile instead, as the "Cluster token" method.

## Choose a cluster

A profile deploys to the cluster chosen at sign-in. Name another one in code:

```typescript title="src/cluster.ts"
export const Cluster = RivetCloud.ControlPlane("Rivet", { cluster: "acme" });
```

## Pick a pool

Any pool works, because nodes connect out to Rivet Cloud. See [Pools](/rivet/pools).

## Your own control plane

To connect to a control plane you already run, use `Rivet.ControlPlane`. See [Control planes](/rivet/control-planes#use-one-you-already-run).

Every option, with its default, is in the reference: [Cloud ControlPlane](/providers/rivet/cloud#controlplane).
