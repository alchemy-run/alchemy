---
title: Hetzner
description: Run a Rivet control plane and pools of nodes on Hetzner Cloud Servers.
---

Host your Durable Objects on Hetzner Cloud, and the control plane runs on Servers with a Volume each, behind a Load Balancer. Each node in a pool is a Server of its own. It's where [Part 4 of the tutorial](/rivet/tutorial/part-4) runs the rooms.

```typescript title="src/cluster.ts"
import * as RivetHetzner from "@alchemy.run/rivet/Hetzner";
import * as Layer from "effect/Layer";

export const Cluster = RivetHetzner.ControlPlane("Rivet");

export const Default = RivetHetzner.Pool("Default").pipe(Layer.provide(Cluster));
```

Install `@alchemy.run/hetzner` and finish [Hetzner setup](/hetzner/setup).

## The control plane

You get one engine on a Server, with its data on a Volume. A Load Balancer is the endpoint. A firewall blocks every other connection to the Server.

```typescript title="src/cluster.ts"
export const Cluster = RivetHetzner.ControlPlane("Rivet", {
  location: "fsn1",
  serverType: "cx33",
  diskSize: 40,
});
```

## Run more engines

More engines share object storage, so `objectStorage` is required. Hetzner Object Storage works:

```typescript title="src/cluster.ts"
export const Cluster = RivetHetzner.ControlPlane("Rivet", {
  instances: 3,
  objectStorage: {
    kind: "s3",
    bucket: "my-rivet-data",
    endpoint: "https://nbg1.your-objectstorage.com",
    region: "nbg1",
    accessKeyId: Config.String("HETZNER_S3_ACCESS_KEY_ID"),
    secretAccessKey: Config.Redacted("HETZNER_S3_SECRET_ACCESS_KEY"),
  },
});
```

Create the bucket and its keys in the Hetzner console first.

## The pool

```typescript title="src/cluster.ts"
export const Default = RivetHetzner.Pool("Default", { replicas: 2, serverType: "cx23" }).pipe(
  Layer.provide(Cluster),
);
```

Each node's firewall only allows SSH, which Alchemy uses to deploy it.

## Call it from a Hetzner Service

```typescript title="src/api.ts"
export const ApiServer = Hetzner.Server("ApiServer", {
  serverType: "cx23",
  image: "ubuntu-24.04",
  location: "nbg1",
});

export default class Api extends Hetzner.Service<Api>()(
  "Api",
  { server: ApiServer, main: import.meta.url },
  Effect.gen(function* () {
    const rooms = yield* Room;
    return {
      fetch: Effect.gen(function* () {
        const visitors = yield* rooms.getByName("lobby").join();
        return yield* HttpServerResponse.json({ visitors });
      }),
    };
  }),
) {}
```

[Part 4 of the tutorial](/rivet/tutorial/part-4) deploys this.

Every option, with its default, is in the reference: [Hetzner ControlPlane](/providers/rivet/hetzner#controlplane) and [Hetzner Pool](/providers/rivet/hetzner#pool).
