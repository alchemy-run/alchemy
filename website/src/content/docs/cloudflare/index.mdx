`@alchemy.run/cloudflare` puts your Cloudflare app and its infrastructure in one TypeScript program. A Worker holds its own handler. The Bucket, database and Durable Objects it uses are declared next to it, and each one reaches the Worker as a typed binding.

Deploy it to your account with `alchemy deploy`, or run it on your machine with `alchemy dev`, on the same runtime Cloudflare uses.

## A taste

A Bucket is a declaration:

```typescript title="src/uploads.ts"
import * as Cloudflare from "@alchemy.run/cloudflare";

export const Uploads = Cloudflare.R2.Bucket("Uploads");
```

A Worker binds it and reads from it. The binding is in the Worker's own code, and its access level is in the name:

```typescript title="src/worker.ts"
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/http/HttpServerResponse";
import { Uploads } from "./uploads.ts";

export default Cloudflare.Worker(
  "Worker",
  { main: import.meta.url },
  Effect.gen(function* () {
    const uploads = yield* Cloudflare.R2.ReadBucket(Uploads);
    return {
      fetch: Effect.gen(function* () {
        const object = yield* uploads.get("hello.txt");
        return object
          ? HttpServerResponse.text(yield* object.text())
          : HttpServerResponse.text("Not found", { status: 404 });
      }).pipe(Effect.orDie),
    };
  }).pipe(Effect.provide(Cloudflare.R2.ReadBucketBinding)),
);
```

And the Stack deploys it to the account your profile signs in to:

```typescript title="alchemy.run.ts"
import * as Alchemy from "alchemy";
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Effect from "effect/Effect";
import Worker from "./src/worker.ts";

export default Alchemy.Stack(
  "MyApp",
  { providers: Cloudflare.providers(), state: Cloudflare.state() },
  Effect.gen(function* () {
    const worker = yield* Worker;
    return { url: worker.url };
  }),
);
```

## Where to start

**New to Cloudflare?** [What is Cloudflare?](/cloudflare/what-is-cloudflare) walks through accounts, zones, Workers, bindings, Durable Objects, storage, queues and workflows, once each, and shows how Alchemy models every one.

**Want to build one?** The [tutorial](/cloudflare/tutorial/part-1) goes from an empty directory to a Worker with storage, tests, local development and CI, one step at a time. Start with [Setup](/cloudflare/setup) to connect your account.

**Want the whole picture?** The chapters follow the shape of Cloudflare itself. Start with the code: [Workers](/cloudflare/compute/workers), [Durable Objects](/cloudflare/compute/durable-objects), [Workflows](/cloudflare/compute/workflows) and [Containers](/cloudflare/compute/containers). Then what it stores: [KV](/cloudflare/data/kv), [R2](/cloudflare/data/r2), [D1](/cloudflare/data/d1) and [Hyperdrive](/cloudflare/data/hyperdrive). Then how work flows between Workers: [Queues](/cloudflare/messaging/queues) and [Cron triggers](/cloudflare/messaging/cron). Then how traffic reaches them: [Domains & DNS](/cloudflare/networking/domains) and [Custom domains & routes](/cloudflare/networking/custom-domains). And finally how you protect and watch them: [Secrets & env](/cloudflare/security/secrets-env), [Access](/cloudflare/security/access) and [Native tracing](/cloudflare/observability/workers-tracing).

**Building a website or an API?** [Frontends](/cloudflare/frontend/frontends) covers every supported framework on Workers with static assets. [Effect HTTP API](/cloudflare/apis/effect-http-api) and [Effect RPC](/cloudflare/apis/effect-rpc) serve typed APIs.

**Building with AI?** [Workers AI](/cloudflare/ai/workers-ai), [AI Gateway](/cloudflare/ai/ai-gateway) and [Vectorize](/cloudflare/ai/vectorize) run models, route calls to providers and search embeddings, all through bindings.

**Working offline?** [Local development](/cloudflare/local-development) runs the whole Stack on your machine.

Every resource is in the generated [API reference](/providers), including the zero-trust and zone-security services these chapters don't cover.
