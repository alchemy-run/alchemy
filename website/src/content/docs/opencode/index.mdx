[OpenCode](https://opencode.ai) is an open-source coding agent that runs as a server: it keeps sessions, runs its own tools on the machine it is on, and asks a model provider for each answer. Alchemy runs it in a sandbox for each session, and answers its model requests and its calls to your tools from your Durable Object. The sandbox holds no API key. Models, tools, skills and sandboxes are the ones you declare with [`@alchemy.run/ai`](/ai).

**New to OpenCode?** Start with [What is OpenCode?](/opencode/what-is-opencode).

## A quick example

A model, and where sandboxes run:

```typescript title="src/agent.ts"
import * as AI from "@alchemy.run/ai";
import * as AIBoat from "@alchemy.run/ai/Boat";
import * as Boat from "@alchemy.run/boat";
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";

export class Fast extends AI.Model<Fast>()("fast") {}

export const FastLive = Layer.unwrap(
  Effect.gen(function* () {
    const ai = yield* Cloudflare.Workers.AI();
    return Fast.layer(ai.model({ model: "@cf/meta/llama-3.3-70b-instruct-fp8-fast" }));
  }),
).pipe(Layer.provide(Cloudflare.Workers.AIBinding));

export const Sandbox = AIBoat.Sandboxes(
  Boat.Snapshot("Base", { run: ["npm install --global pnpm"] }),
);
```

A Durable Object yields the harness and prompts a session by name:

```typescript title="src/Coder.ts"
import * as AI from "@alchemy.run/ai";
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as OpenCode from "@alchemy.run/opencode";
import * as OpenCodeCloudflare from "@alchemy.run/opencode/Cloudflare";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import { Fast, FastLive, Sandbox } from "./agent.ts";

const HarnessLive = Layer.mergeAll(
  FastLive,
  Sandbox,
  OpenCode.CodingTools,
  OpenCodeCloudflare.DurableObjectInstance,
);

export default class Coder extends Cloudflare.DurableObject<Coder>()(
  "Coder",
  Effect.gen(function* () {
    const harness = yield* OpenCode.Harness({ models: [Fast], tools: [AI.CodingTools] });

    return Effect.gen(function* () {
      return {
        prompt: Effect.fn(function* (name: string, text: string, requestId: string) {
          const reply = yield* harness.session(name).prompt(text, { requestId });
          return reply.text;
        }),
      };
    });
  }).pipe(Effect.provide(HarnessLive)),
) {}
```
