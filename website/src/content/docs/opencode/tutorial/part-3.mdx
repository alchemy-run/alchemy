The bot answers over `curl`, which waits for the whole prompt. GitHub won't: a webhook delivery must be answered within ten seconds, and a prompt takes longer. So the Worker hands the issue to the Durable Object and returns, and the object runs the prompt from its alarm and posts the answer itself.

```diff lang="typescript"

+import * as Alchemy from "alchemy";
import * as Effect from "effect/Effect";
```


A callback that fails is delivered again. `requestId` makes that safe: a second prompt with the same id waits for the first and gets its answer.

## Schedule a job instead of prompting

Replace `ask` with a method that stores the job and returns:

```diff lang="typescript"
return {
-  ask: Effect.fn(function* (text: string) {
-    const reply = yield* session.prompt(text);
-    return reply.text;
-  }),
+  ask: Effect.fn(function* (issue: number, text: string, deliveryId: string) {
+    yield* answer.schedule(deliveryId, {
+      after: 0,
+      payload: { issue, text, deliveryId },
+    });
+  }),
};
```

`after: 0` runs it as soon as the alarm can fire. The job's id is the delivery's id, so scheduling the same delivery twice leaves one job.

## Consume the repository's events

`GitHub.consumeRepositoryEvents` subscribes the Worker to the repository. At deploy it creates the webhook, pointed at the Worker, with a signing secret. While the Worker runs, it verifies each delivery and calls your handler with a typed event.

```diff lang="typescript"
import * as Cloudflare from "@alchemy.run/cloudflare";
+import * as GitHub from "@alchemy.run/github";
import * as Effect from "effect/Effect";
import { HttpServerRequest } from "effect/http/HttpServerRequest";
import * as HttpServerResponse from "effect/http/HttpServerResponse";
import Issue from "./Issue.ts";
+import { owner, repository } from "./Repo.ts";

export default class Bot extends Cloudflare.Worker<Bot>()(
  "Bot",
  { main: import.meta.url },
  Effect.gen(function* () {
    const issues = yield* Issue;

+    yield* GitHub.consumeRepositoryEvents(
+      { owner, repository, events: ["issues"] },
+      Effect.fn(function* (event) {
+        const { action, issue } = event.payload;
+        if (action === "opened") {
+          yield* issues
+            .getByName(String(issue.number))
+            .ask(issue.number, `Issue #${issue.number}: ${issue.title}\n\n${issue.body ?? ""}`, event.id);
+        }
+      }, Effect.orDie),
+    );
+
    return {
```

`event.id` is GitHub's id for the delivery. The handler returns once the job is stored, so GitHub gets its answer in milliseconds.
