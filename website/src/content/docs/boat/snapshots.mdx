A **snapshot** is a sandbox's disk saved under a name: installed packages, a cloned repository, a warm build cache. A sandbox started from it begins exactly there. A **fork** copies one sandbox into a new one from its last snapshot, which Boat takes now and then while it runs, and every time it stops.

## Save a snapshot

Declare the sandbox to build, then a snapshot of it:

```typescript title="src/Golden.ts"
import * as Boat from "@alchemy.run/boat";
import * as Effect from "effect/Effect";

export const Builder = Boat.Sandbox("Builder", {
  type: "small",
  setupScript: "sudo apt-get install -y ripgrep && npm i -g pnpm",
});

export const Golden = Effect.gen(function* () {
  const builder = yield* Builder;
  return yield* Boat.Snapshot("Golden", { sandboxId: builder.sandboxId });
});
```

Saving waits for the sandbox's setup script to finish, then for Boat to save the disk, a few seconds. The snapshot keeps the disk as it was at that deploy. Destroying the resource deletes it.

## Start sandboxes from it

A declared sandbox starts from a snapshot with `from`:

```typescript
const golden = yield* Golden;
const box = yield* Boat.Sandbox("Box", { from: golden.name });
```

So do the sandboxes a binding creates, when you bind the snapshot:

```typescript
const sandboxes = yield* Boat.CreateSandbox(yield* Golden);
const sandbox = yield* sandboxes.create({ ttlSeconds: 600 });
```

A sandbox from a snapshot takes its machine size unless you pass `type`.

## Fork a sandbox

`fork` starts a copy of a sandbox created at run time, from its last snapshot:

```typescript
yield* sandbox.stop(); // stopping takes a snapshot
const copy = yield* sandbox.fork({ ttlSeconds: 600 });
yield* sandbox.resume();
```

Before a sandbox has a snapshot, `fork` fails with `ForkNeedsSnapshot`. Boat never copies labels onto a fork; Alchemy adds the host's `alchemy.*` labels again.

## Save from a running sandbox

A handle saves its sandbox under a name of your own, and waits until it's ready:

```typescript
const saved = yield* sandbox.snapshot("after-install");
```

Snapshots you save at run time aren't deleted with the Stack.
