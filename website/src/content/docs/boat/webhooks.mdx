## Declare a webhook

Point it at a Worker of yours:

```typescript title="alchemy.run.ts"
const receiver = yield* Receiver;
const hook = yield* Boat.Webhook("Events", {
  url: Output.interpolate`${receiver.url}/boat`,
  events: ["sandbox.ready", "sandbox.archived"],
});
```

The URL must be public HTTPS, on port 443. Changing it, or the events, updates the webhook in place.

## Check the signature

Boat signs each delivery with the webhook's secret. `hook.secret` is that secret, as a `Redacted` value: Boat shows it only when it's created, so Alchemy keeps it in state. Bind it into the receiver to check each delivery before acting on it.
