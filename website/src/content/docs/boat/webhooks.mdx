## Receive events in a Worker

Subscribe a Worker to the events it needs, with a handler for each one:

```typescript title="src/Api.ts"
import * as Boat from "@alchemy.run/boat";
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/http/HttpServerResponse";

export default class Api extends Cloudflare.Worker<Api>()(
  "Api",
  { main: import.meta.url },
  Effect.gen(function* () {
    yield* Boat.consumeSandboxEvents({ events: ["sandbox.ready", "sandbox.archived"] }, (event) =>
      Effect.log(`${event.data.sandbox.id} is ${event.data.state}`),
    );
    return { fetch: Effect.succeed(HttpServerResponse.text("ok")) };
  }).pipe(Effect.provide(Boat.SandboxEventsLive)),
) {}
```

At deploy, Alchemy registers a webhook pointing at the Worker's `/__alchemy/boat/events`, and gives the Worker its signing secret. The Worker checks each delivery's signature, and refuses unsigned, forged or stale ones (over five minutes old) with 401 before your handler runs. Boat retries a delivery that fails, so make the handler safe to repeat, keyed on `event.id`. Destroying the Worker removes the webhook.

## Only your stack's sandboxes

Boat sends a webhook the events of every sandbox in the account. The event names only the sandbox's id, so the Worker reads its labels from Boat, with a key that can only read sandboxes, and hands your handler only the ones this stack and stage own: sandboxes the Stack declares, and the ones its bindings create.

The event your handler gets carries the labels, so you can route by your own labels too:

```typescript
yield* Boat.consumeSandboxEvents({ events: ["sandbox.archived"] }, (event) =>
  event.data.sandbox.labels?.user === undefined
    ? Effect.void
    : Effect.log(`${event.data.sandbox.labels.user}'s sandbox stopped`),
);
```

To receive every sandbox's events, pass `scope: "account"`. The Worker then skips the lookup, and `labels` is undefined. A sandbox that was deleted before its event arrived can't be read, so `scope: "stack"` drops its events.

## Limits

An account has at most 10 webhooks, and each Worker that consumes events, in each stage, uses one. Destroy stages you no longer use. Boat delivers only to public HTTPS URLs on port 443, so under `alchemy dev` no webhook is registered.

## Declare a webhook yourself

For an endpoint that isn't an Alchemy host, declare the webhook directly:

```typescript title="alchemy.run.ts"
const hook = yield* Boat.Webhook("Events", {
  url: "https://example.com/boat",
  events: ["sandbox.ready", "sandbox.archived"],
});
```

`hook.secret` is the signing secret, as a `Redacted` value: Boat shows it only when the webhook is created, so Alchemy keeps it in state. Each delivery carries `X-Ascii-Delivery`, `X-Ascii-Timestamp` and `X-Ascii-Signature: v1=<hex HMAC-SHA256 of delivery.timestamp.body>`; check it before acting on the event. Changing the URL or the events updates the webhook in place.
