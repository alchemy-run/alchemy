Build an API that runs code in sandboxes: a one-shot sandbox per request, and a sandbox per user that keeps their files.

The finished code is in [`examples/boat-agent-sandbox`](https://github.com/alchemy-run/alchemy/tree/main/examples/boat-agent-sandbox).

## Prerequisites

Finish [Boat setup](/boat/setup) and [Cloudflare setup](/cloudflare/setup).

## Declare a sandbox

Start with one sandbox in the Stack, to see Boat work:

```typescript title="alchemy.run.ts"
import * as Boat from "@alchemy.run/boat";
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Alchemy from "alchemy";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";

export default Alchemy.Stack(
  "BoatAgentSandboxExample",
  {
    providers: Layer.mergeAll(Cloudflare.providers(), Boat.providers()),
    state: Alchemy.localState(),
  },
  Effect.gen(function* () {
    const box = yield* Boat.Sandbox("Scratch", { type: "small", noEnv: true, ttlSeconds: 600 });
    return { sandboxId: box.sandboxId };
  }),
);
```

`noEnv` keeps your account's secrets out of it, and it stops itself after ten minutes.

## Deploy

<PackageManagers run="alchemy deploy" />

The sandbox is ready in about a second. It's in your Boat dashboard, labelled with the Stack, the stage and `Scratch`.
