`SQL.LibSQL` opens an `@effect/sql-libsql` client over a libSQL database, such as [Turso](/turso). Queries are Effects with `SqlError` in the error channel.

Install the driver — an optional peer of alchemy:

<PackageManagers add={deps} />

## Connect

Bind a Turso database with `Turso.Connect` and hand the client to `SQL.LibSQL`:

```typescript
// src/api.ts
import * as Cloudflare from "alchemy/Cloudflare";
import * as SQL from "alchemy/SQL/LibSQL";
import * as Turso from "alchemy/Turso";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/http/HttpServerResponse";
import { Db } from "./db.ts";

export default class Api extends Cloudflare.Worker<Api>()(
  "Api",
  { main: import.meta.url },
  Effect.gen(function* () {
    const conn = yield* Turso.Connect(Db);
    const sql = yield* SQL.LibSQL(conn);

    return {
      fetch: Effect.gen(function* () {
        const users = yield* sql`SELECT * FROM users`;
        return yield* HttpServerResponse.json({ users });
      }),
    };
  }).pipe(Effect.provide(Turso.ConnectHttp)),
) {}
```

The client opens on the first query of a request and closes when the request ends — see [Connection lifecycle](/sql/effect-sql/lifecycle).

## Connect to any libSQL server

```typescript
const sql = yield* SQL.LibSQL({
  url: "libsql://my-db.example.com",
  authToken: Redacted.make(token),
});
```

`url` and `authToken` accept plain values or Effects that return them.

## Queries

Interpolated values are parameters, never string concatenation:

```typescript
const user = yield* sql`SELECT * FROM users WHERE id = ${id}`;

yield* sql`INSERT INTO users ${sql.insert({ name, email })}`;
```

Annotate the row type with `sql<{ id: number; name: string }>\`...\``.

## Transactions

```typescript
yield* sql.withTransaction(
  Effect.gen(function* () {
    yield* sql`UPDATE accounts SET balance = balance - ${amount} WHERE id = ${from}`;
    yield* sql`UPDATE accounts SET balance = balance + ${amount} WHERE id = ${to}`;
  }),
);
```

If any statement fails, the transaction rolls back.

## Errors

```typescript
const users = yield* sql`SELECT * FROM users`.pipe(
  Effect.catchTag("SqlError", () => Effect.succeed([])),
);
```

## Provide as a service

Depend on the generic `SqlClient` and provide the database with `SQL.LibSQLLayer`:

```typescript
import * as SqlClient from "effect/sql/SqlClient";

const makeUsers = Effect.gen(function* () {
  const sql = yield* SqlClient.SqlClient;
  return {
    find: (id: number) => sql<User>`SELECT * FROM users WHERE id = ${id}`,
  };
});

const users = yield* makeUsers.pipe(Effect.provide(SQL.LibSQLLayer(conn)));
```
