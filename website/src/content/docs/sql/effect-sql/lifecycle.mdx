## Construction runs once, events run many times

```typescript
Effect.gen(function* () {
  const sql = yield* SQL.Postgres({ url }); // No connection yet.

  return {
    fetch: Effect.gen(function* () {
      const users = yield* sql`SELECT * FROM users`;
      return yield* HttpServerResponse.json(users);
    }),
  };
});
```

Construct the adapter during initialization. The first query opens its connection in the handler's scope.

## One client per execution

```typescript
const users = yield* sql`SELECT * FROM users`;
const posts = yield* sql`SELECT * FROM posts`;
```

Both queries share the execution's client. Closing the scope releases it; migration resources connect separately during deployment.

## Why not a global pool

Workerd sockets belong to the request that created them. Use [Hyperdrive](/cloudflare/data/hyperdrive) for cross-request pooling, not an isolate-wide socket pool.

## Narrowing with Effect.scoped

```typescript
const users = yield* Effect.scoped(sql`SELECT * FROM users`);
```

The client closes at the end of this block, before the surrounding handler finishes.

## Lambda and servers

Alchemy supplies a scope per invocation or request. Standalone programs use `Effect.scoped`.
