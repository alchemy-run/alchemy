## Postgres

```typescript
import * as Neon from "alchemy/Neon";

const project = yield* Neon.Project("Database");
const branch = yield* Neon.Branch("App", {
  project,
  migrations: "./migrations",
});
```

[Setup](/neon/setup) · [Migrations](/neon/data/migrations) · [Preview branches](/neon/guides/preview-branches)

For a Worker, pass the direct origin to Hyperdrive:

```typescript
const hyperdrive = yield* Cloudflare.Hyperdrive.Connection("Database", {
  origin: branch.origin,
  caching: { disabled: true },
});
```

```typescript
const connection = yield* Cloudflare.Hyperdrive.Connect(hyperdrive);
const db = yield* Drizzle.Postgres(connection.connectionString);
```
