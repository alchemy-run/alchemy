## Service + Neon + Drizzle

```typescript
const project = yield* Neon.Project("Database");
const branch = yield* Neon.Branch("App", {
  project,
  migrations: "./migrations",
});
```

Pass the connection URL to the backend Service:

```typescript
env: { DATABASE_URL: branch.connectionUri }
```

```typescript
const db = yield* Drizzle.Postgres(Config.Redacted("DATABASE_URL"));
```

This uses external Neon Postgres, not a Hetzner-managed database resource.
