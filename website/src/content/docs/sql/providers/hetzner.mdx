---
title: Hetzner
description: Query external Postgres or MySQL databases from a Hetzner-hosted application.
---

Hetzner hosts the application; provision Postgres or MySQL separately and connect over a reachable network. These are external database connections, not managed Hetzner database services.

## External Postgres

```typescript
import * as Drizzle from "alchemy/Drizzle/Postgres";
import * as Config from "effect/Config";
import * as Effect from "effect/Effect";
import { users } from "./schema.ts";

const url = yield* Config.Redacted("DATABASE_URL");
const db = yield* Drizzle.Postgres(Effect.succeed(url));
const rows = yield* db.select().from(users);
```

Follow [Hetzner + Postgres + Drizzle](/hetzner/data/drizzle-postgres) for application deployment and connection configuration.

[Neon](/sql/providers/neon) and [PlanetScale](/sql/providers/planetscale) cover managed database options. The [Postgres client guide](/sql/drizzle/postgres) works with either provider.

## External MySQL

Connect to a reachable MySQL database, such as [PlanetScale MySQL](/planetscale/data/mysql), using the [Drizzle MySQL client](/sql/drizzle/mysql) or [Effect SQL](/sql/effect-sql/mysql). Provision the database separately and supply its connection details to the Hetzner application.

See [Hetzner setup](/hetzner/setup) and [generate and commit migrations](/sql/drizzle/migrations).
