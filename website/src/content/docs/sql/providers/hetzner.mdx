Host the application on Hetzner and connect it to a reachable Postgres database, such as Neon. This guide does not provision a managed Hetzner database.

## Query from a handler

```typescript
import * as Drizzle from "alchemy/Drizzle/Postgres";
import * as Config from "effect/Config";
import * as Effect from "effect/Effect";
import { users } from "./schema.ts";

const url = yield* Config.Redacted("DATABASE_URL");
const db = yield* Drizzle.Postgres(Effect.succeed(url));
const rows = yield* db.select().from(users);
```

Follow [Hetzner + Postgres + Drizzle](/hetzner/data/drizzle-postgres) for application deployment and connection configuration.
