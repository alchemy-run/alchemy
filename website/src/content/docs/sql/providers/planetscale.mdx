## Postgres

```typescript
import * as Planetscale from "alchemy/Planetscale";

const database = yield* Planetscale.PostgresDatabase("Database", {
  region: { slug: "us-east" },
  clusterSize: "PS_10",
});
const branch = yield* Planetscale.PostgresBranch("App", {
  database,
  migrations: "./migrations",
});
```

## MySQL

```typescript
const database = yield* Planetscale.MySQLDatabase("Database", {
  region: { slug: "us-east" },
  clusterSize: "PS_10",
});
const branch = yield* Planetscale.MySQLBranch("App", {
  database,
  isProduction: false,
  migrations: "./migrations",
});
```

## Workers with Hyperdrive

```typescript
const connection = yield* Cloudflare.Hyperdrive.Connect(hyperdrive);
const db = yield* Drizzle.Postgres(connection.connectionString);
```

Use `Drizzle.MySQL` for MySQL. The integration guide includes branch credentials and Hyperdrive setup.
