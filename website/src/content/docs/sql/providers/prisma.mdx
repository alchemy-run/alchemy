## Prisma Postgres

```typescript
import * as Prisma from "alchemy/Prisma";

const project = yield* Prisma.Project("App", {
  createDatabase: false,
  region: "us-east-1",
});
const database = yield* Prisma.Postgres("Database", { project });
```

## Prisma Compute

```typescript
const db = yield* Drizzle.Postgres(Config.Redacted("DATABASE_URL"));
```

Compute applications receive database variables from their project.

[Compute guide](/prisma/compute/apps) · [Setup](/prisma/setup)

## Prisma ORM

```typescript
const contract = yield* Prisma.Contract("Contract");
yield* Prisma.Migrate("Migrate", {
  url: yield* Config.Redacted("DATABASE_URL"),
  contract,
});
```

Prisma ORM is separate from Prisma hosting. ORM v8 requires PostgreSQL 17+; its current Worker examples use Neon.
