This is the Prisma cloud provider and Prisma Postgres, not a requirement to use Prisma ORM. Drizzle and Effect SQL can query the database.

## Create a database

```typescript
import * as Prisma from "alchemy/Prisma";

const project = yield* Prisma.Project("App", {
  createDatabase: false,
  region: "us-east-1",
});

const database = yield* Prisma.Postgres("Database", { project });
```

See [Prisma Postgres](/prisma/data/postgres) for local development and [branches](/prisma/data/branches) for preview databases.
