## D1

```typescript
const database = yield* Cloudflare.D1.Database("Database", {
  migrations: "./migrations",
});
```

In a Worker:

```typescript
const connection = yield* Cloudflare.D1.QueryDatabase(database);
const db = yield* Drizzle.D1(connection);
```

## Postgres and MySQL

```typescript
const hyperdrive = yield* Cloudflare.Hyperdrive.Connection("Database", {
  origin: branch.origin,
  caching: { disabled: true },
});
```

```typescript
const connection = yield* Cloudflare.Hyperdrive.Connect(hyperdrive);
const db = yield* Drizzle.Postgres(connection.connectionString);
```

Use `Drizzle.MySQL` for a MySQL origin. Apply migrations through the database provider, not Hyperdrive.
