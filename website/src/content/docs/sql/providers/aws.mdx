## Aurora PostgreSQL and Drizzle

```typescript
const database = yield* AWS.RDS.Aurora("Database", {
  engine: "aurora-postgresql",
  databaseName: "app",
  subnetIds,
  securityGroupIds,
  dataApi: true,
  cluster: { enableIAMDatabaseAuthentication: true },
});
```

In a Lambda:

```typescript
const connect = yield* AWS.RDS.Connect(database.cluster, {
  auth: "iam",
  username: "app_iam",
  database: "app",
  subnetIds,
  securityGroupIds,
});
```

## Aurora DSQL

```typescript
const cluster = yield* AWS.DSQL.Cluster("Database", {
  deletionProtectionEnabled: false,
});
```

```typescript
const connect = yield* AWS.DSQL.Connect(cluster, {
  username: "app_user",
});
```

DSQL is separate from Aurora PostgreSQL. The example creates the database role during deployment, not from an HTTP endpoint.

[Drizzle integration](/aws/data/drizzle-dsql) · [Runnable example](https://github.com/alchemy-run/alchemy/tree/main/examples/aws-dsql-drizzle) · [Frontend + RPC](/aws/frontend/full-stack-tanstack-rpc-drizzle)

## RDS Data API

```typescript
const execute = yield* AWS.RDSData.ExecuteStatement(database.cluster, {
  secret: database.secret,
  database: "app",
});

yield* execute({ sql: "SELECT 1 AS value" });
```

This runs SQL over HTTPS, rather than opening a Drizzle connection.
