## Postgres

```typescript
import * as Railway from "alchemy/Railway";

const project = yield* Railway.Project("App");
const database = yield* Railway.Postgres("Database", { project });
```

In a Service:

```typescript
const connection = yield* Railway.ConnectPostgres(database);
const db = yield* Drizzle.Postgres(connection.connectionString);
```

Provide `Railway.ConnectPostgresHttp` on the Service. Private database hostnames are reachable inside Railway; external migration runners need the public endpoint.
