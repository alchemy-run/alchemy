---
title: Railway
description: Run Postgres or MySQL alongside a Railway Service and query it with Drizzle or Effect SQL.
---

Railway databases run as services with persistent volumes inside your project. Each database below is an independent example.

## Postgres

**Resources**

```typescript
import * as Railway from "alchemy/Railway";

const project = yield* Railway.Project("App");
const database = yield* Railway.Postgres("Database", { project });
```

**Binding — the runtime argument of `Railway.Service`**

```typescript
import * as Drizzle from "alchemy/Drizzle/Postgres";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/unstable/http/HttpServerResponse";
import { sql } from "drizzle-orm";

const runtime = Effect.gen(function* () {
  const connection = yield* Railway.ConnectPostgres(database);
  const db = yield* Drizzle.Postgres(connection.connectionString);
  return {
    fetch: Effect.gen(function* () {
      const rows = yield* db.execute(sql`select 1 as ok`);
      return yield* HttpServerResponse.json(rows);
    }).pipe(Effect.orDie),
  };
}).pipe(Effect.provide(Railway.ConnectPostgresHttp));
```

Use the same project and environment for the Service, with `build: { install: ["pg"] }`; the [Postgres deployment guide](/railway/data/drizzle-postgres) shows the complete host.

**Migrations — `drizzle.config.ts`**

```typescript
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "postgresql",
  schema: "./src/schema.ts",
  out: "./drizzle",
  dbCredentials: { url: process.env.DATABASE_URL! },
});
```

**Generate after a schema change, review, and commit**

```sh
pnpm exec drizzle-kit generate
git add src/schema.ts drizzle.config.ts drizzle
git diff --cached
git commit -m "Add schema migration"
```

**Apply committed migrations**

```sh
pnpm exec drizzle-kit migrate
```

After provisioning, set the runner's secret `DATABASE_URL` to `connectionUri` inside the Railway environment or `publicConnectionUri` for an external runner. Review the guide's [public TLS requirements](/railway/data/drizzle-postgres#review-public-tls); generated Postgres URLs currently disable certificate verification.

## MySQL

**Resources**

```typescript
import * as Railway from "alchemy/Railway";

const project = yield* Railway.Project("App");
const database = yield* Railway.MySQL("Database", { project });
```

**Binding — the runtime argument of `Railway.Service`**

```typescript
import * as Drizzle from "alchemy/Drizzle/MySQL";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/unstable/http/HttpServerResponse";
import { sql } from "drizzle-orm";

const runtime = Effect.gen(function* () {
  const connection = yield* Railway.ConnectMySQL(database);
  const db = yield* Drizzle.MySQL(connection.connectionString);
  return {
    fetch: Effect.gen(function* () {
      const rows = yield* db.execute(sql`select 1 as ok`);
      return yield* HttpServerResponse.json(rows);
    }).pipe(Effect.orDie),
  };
}).pipe(Effect.provide(Railway.ConnectMySQLHttp));
```

Use the same project and environment for the Service, with `build: { install: ["mysql2"] }`; the [MySQL deployment guide](/railway/data/drizzle-mysql) shows the complete host.

**Migrations — `drizzle.config.ts`**

```typescript
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mysql",
  schema: "./src/schema.ts",
  out: "./drizzle",
  dbCredentials: { url: process.env.DATABASE_URL! },
});
```

**Generate after a schema change, review, and commit**

```sh
pnpm exec drizzle-kit generate
git add src/schema.ts drizzle.config.ts drizzle
git diff --cached
git commit -m "Add schema migration"
```

**Apply committed migrations**

```sh
pnpm exec drizzle-kit migrate
```

After provisioning, use `connectionUri` within the Railway environment or `publicConnectionUri` externally, with verified TLS for public traffic. Railway's Postgres and MySQL resources have no `migrations` prop; apply committed SQL before deploying dependent queries, as described in the [migration workflow](/sql/drizzle/migrations).

See [Railway setup](/railway/setup), [Effect SQL on Postgres](/sql/effect-sql/postgres), and [Effect SQL on MySQL](/sql/effect-sql/mysql).
