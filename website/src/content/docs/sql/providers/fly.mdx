## Fly Managed Postgres

```typescript
import * as Fly from "alchemy/Fly";

const database = yield* Fly.Postgres("Database", {
  region: "iad",
  migrations: "./migrations",
});
```

In a Service:

```typescript
const connection = yield* Fly.ConnectPostgres(database);
const db = yield* Drizzle.Postgres(connection.connectionString);
```

Provide `Fly.ConnectPostgresHttp` on the Service. Deployment-time migrations need access to Fly's private network.
