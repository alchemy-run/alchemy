title: Databases
description: Create, configure, fork, and protect Turso databases.
---

A Turso database is a libSQL (SQLite-compatible) database inside a [group](/turso/data/groups).

## Create a database

```typescript
const group = yield* Turso.Group("Group", { location: "aws-us-east-1" });
const db = yield* Turso.Database("Db", { group: group.name });
```

`db.url` is the `libsql://` URL clients connect to. `db.hostname` and `db.httpUrl` are also available.

Moving a database to another group replaces it.

## Name it

```typescript
const db = yield* Turso.Database("Db", { group: group.name, name: "app" });
```

Without `name`, Alchemy generates one per stage. Database names are unique within your organization.

## Apply migrations

```typescript
const db = yield* Turso.Database("Db", {
  group: group.name,
  migrations: "./migrations",
});
```

See [Migrations](/turso/data/migrations).

## Fork another database

```typescript
const preview = yield* Turso.Database("Preview", {
  group: group.name,
  seed: { type: "database", name: db.name },
});
```

The new database starts as a copy of `db`, schema and rows. Add `timestamp` to fork from a point in time:

```typescript
seed: { type: "database", name: db.name, timestamp: "2026-10-07T12:00:00Z" },
```

`seed` only applies when the database is created.

## Block reads or writes

```typescript
const db = yield* Turso.Database("Db", {
  group: group.name,
  blockWrites: true,
});
```

Use `blockWrites` for a read-only maintenance window, and `blockReads` to take a database offline. Remove the prop and deploy to lift the block.

## Protect it from deletion

```typescript
const db = yield* Turso.Database("Db", {
  group: group.name,
  deleteProtection: true,
});
```

While protection is on, destroying the database fails. Set it to `false` and deploy first.

## Restrict network access

```typescript
const db = yield* Turso.Database("Db", {
  group: group.name,
  allowedIps: ["203.0.113.0/24"],
});
```

`allowedIps` and `allowedAwsVpcIds` require a paid Turso plan.

## Encrypt with your own key

```typescript
const db = yield* Turso.Database("Db", {
  group: group.name,
  encryption: {
    key: Redacted.make(process.env.DB_KEY!),
    cipher: "aes256gcm",
  },
});
```

The key is base64: 32 bytes for `aes256gcm`. Changing `encryption` replaces the database. Encryption requires a Pro or Enterprise plan.
