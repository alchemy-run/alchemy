---
title: Preview databases
description: Give every pull request its own Turso database, forked from staging.
---

Fork staging's database for every pull request. Each preview gets real data to test against and is deleted with its stage.

## Read the stage

```typescript
import * as Alchemy from "alchemy";

const { stage } = yield* Alchemy.Stack;
const preview = stage.startsWith("pr-");
```

## Reuse staging's group

```typescript
const group = preview
  ? yield* Turso.Group.ref("Group", { stage: "staging" })
  : yield* Turso.Group("Group", { location: "aws-us-east-1" });
```

`Turso.Group.ref` reads the group the `staging` stage deployed. Preview stages don't create or delete it.

## Fork staging's database

```typescript
const source = preview ? yield* Turso.Database.ref("Db", { stage: "staging" }) : undefined;

const db = yield* Turso.Database("Db", {
  group: group.name,
  seed: source ? { type: "database", name: source.name } : undefined,
  migrations: "./migrations",
});
```

Each preview stage creates its own copy of staging's database, then applies any migrations the pull request adds.

## Tear it down

```sh
alchemy destroy --stage pr-42
```

Destroying the preview stage deletes its database. Staging's group and database stay.
