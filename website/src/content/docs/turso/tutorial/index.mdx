Build a notes API where every customer (tenant) gets their own Turso database. A Worker creates each database by copying a template, then reads and writes notes with Drizzle.

The finished code is in [`examples/cloudflare-turso-drizzle`](https://github.com/alchemy-run/alchemy/tree/main/examples/cloudflare-turso-drizzle). The next pages build it one step at a time.

## Prerequisites

Finish [Turso setup](/turso/setup) and [Cloudflare setup](/cloudflare/setup). Turso's free plan is enough.

## Open the example

```diff lang="sh"
+cd examples/cloudflare-turso-drizzle
```

## Deploy

```diff lang="sh"
+pnpm alchemy deploy
```

Alchemy prints the Worker's `url` and the template database's name.

## Create two tenants

```diff lang="sh"
+curl -X POST $URL/tenants/acme
+curl -X POST $URL/tenants/globex
```

Each call creates a database with the tenant's name. Names must be unique in your Turso organization.

## Write a note

```diff lang="sh"
+curl -X POST $URL/tenants/acme/notes -d '{"body":"hello from acme"}'
+curl $URL/tenants/acme/notes
```

`acme` sees its note. `globex` has its own database, still empty:

```diff lang="sh"
+curl $URL/tenants/globex/notes
```
