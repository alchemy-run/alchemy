---
title: Query a tenant's notes
description: Read and write a tenant's notes with Drizzle.
---

Each request reads the tenant from the URL and only touches that tenant's database.

## Install the driver

```diff lang="sh"
+pnpm add drizzle-orm @effect/sql-libsql
```

## Connect to the tenant's database

```diff lang="typescript"
+import * as Drizzle from "alchemy/Drizzle/LibSQL";

if (resource === "notes") {
+  const db = yield* Drizzle.LibSQL(tenants.connect(tenant));
}
```

`tenants.connect(tenant)` returns the database's URL and a token. The connection opens on the first query and closes when the request ends.

## List notes

```diff lang="typescript"
case "GET": {
+  const notes = yield* db.select().from(Notes);
+  return yield* HttpServerResponse.json({ notes });
}
```

## Add a note

```diff lang="typescript"
case "POST": {
+  const { body } = (yield* request.json) as { body: string };
+  const [note] = yield* db.insert(Notes).values({ body }).returning();
+  return yield* HttpServerResponse.json({ note });
}
```

Notes for `acme` never show up for `globex`. They are in different databases.

## Deploy and try it

```diff lang="sh"
+pnpm alchemy deploy
+curl -X POST $URL/tenants/acme
+curl -X POST $URL/tenants/acme/notes -d '{"body":"hello"}'
+curl $URL/tenants/acme/notes
```

## Clean up

Delete the tenants you created, then destroy the Stack:

```diff lang="sh"
+curl -X DELETE $URL/tenants/acme
+pnpm alchemy destroy
```

This deletes the `Tenants` group and any tenant databases still in it.

:::note
If you change the schema later, the template gets the new migration but existing tenants don't. See [Database per tenant](/turso/guides/database-per-tenant#update-existing-tenants).
:::
