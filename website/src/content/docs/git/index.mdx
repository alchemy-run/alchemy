You want a git remote you control. Code that stays in your cloud.
Pushes gated by your rules, not a hosted service's roles. A product
built on repositories, where git is the storage and your app is the
face.

What exists is appliances. A binary you run on a box, or a service you
rent, configured through whatever knobs it exposes. And the parts of
hosting git that are hard, packs and deltas, ref updates that must not
race, connectivity checks, pushes larger than memory, are exactly the
parts you don't want to write.

`alchemy/Git` ships those parts as blocks. You assemble them in one
file, and the shape is yours:

```typescript
import * as Cloudflare from "alchemy/Cloudflare";
import * as Git from "alchemy/Git";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";

export const GitObjects = Cloudflare.R2.Bucket("GitObjects");

const GitLive = Git.ServerLive.pipe(
  Layer.provide(Git.ReposDurableObject), // refs, objects, pull requests
  Layer.provide(Git.RegistryDurableObject), // owner/name → repo
  Layer.provide(Git.BlobStoreR2(GitObjects)), // packs, bundles, large pushes
  Layer.provide(Git.HasherInline), // push verification
  Layer.provide(Git.AuthTokens), // who may read and write
);

export default Cloudflare.Worker(
  "Git",
  { main: import.meta.url, ...Git.GIT_WORKER_OPTIONS },
  Effect.gen(function* () {
    const git = yield* Git.Server;
    return { fetch: git.fetch };
  }).pipe(Effect.provide(GitLive)),
);
```

`bun alchemy deploy` and you have a host that speaks git's smart HTTP
to any client, a typed REST plane, pull requests, and a
GitHub-compatible API, on your Cloudflare account. Each line of the
graph is a decision. Change the line and the decision changes:

```diff lang="typescript"
const GitLive = Git.ServerLive.pipe(
  Layer.provide(Git.ReposDurableObject),
  Layer.provide(Git.RegistryDurableObject),
-  Layer.provide(Git.BlobStoreR2(GitObjects)),
+  Layer.provide(Git.BlobStoreS3({ bucket: "git-objects", region: "us-east-1" })),
  Layer.provide(Git.HasherInline),
-  Layer.provide(Git.AuthTokens),
+  Layer.provide(ProtectedMain),
);
```

Bytes now live in S3 and pushes to `main` need an admin. Nothing else
changed, and leaving a line out is a type error, not a 500 on your
first clone.

[git.alchemy.run](https://git.alchemy.run) is this file grown up. The
alchemy monorepo, 44,051 objects in a 67 MiB pack, is hosted on it, and
it clones back byte-identical under `git fsck --strict`.

## Not a GitHub replacement

No issues, reviews, comments, checks, Actions, or GraphQL. `gh api`
works. `gh pr create` and the rest of the porcelain do not. What it is:
a git remote you own, with an API, that you can build on.

Looking for the GitHub *provider*, which manages repos, Actions
secrets, and webhooks on github.com? That is [GitHub](/github).
