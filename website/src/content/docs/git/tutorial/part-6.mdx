The middleware decides who may push. Now add a rule about what an authorized
push may do: it may update `main`, but it may not delete it.

A Git push's ref changes are inside the protocol request. `Git.Hooks.preReceive`
runs after those changes have been parsed and before any refs move, so it can
inspect the proposed updates.

## Define the branch rule

Create `src/hooks.ts`:

```typescript
// src/hooks.ts
import * as Git from "alchemy/Git";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";

export const ProtectedMain = Layer.succeed(Git.Hooks, {
  preReceive: ({ updates }) =>
    Effect.succeed(
      updates
        .filter((update) =>
          update.ref === "refs/heads/main" && /^0+$/.test(update.newOid),
        )
        .map((update) => ({
          ref: update.ref,
          reason: "main cannot be deleted",
        })),
    ),
});
```

A deletion uses an all-zero `newOid`. The hook returns a reason for each rejected
ref; an empty array accepts the push. This rule allows creating and updating
`main`, and it allows deleting other branches.

## Supply the hook to Git's handlers

Import it:

```diff lang="typescript"
// src/git.ts
import { AppApiLive } from "./api.ts";
+import { ProtectedMain } from "./hooks.ts";
```

Provide the hook after the handler layer that consumes it:

```diff lang="typescript"
// src/git.ts
  Layer.provide(Git.ApiHandlersLive),
+  Layer.provide(ProtectedMain),
  Layer.provide(Git.ReposDurableObject),
```

The hook is optional. Providing this layer activates your rule for ref writes,
including Git pushes and the REST API.

## Verify an ordinary update

```sh
printf 'Main is protected from deletion.\n' >> work/README.md
git -C work commit -am "Document the branch rule"
git -c credential.helper= -C work push origin main
```

The push should succeed: updating `main` does not match the deletion rule.

## Verify that another branch can be deleted

```sh
git -c credential.helper= -C work push origin HEAD:feature
git -c credential.helper= -C work push origin --delete feature
```

Both operations should succeed.

## Verify that main cannot be deleted

```sh
git -c credential.helper= -C work push origin --delete main
```

Expect the push to be rejected with `main cannot be deleted`. Verify that the
remote still has the branch:

```sh
git -c credential.helper= -C work ls-remote origin refs/heads/main
```

It should print the current commit ID and `refs/heads/main`. Authentication
accepted the caller; the hook rejected the proposed change.
