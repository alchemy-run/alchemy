---
title: One origin
description: Your application and your git host on the same domain. A front-door Worker serves your app and forwards the git and API paths to the host over a service binding.
---

Clone URLs on your own domain, no CORS between your app and the REST
plane, and the git host still its own Worker. The front door is a
second Worker that forwards the git paths and serves your app for
everything else:

```typescript
// src/worker.ts
interface Env {
  GIT: { fetch(request: Request): Promise<Response> };
  ASSETS: { fetch(request: Request): Promise<Response> };
}

const API = /^\/api\/v[13]\//;
const WIRE = /^\/[^/]+\/[^/]+\/(?:info\/refs$|git-upload-pack$|git-receive-pack$)/;

export default {
  fetch(request: Request, env: Env): Promise<Response> {
    const { pathname } = new URL(request.url);
    if (API.test(pathname) || WIRE.test(pathname)) {
      return env.GIT.fetch(request);
    }
    return env.ASSETS.fetch(request);
  },
};
```

```typescript
// alchemy.run.ts
import * as Alchemy from "alchemy";
import * as Cloudflare from "alchemy/Cloudflare";
import * as Effect from "effect/Effect";
import GitHost from "./src/git.ts";

export default Alchemy.Stack(
  "GitService",
  { providers: Cloudflare.providers(), state: Cloudflare.state() },
  Effect.gen(function* () {
    const git = yield* GitHost;

    const web = yield* Cloudflare.Website.Vite("Web", {
      main: "src/worker.ts",
      domain: "git.example.com",
      assets: {
        notFoundHandling: "single-page-application",
        runWorkerFirst: true,
      },
      env: { GIT: GitHost },
    });

    return { url: git.url.as<string>(), webUrl: web.url };
  }),
);
```

`env: { GIT: GitHost }` is a service binding. The request crosses to
the git host inside Cloudflare, with its `Host` header intact, so the
host derives same-domain clone URLs and a push body streams through
untouched.

## What to forward

Two families of paths belong to the host:

| Paths | Plane |
| --- | --- |
| `/:owner/:repo.git/info/refs`, `/:owner/:repo.git/git-upload-pack`, `/:owner/:repo.git/git-receive-pack` | git wire |
| `/api/v1/**`, `/api/v3/**` | REST and the GitHub facade |

Forward them verbatim. A proxy that buffers request bodies breaks
streaming pushes, and one that rewrites `Host` makes the host print
clone URLs for the wrong domain.

## The git host stays private

`GitHost` needs no route of its own. Leave it on its `workers.dev`
address or disable that too, and the service binding is the only way
in. Your front door is where you add what the host does not have:
sessions, a UI, rate limits. [Build on it](/git/build) continues from
here.
