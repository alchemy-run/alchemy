title: Setup
description: Deploy a git host to Cloudflare and push your first repository.
---

You need a Cloudflare account with Workers, Durable Objects, and R2
enabled. [Cloudflare setup](/cloudflare/setup) connects one.

## Install

```sh
bun add alchemy
```

## Define the host

```typescript
// src/git.ts
import * as Cloudflare from "alchemy/Cloudflare";
import * as Git from "alchemy/Git";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";

export const GitObjects = Cloudflare.R2.Bucket("GitObjects");

const GitLive = Git.ServerLive.pipe(
  Layer.provide(Git.ReposDurableObject),
  Layer.provide(Git.RegistryDurableObject),
  Layer.provide(Git.BlobStoreR2(GitObjects)),
  Layer.provide(Git.HasherInline),
  Layer.provide(Git.PolicyOwners),
  Layer.provide(Git.AuthenticatedSecret({ principal: { id: "acme" } })),
);

export default class GitHost extends Cloudflare.Worker<GitHost>()(
  "Git",
  { main: import.meta.url, ...Git.GIT_WORKER_OPTIONS },
  Effect.gen(function* () {
    const git = yield* Git.Server;
    return { fetch: git.fetch };
  }).pipe(Effect.provide(GitLive)),
) {}
```

`GIT_WORKER_OPTIONS` sets the compatibility flags and the CPU limit a
push needs. `AuthenticatedSecret` is the smallest thing that secures a
fresh host: one shared secret, and whoever presents it is the principal
`acme`, who owns the repositories it creates.

Add it to your stack:

```typescript
// alchemy.run.ts
import * as Alchemy from "alchemy";
import * as Cloudflare from "alchemy/Cloudflare";
import * as Effect from "effect/Effect";
import GitHost from "./src/git.ts";

export default Alchemy.Stack(
  "GitService",
  { providers: Cloudflare.providers(), state: Cloudflare.state() },
  Effect.gen(function* () {
    const git = yield* GitHost;
    return { url: git.url.as<string>() };
  }),
);
```

## Set the secret

`AuthenticatedSecret` reads `GIT_SERVICE_SECRET` at deploy time and
binds it to the Worker as a secret:

```sh
export GIT_SERVICE_SECRET="$(openssl rand -base64 32)"
```

## Deploy

```sh
bun alchemy deploy
```

The stack prints the Worker's URL. The rest of this page calls it
`$HOST`.

## Create a repository

```sh
curl -X POST "$HOST/api/v1/repos" \
  -H "Authorization: Bearer $GIT_SERVICE_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"owner":"acme","name":"web","public":true}'
```

## Push

The secret goes in the password field of the remote URL. The username
is ignored:

```sh
git remote add origin "https://x:$GIT_SERVICE_SECRET@$HOST/acme/web.git"
git push -u origin main
```

Clone it back to prove the round trip. The repository is public, so
this needs no credentials:

```sh
git clone "https://$HOST/acme/web.git" verify
git -C verify fsck --strict
```
