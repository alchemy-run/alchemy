`Git.Server` is the composed HTTP surface behind one `fetch`, and
`ServerLive` is its default composition:

```typescript
export default Cloudflare.Worker(
  "Git",
  { main: import.meta.url, ...Git.GIT_WORKER_OPTIONS },
  Effect.gen(function* () {
    const git = yield* Git.Server;
    return { fetch: git.fetch };
  }).pipe(Effect.provide(GitLive)),
);
```

It is not a Worker. You write the Worker, so you choose its name, its
domain, its compatibility date, and what else runs beside it. And
`ServerLive` is not the only way in: every plane it composes is
exported on its own.

## Three planes

| Path | Plane | Client |
| --- | --- | --- |
| `/:owner/:repo.git/info/refs`, `git-upload-pack`, `git-receive-pack` | git smart HTTP | `git` |
| `/api/v1/**` | REST, an Effect `HttpApi` | your code, `curl`, the typed client |
| `/api/v3/**` | GitHub REST v3 facade | `gh api`, Octokit |

## The pieces

**`Git.Api`** is the REST plane as an `HttpApi`: the `repos`, `refs`,
`objects`, and `pulls` groups under `/api/v1`, with no middleware of
their own. Derive your API from it and apply yours:

```typescript
export const AppApi = Git.Api.add(Me).middleware(Session);
```

**`Git.handlers(api)`** implements the git groups of an API derived
from `Git.Api`. Its requirements are the middleware you applied, so
the compiler asks for `Session`'s implementation:

```typescript
Layer.provide(Git.handlers(AppApi).pipe(Layer.provide(SessionLive)))
```

**`Git.WireRoutes`** is the git wire protocol plus the push pipeline's
internal hash route, **`Git.RawRoutes`** the streaming blob and file
reads under `/api/v1`, and **`Git.GithubRoutes`** the facade under
`/api/v3`. They are `HttpRouter` Layers merged beside the API, and
they resolve the caller through `Git.Authenticate` because a `git`
client can only send HTTP Basic:

```typescript
const api = yield* HttpApiBuilder.layer(AppApi).pipe(
  Layer.provide(Git.handlers(AppApi).pipe(Layer.provide(SessionLive))),
  Layer.provide(MeLive.pipe(Layer.provide(SessionLive))),
  Layer.merge(Git.WireRoutes),
  Layer.merge(Git.RawRoutes),
  Layer.merge(Git.GithubRoutes),
  Layer.provide(AuthenticateLive),
  Layer.provide([Etag.layer, HttpPlatformStub, Path.layer]),
  HttpRouter.toHttpEffect,
);
```

`HttpPlatformStub` is the same stand-in the
[Effect HTTP API](/cloudflare/apis/effect-http-api) guide uses, since
Workers have no filesystem. [Part 3 of the tutorial](/git/tutorial/part-3)
builds this composition from the ground up.

**`Git.ServerLive`** is the composition above with the default
middleware, `Git.Authenticated`, which bridges `Authenticate` into
`Caller` so one implementation serves every plane. Provide it and
`Authenticate`, and `git.fetch` is the whole host.

All of the pieces share one core per Worker: the registry cache, the
Durable Object stubs, and the push admission gate are built once
however many of them you merge.

## Worker options

```typescript
{ main: import.meta.url, ...Git.GIT_WORKER_OPTIONS }
```

`nodejs_compat` for zlib and crypto, a 300 s CPU ceiling so a large
push can be verified, and a service binding to the Worker itself for
the hasher. Spread it first and put your own options after it.

## Under your own routes

`git.fetch` is an Effect that reads the request from context and
returns a response, so it composes with anything else you serve:

```typescript
Effect.gen(function* () {
  const git = yield* Git.Server;

  return {
    fetch: Effect.gen(function* () {
      const request = yield* HttpServerRequest.HttpServerRequest;
      if (request.url === "/healthz") {
        return HttpServerResponse.text("ok");
      }
      return yield* git.fetch;
    }),
  };
});
```

To put a whole application on the same domain, keep the git host as
its own Worker and forward the git paths to it over a service binding.
[Part 3 of the tutorial](/git/tutorial/part-3) shows the front door.

## The typed client

The REST plane is declared as `GitApi`, so the same schema types the
server, the client, and your tests:

```typescript
import { GitApi } from "alchemy/Git";
import * as HttpApiClient from "effect/unstable/httpapi/HttpApiClient";

const client = yield* HttpApiClient.make(GitApi, { baseUrl: host });

const repo = yield* client.repos.get({
  params: { owner: "acme", repo: "web" },
});
```

[Repositories](/git/repositories) and [Pull requests](/git/pull-requests)
use it throughout.
