---
title: Buckets
description: Prisma Buckets provision S3-compatible object storage inside a project, and Bucket Keys mint the S3 credentials — access key, one-time secret, endpoint, and the provider-side bucket name.
---

A `Prisma.Bucket` is an Object Store bucket inside a Prisma
project. A `Prisma.BucketKey` is an access key for one bucket and
yields the S3 credentials your app connects with.

```typescript
import * as Prisma from "alchemy/Prisma";

const bucket = yield* Prisma.Bucket("uploads", {
  project,
  name: "uploads",
});

const key = yield* Prisma.BucketKey("uploads-key", {
  bucket,
  role: "read_write",
});
```

## Bucket key outputs

```typescript
key.accessKeyId; //     S3 access key ID
key.secretAccessKey; // S3 secret, Redacted — returned once at creation
key.endpoint; //        S3-compatible endpoint URL
key.bucketName; //      provider-side S3 bucket name (e.g. user-<id>)
```

Prisma returns `secretAccessKey` exactly once, in the create
response. Alchemy persists it `Redacted` in state and never re-reads
it from the API, so keep your state store somewhere durable.

S3 clients must use `key.bucketName` — the provider-side name — as
the bucket, not the friendly display name you chose on the bucket:

```typescript
const app = yield* Prisma.Compute("api", {
  project,
  path: "./app",
  env: {
    S3_ENDPOINT: key.endpoint,
    S3_BUCKET: key.bucketName,
    S3_ACCESS_KEY_ID: key.accessKeyId,
    S3_SECRET_ACCESS_KEY: key.secretAccessKey,
  },
});
```

## Roles

A key's `role` is `"read"` or `"read_write"` and is fixed at
creation — changing it (or the key's name or bucket) replaces the
key and mints fresh credentials.

## Deletion

Destroying a bucket deletes its objects and revokes any remaining
keys server-side. A `Prisma.BucketKey` destroyed after its bucket
tolerates the already-revoked key.

## Branch-scoped buckets

Pass `branchId` to scope a bucket to a branch, e.g. for per-preview
storage:

```typescript
const previewBucket = yield* Prisma.Bucket("preview-uploads", {
  project,
  branchId: preview.branchId,
});
```
