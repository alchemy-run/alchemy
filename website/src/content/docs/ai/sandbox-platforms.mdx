An [`AI.Sandboxes`](/ai/sandboxes) Layer maps a key to a sandbox on one platform. The platforms differ in two ways that matter here: how a sandbox is found again by its key, and what stopping one keeps. These Layers are the ones the [cloudflare-pi example](https://github.com/alchemy-run/alchemy/tree/main/examples/cloudflare-pi) runs.

## E2B

E2B finds a sandbox by its metadata and pauses it on `suspend`, keeping its memory and files. It kills a sandbox left running for ten minutes.

```typescript title="src/sandboxes/E2B.ts"
import * as AI from "@alchemy.run/ai";
import * as E2B from "@alchemy.run/e2b";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";

export const E2BSandbox = Layer.effect(
  AI.Sandboxes,
  Effect.gen(function* () {
    const base = yield* E2B.Template("E2BBase", { image: "node:22-bookworm" });
    const sandboxes = yield* E2B.CreateSandbox(base);
    const find = (key: string) =>
      sandboxes.list({ metadata: { key }, state: ["running", "paused"] });

    return {
      open: Effect.fn(function* (key) {
        const [existing] = yield* find(key);
        return existing
          ? yield* sandboxes.connect(existing.sandboxID, { timeout: 600 })
          : yield* sandboxes.create({ metadata: { key }, timeout: 600 });
      }),
      suspend: Effect.fn(function* (key) {
        const [existing] = yield* find(key);
        if (existing?.state !== "running") return;
        const sandbox = yield* sandboxes.connect(existing.sandboxID);
        yield* sandbox.pause();
      }),
      remove: Effect.fn(function* (key) {
        const found = yield* find(key);
        yield* Effect.forEach(found, (sandbox) => sandboxes.kill(sandbox.sandboxID));
      }),
    };
  }),
).pipe(Layer.provide(E2B.CreateSandboxHttp));
```

See [E2B sandboxes](/e2b/sandboxes).

## Daytona

Daytona finds a sandbox by its name and stops it on `suspend`, keeping its disk. It stops a sandbox idle for fifteen minutes and deletes one that has been stopped for a day.

```typescript title="src/sandboxes/Daytona.ts"
import * as AI from "@alchemy.run/ai";
import * as Daytona from "@alchemy.run/daytona";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";

export const DaytonaSandbox = Layer.effect(
  AI.Sandboxes,
  Effect.gen(function* () {
    const base = yield* Daytona.Snapshot("DaytonaBase", {
      image: "node:22-bookworm",
      cpu: 1,
      memory: 1,
      disk: 3,
    });
    const sandboxes = yield* Daytona.CreateSandbox(base);

    return {
      open: Effect.fn(function* (key) {
        const existing = yield* sandboxes.get(key);
        if (existing === undefined) {
          return yield* sandboxes.create({
            name: key,
            autoStopInterval: 15,
            autoDeleteInterval: 24 * 60,
          });
        }
        yield* existing.startSandbox();
        return existing;
      }),
      suspend: Effect.fn(function* (key) {
        const existing = yield* sandboxes.get(key);
        if (existing === undefined) return;
        const { state } = yield* existing.getSandbox();
        if (state === "started") yield* existing.stopSandbox();
      }),
      remove: (key) => sandboxes.delete(key),
    };
  }),
).pipe(Layer.provide(Daytona.CreateSandboxHttp));
```

See [Daytona sandboxes](/daytona/sandboxes/sandboxes).

## Modal

Modal finds a sandbox by its name. It has no pause, so `suspend` does nothing: Modal ends a sandbox idle for ten minutes, and the next `open` creates an empty one.

```typescript title="src/sandboxes/Modal.ts"
import * as AI from "@alchemy.run/ai";
import * as Modal from "@alchemy.run/modal";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";

export const ModalSandbox = Layer.effect(
  AI.Sandboxes,
  Effect.gen(function* () {
    const app = yield* Modal.App("ModalApp", {});
    const base = yield* Modal.Image("ModalBase", { app, image: "node:22-bookworm" });
    const sandboxes = yield* Modal.CreateSandbox(base);

    return {
      open: Effect.fn(function* (key) {
        return (
          (yield* sandboxes.fromName(key)) ??
          (yield* sandboxes.create({ name: key, idleTimeout: "10 minutes" }))
        );
      }),
      suspend: () => Effect.void,
      remove: Effect.fn(function* (key) {
        const sandbox = yield* sandboxes.fromName(key);
        if (sandbox !== undefined) yield* sandbox.terminate();
      }),
    };
  }),
).pipe(Layer.provide(Modal.CreateSandboxHttp));
```

See [Modal sandboxes](/modal/sandboxes/sandboxes).

## Archil

Archil finds a sandbox by its name: `create` returns the one that already has it. `suspend` pauses a running sandbox, keeping its memory and files. Archil also pauses a sandbox that is idle, and resumes it on the next command.

```typescript title="src/sandboxes/Archil.ts"
import * as AI from "@alchemy.run/ai";
import * as Archil from "@alchemy.run/archil";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";

export const ArchilSandbox = Layer.effect(
  AI.Sandboxes,
  Effect.gen(function* () {
    const base = yield* Archil.Image("ArchilBase", { image: "node:22-bookworm" });
    const sandboxes = yield* Archil.CreateSandbox(base);

    return {
      open: (key) => sandboxes.create({ name: key }),
      suspend: Effect.fn(function* (key) {
        const sandbox = yield* sandboxes.get(key);
        if (sandbox === undefined) return;
        const { status } = yield* sandbox.refresh();
        if (status === "running") yield* sandbox.pause();
      }),
      remove: (key) => sandboxes.delete(key),
    };
  }),
).pipe(Layer.provide(Archil.CreateSandboxHttp));
```

See [Archil sandboxes](/archil/compute/sandboxes).

## What the image needs

A harness installs its own program in each new sandbox: Pi its daemon, OpenCode itself. The image needs `sh`, `curl`, `tar`, `sha512sum`, `base64`, `dd` and `mkfifo`, and the sandbox needs to reach `registry.npmjs.org` for that install. `node:22-bookworm` has them all, and so does Boat's own image.
