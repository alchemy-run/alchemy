---
title: Connect a front end
description: Record a session into your Domain model, so a front end sends commands and follows the agent's status and transcript through one Api. Or serve a session over an RPC interface of your own.
---

A front end needs two things from a session: a live view of what it does, and a way to act on it. The way that needs nothing new is to make the session part of your [Domain model](/ai/domain). The front end then talks to one Api: it sends commands, and watches the agent's status and transcript like any other view and stream.

The code is from the [`cloudflare-ai-issues`](https://github.com/alchemy-run/alchemy/tree/main/examples/cloudflare-ai-issues) example, which has a web page for an issue.

## Record what the session does

One command carries a batch of what a session reported: its status, what is queued, and the items it stored. `@alchemy.run/ai/Session` has the Schemas.

```typescript title="src/Board/RecordActivity.command.ts"
import { QueuedMessage, SessionEntry } from "@alchemy.run/ai/Session";
import * as Domain from "@alchemy.run/domain";
import * as Schema from "effect/Schema";
import { IssueId } from "./Issue.id.ts";

export const Status = Schema.Literals(["idle", "working"]);

/** What an issue's session did since the last record: where it stands, and the items it stored. */
export class ActivityRecorded extends Domain.Event("ActivityRecorded", {
  status: Status,
  queued: Schema.Array(QueuedMessage),
  items: Schema.Array(SessionEntry),
}) {}

/** Sent by the object that runs the session, with a batch of what the session reported. */
export class RecordActivity extends Domain.Command("RecordActivity", {
  input: {
    issueId: IssueId,
    status: Status,
    queued: Schema.Array(QueuedMessage),
    items: Schema.Array(SessionEntry),
  },
  events: [ActivityRecorded],
  rejects: [],
}) {}
```

An aggregate decides it. It drops the items it already has, so a batch sent twice changes nothing:

```typescript title="src/Board/IssueSession.aggregate.ts"
import { QueuedMessage } from "@alchemy.run/ai/Session";
import * as Domain from "@alchemy.run/domain";
import * as Schema from "effect/Schema";
import { IssueId } from "./Issue.id.ts";
import { ActivityRecorded, RecordActivity, Status } from "./RecordActivity.command.ts";

const sameQueue = (a: ReadonlyArray<QueuedMessage>, b: ReadonlyArray<QueuedMessage>) =>
  a.length === b.length && a.every((message, index) => message.id === b[index]!.id);

/**
 * The session that looks after one issue, as the board knows it: what the
 * session's object has recorded of it so far.
 */
export class IssueSession extends Domain.Aggregate("IssueSession", {
  id: IssueId,
  state: Schema.Struct({
    /** The last item recorded. */
    seq: Schema.Number,
    status: Status,
    queued: Schema.Array(QueuedMessage),
  }),
  initial: { seq: 0, status: "idle", queued: [] },
  commands: [RecordActivity],
  keyOf: (command) => command.issueId,
  decide: {
    // Items already recorded are dropped, so a batch sent again changes nothing.
    RecordActivity: (session, command) => {
      const items = command.items.filter((entry) => entry.seq > session.seq);
      const changed =
        command.status !== session.status || !sameQueue(command.queued, session.queued);
      return items.length === 0 && !changed
        ? []
        : [new ActivityRecorded({ status: command.status, queued: command.queued, items })];
    },
  },
  evolve: {
    ActivityRecorded: (session, event) => ({
      seq: event.items.at(-1)?.seq ?? session.seq,
      status: event.status,
      queued: event.queued,
    }),
  },
}) {}
```

## Keep the transcript as a stream

Each item is one entry of a stream, so a page reads what it missed and then follows:

```typescript title="src/Board/Transcript.stream.ts"
import { SessionEntry } from "@alchemy.run/ai/Session";
import * as Domain from "@alchemy.run/domain";
import { IssueSession } from "./IssueSession.aggregate.ts";

/** One item of the transcript: a message, a tool call or a tool result. */
export class ItemStored extends Domain.Event("ItemStored", SessionEntry.fields) {}

/** The session's transcript, one entry per item. */
export class Transcript extends Domain.Stream("Transcript", {
  key: IssueSession,
  entries: [ItemStored],
}) {}
```

A projection appends them:

```typescript title="src/Board/Transcripts.projection.ts"
import * as Domain from "@alchemy.run/domain";
import * as Effect from "effect/Effect";
import { IssueSession } from "./IssueSession.aggregate.ts";
import { ActivityRecorded } from "./RecordActivity.command.ts";
import { ItemStored, Transcript } from "./Transcript.stream.ts";

/** Appends each recorded item to the transcript. */
export class Transcripts extends Domain.Projection("Transcripts", {
  from: [IssueSession],
  key: IssueSession,
  on: [ActivityRecorded],
  writes: [Transcript],
}) {}

export const TranscriptsLive = Transcripts.toLayer(
  Effect.gen(function* () {
    const transcript = yield* Transcript;
    return Effect.fn(function* (batch) {
      for (const input of batch) {
        yield* transcript.append(input, ...input.event.items.map((entry) => new ItemStored(entry)));
      }
    });
  }),
);
```

## Record from the session's object

The object that runs the session reads its events and sends them to the model. `live` follows the session from the last item the model has. `catchUp` records everything stored that the model lacks, and says whether the session is done:

```typescript
/** Send the board a batch of what the session reported. */
const report = (
  issue: IssueId,
  status: AI.SessionEvent & { type: "status" },
  items: ReadonlyArray<AI.SessionEntry>,
) =>
  sessions.send(
    new RecordActivity({ issueId: issue, status: status.status, queued: status.queued, items }),
  );

/**
 * Record the session as it happens: every event after the last item the
 * board has, a batch at a time. It runs for as long as this instance does.
 */
const live = Effect.fn(function* (issue: IssueId) {
  const recorded = yield* sessions.get(IssueSession.ref(issue));
  let status: AI.SessionEvent & { type: "status" } = {
    type: "status",
    status: recorded.status,
    queued: recorded.queued,
  };
  yield* triage
    .get(issue)
    .events({ after: recorded.seq })
    .pipe(
      Stream.groupedWithin(50, "100 millis"),
      Stream.runForEach((batch) => {
        const events = Array.from(batch);
        status = events.findLast((event) => event.type === "status") ?? status;
        return report(
          issue,
          status,
          events.flatMap((event) =>
            event.type === "item" ? [{ seq: event.seq, item: event.item }] : [],
          ),
        );
      }),
    );
});

/**
 * Record everything the session has stored that the board lacks, and say
 * whether the session is done: idle, with nothing queued.
 */
const catchUp = Effect.fn(function* (issue: IssueId) {
  const session = triage.get(issue);
  const status = Option.getOrUndefined(yield* Stream.runHead(session.events()));
  if (status?.type !== "status") return true;
  let after = (yield* sessions.get(IssueSession.ref(issue))).seq;
  while (true) {
    const page = yield* session.history({ after, take: 100 });
    yield* report(issue, status, page.items);
    if (page.next === undefined) break;
    after = page.next;
  }
  return status.status === "idle" && status.queued.length === 0;
});
```

## Keep recording through an eviction

`live` runs in memory, so it ends when the object is evicted. A job on the object's alarm makes recording durable. It is stored with the object, wakes it, records what the model lacks, and comes back every five seconds until the session is idle:

```typescript
let recording = false;
/** Start recording live, once for as long as this instance lives. */
const follow = (issue: IssueId) =>
  Effect.suspend(() => {
    if (recording) return Effect.void;
    recording = true;
    return state.waitUntil(
      live(issue).pipe(Effect.ensuring(Effect.sync(() => void (recording = false)))),
    );
  });

/**
 * What makes recording durable: a job on the object's alarm, kept in
 * its storage. It wakes the object, records what the board lacks, and
 * comes back until the session is done, however often the object is
 * evicted in between.
 */
const again = (issue: IssueId): Effect.Effect<void, never, RuntimeContext> =>
  onRecord.schedule(issue, { after: "5 seconds", payload: issue }).pipe(Effect.orDie);
const onRecord: Alchemy.Callback<IssueId> = yield* Alchemy.makeCallback(
  "record",
  Effect.fn(function* (issue: IssueId) {
    yield* follow(issue);
    if (!(yield* catchUp(issue))) yield* again(issue);
  }, Effect.orDie),
);
/** Record from now until the session is done. */
const record = (issue: IssueId) => Effect.andThen(follow(issue), again(issue));

return {
  // The same id however often the event is delivered, so the issue is taken up once.
  start: (issue) =>
    triage
      .get(issue)
      .send(`The issue is ${issue}.`, { requestId: "start" })
      .pipe(Effect.andThen(record(issue)), Effect.orDie),
  tell: (issue, text, id) =>
    triage
      .get(issue)
      .send(text, { requestId: id })
      .pipe(Effect.andThen(record(issue)), Effect.orDie),
} satisfies Agent;
```

The harness already resumes the session itself after an eviction. This job is what makes the model catch up with it.

## Act on the session with commands

A page does not call the session. It sends a command, and the model's policy passes it on through a port, as in [Processes and Domain models](/ai/domain#let-a-policy-ask-for-the-work). Here a reply on an issue is `CommentOnIssue`, and the policy tells the issue's session. A session that is working queues it.

## Read it in a Foldkit app

`DomainFoldkit.make` gives a Command for each command of the Api, and `watch` and `events` for each view and stream. The page keeps the status, the queue and the transcript in its Model:

```typescript title="web/src/Issue.ts"
import { QueuedMessage, SessionEntry } from "@alchemy.run/ai/Session";
import type * as Domain from "@alchemy.run/domain";
import * as DomainFoldkit from "@alchemy.run/domain/Foldkit";
import * as Option from "effect/Option";
import * as Schema from "effect/Schema";
import { Command, Subscription, type Update } from "foldkit";
import type { Document, HtmlBuilder } from "foldkit/html";
import { defineMessageUnion } from "foldkit/message";
import { modifyFields } from "foldkit/struct";
import { IssueId } from "../../src/Board/Issue.id.ts";
import { Label } from "../../src/Board/LabelIssue.command.ts";
import { Status } from "../../src/Board/RecordActivity.command.ts";
import { WebApi } from "../../src/Board/WebApi.api.ts";

type Board = Domain.Api.ClientKey<"WebApi">;
/** One Command per command of the Api, and a read namespace per view and stream. */
export const BoardClient = DomainFoldkit.make(WebApi);

// MODEL

export const Flags = Schema.Struct({ issueId: IssueId, page: Schema.String });
export type Flags = typeof Flags.Type;

export const Model = Schema.Struct({
  issueId: IssueId,
  commandIds: DomainFoldkit.CommandIds,
  draft: Schema.String,
  /** The issue, once it is reported. */
  title: Schema.Option(Schema.String),
  label: Schema.Option(Label),
  /** Whether the issue's session is working, and what is queued for it. */
  status: Status,
  queued: Schema.Array(QueuedMessage),
  /** The session's transcript so far, and where to resume reading it. */
  items: Schema.Array(SessionEntry),
  cursor: Schema.Option(Schema.Number),
  error: Schema.Option(Schema.String),
});
export type Model = typeof Model.Type;

// MESSAGE

export const Message = defineMessageUnion({
  ChangedDraft: { text: Schema.String },
  ClickedReport: {},
  ClickedReply: {},
  ReceivedBoardResult: { result: BoardClient.Message },
  ReceivedIssue: { title: Schema.Option(Schema.String), label: Schema.Option(Label) },
  ReceivedStatus: { status: Status, queued: Schema.Array(QueuedMessage) },
  ReceivedItem: { entry: SessionEntry, cursor: Schema.Number },
  CaughtUpTranscript: { cursor: Schema.Number },
  FailedRead: { reason: Schema.String },
});
export type Message = typeof Message.Type;

// UPDATE

type Return = Update.Return<Model, Message, Board>;

/** Send one command of the Api, named so that a retry is not run twice. */
const send = (
  model: Model,
  command: (commandId: string) => Command.Command<typeof BoardClient.Message.Type, never, Board>,
): Return => {
  const { commandId, commandIds } = DomainFoldkit.next(model.commandIds);
  return {
    model: modifyFields(model, {
      commandIds: () => commandIds,
      draft: () => "",
      error: () => Option.none(),
    }),
    commands: [
      Command.mapMessage(command(commandId), (result) => Message.ReceivedBoardResult({ result })),
    ],
  };
};

export const update = (model: Model, message: Message) =>
  Message.match<Return>(message, {
    ChangedDraft: ({ text }) => ({ model: modifyFields(model, { draft: () => text }) }),
    // Reporting the issue is what starts its session: the board's policy does that.
    ClickedReport: () =>
      send(model, (commandId) =>
        BoardClient.ReportIssue({
          input: { issueId: model.issueId, title: model.draft, body: "" },
          commandId,
        }),
      ),
    // A reply is passed to the session by the same policy. A working session queues it.
    ClickedReply: () =>
      send(model, (commandId) =>
        BoardClient.CommentOnIssue({
          input: { issueId: model.issueId, commentId: commandId, body: model.draft },
          commandId,
        }),
      ),
    ReceivedBoardResult: ({ result }) => ({
      model:
        result._tag === "FailedReportIssue" || result._tag === "FailedCommentOnIssue"
          ? modifyFields(model, { error: () => Option.some(result.failure._tag) })
          : model,
    }),
    ReceivedIssue: ({ title, label }) => ({
      model: modifyFields(model, { title: () => title, label: () => label }),
    }),
    ReceivedStatus: ({ status, queued }) => ({
      model: modifyFields(model, { status: () => status, queued: () => queued }),
    }),
    ReceivedItem: ({ entry, cursor }) => ({
      model: modifyFields(model, {
        items: (items) => [...items, entry],
        cursor: () => Option.some(cursor),
      }),
    }),
    CaughtUpTranscript: ({ cursor }) => ({
      model: modifyFields(model, { cursor: () => Option.some(cursor) }),
    }),
    FailedRead: ({ reason }) => ({
      model: modifyFields(model, { error: () => Option.some(reason) }),
    }),
  });

// INIT

export const init = (flags: Flags): Return => ({
  model: Model.make({
    issueId: flags.issueId,
    commandIds: { session: flags.page, sent: 0 },
    draft: "",
    title: Option.none(),
    label: Option.none(),
    status: "idle",
    queued: [],
    items: [],
    cursor: Option.none(),
    error: Option.none(),
  }),
});

// SUBSCRIPTION

export const subscriptions = Subscription.make<Model, Message, Board>()(() => ({
  issue: BoardClient.IssueDetail.watch({
    key: (model: Model) => model.issueId,
    toMessage: ({ state }): Message =>
      Message.ReceivedIssue({
        title: Option.map(state, (detail) => detail.title),
        label: Option.flatMap(state, (detail) => Option.fromNullishOr(detail.label)),
      }),
    onFailure: (error): Message => Message.FailedRead({ reason: error._tag }),
    onDefect: (): Message => Message.FailedRead({ reason: "Read defect" }),
  }),
  status: BoardClient.SessionStatus.watch({
    key: (model: Model) => model.issueId,
    toMessage: ({ state }): Message =>
      Message.ReceivedStatus(
        Option.getOrElse(state, () => ({ status: "idle" as const, queued: [] })),
      ),
    onFailure: (error): Message => Message.FailedRead({ reason: error._tag }),
    onDefect: (): Message => Message.FailedRead({ reason: "Read defect" }),
  }),
  transcript: BoardClient.Transcript.events({
    key: (model: Model) => model.issueId,
    cursor: (model) => model.cursor,
    onEntry: ({ event, envelope }): Message =>
      Message.ReceivedItem({ entry: { seq: event.seq, item: event.item }, cursor: envelope.seq }),
    onCaughtUp: (cursor): Message => Message.CaughtUpTranscript({ cursor }),
    onFailure: (error): Message => Message.FailedRead({ reason: error._tag }),
    onDefect: (): Message => Message.FailedRead({ reason: "Read defect" }),
  }),
}));

// VIEW

const itemView = ({ seq, item }: SessionEntry, h: HtmlBuilder<Message>) =>
  h.keyed("li")(
    String(seq),
    [],
    [
      item.type === "user"
        ? `You: ${item.text}`
        : item.type === "tool"
          ? `${item.name} answered: ${item.output}`
          : item.toolCalls.length > 0
            ? `Calls ${item.toolCalls.map((call) => call.name).join(", ")}`
            : `Agent: ${item.text}`,
    ],
  );

export const view = (model: Model, h: HtmlBuilder<Message>): Document => {
  const reported = Option.isSome(model.title);
  return {
    title: Option.getOrElse(model.title, () => "New issue"),
    body: h.div(
      [],
      [
        h.h1([], [Option.getOrElse(model.title, () => `Issue ${model.issueId}`)]),
        h.p([], [`Label: ${Option.getOrElse(model.label, () => "none yet")}`]),
        h.p([], [model.status === "working" ? "The agent is working" : "The agent is idle"]),
        h.ul(
          [],
          model.items.map((entry) => itemView(entry, h)),
        ),
        h.ul(
          [],
          model.queued.map((message) => h.keyed("li")(message.id, [], [`Queued: ${message.text}`])),
        ),
        h.input([h.Value(model.draft), h.OnInput((text) => Message.ChangedDraft({ text }))]),
        reported
          ? h.button([h.OnClick(Message.ClickedReply())], ["Reply"])
          : h.button([h.OnClick(Message.ClickedReport())], ["Report this issue"]),
        h.p([], [Option.getOrElse(model.error, () => "")]),
      ],
    ),
  };
};
```

The client is provided once, on the app's own origin:

```typescript title="web/src/entry.ts"
import * as Domain from "@alchemy.run/domain";
import * as Effect from "effect/Effect";
import * as FetchHttpClient from "effect/http/FetchHttpClient";
import * as Layer from "effect/Layer";
import * as Socket from "effect/socket/Socket";
import { Runtime } from "foldkit";
import { WebApi } from "../../src/Board/WebApi.api.ts";
import { Flags, init, Model, subscriptions, update, view } from "./Issue.ts";
import { issueOf } from "./Location.ts";

/**
 * The board's Api for the life of the app. Commands go over HTTP. Each live
 * read is a WebSocket to the Durable Object that owns what it reads.
 */
const BoardConnection = WebApi.layerClient.pipe(
  Layer.provide(Domain.protocolWebSocket(`${location.origin}/api`)),
  Layer.provide(Layer.mergeAll(FetchHttpClient.layer, Socket.layerWebSocketConstructorGlobal)),
);

Runtime.run(
  Runtime.makeApplication({
    Model,
    Flags,
    init,
    update,
    view,
    subscriptions,
    resources: BoardConnection,
    container: document.getElementById("root"),
  }),
  {
    flags: Effect.sync(() => {
      const { issueId, url } = issueOf(location.href, () => `web-${Date.now()}`);
      // Keep the issue in the address bar: a refresh resumes it.
      history.replaceState(null, "", url);
      return {
        issueId,
        // Names this page's commands, so each is unique even across reloads.
        page: crypto.randomUUID(),
      };
    }),
  },
);
```

## Without a Domain model

An app with no model can serve a session over an [Effect RPC](/cloudflare/apis/effect-rpc) group of its own. Alchemy AI gives the Schemas, and Alchemy serves the group over a WebSocket from the session's Durable Object.

### Define the interface

`@alchemy.run/ai/Session` has a Schema for everything a session says about itself: `SessionEvent`, `SessionEntry`, `SessionItem`, `QueuedMessage`, `HistoryOptions` and `SessionPage`. Use them as the results of your own procedures:

```typescript title="src/chat/Rpcs.ts"
import { HistoryOptions, SessionEvent, SessionPage } from "@alchemy.run/ai/Session";
import * as Rpc from "effect/rpc/Rpc";
import * as RpcGroup from "effect/rpc/RpcGroup";
import * as Schema from "effect/Schema";

/** The session could not do what it was asked. */
export class ChatError extends Schema.TaggedClass<ChatError>()("ChatError", {
  message: Schema.String,
}) {}

const Text = { text: Schema.String, requestId: Schema.String };

/** What the front end may ask of one session. */
export class ChatRpcs extends RpcGroup.make(
  Rpc.make("send", { payload: Text, error: ChatError }),
  Rpc.make("steer", { payload: Text, error: ChatError }),
  Rpc.make("withdraw", { payload: { id: Schema.String }, error: ChatError }),
  Rpc.make("interrupt", { error: ChatError }),
  Rpc.make("events", {
    payload: { after: Schema.optional(Schema.Number) },
    success: SessionEvent,
    error: ChatError,
    stream: true,
  }),
  Rpc.make("history", { payload: HistoryOptions, success: SessionPage, error: ChatError }),
) {}
```

`events` is a stream. The interface is yours, so it holds only what this front end may do: leave out `interrupt`, add a field, or put a middleware on it.

### Implement it with a session

Each procedure calls one method of `AI.Session`:

```typescript title="src/chat/Handlers.ts"
import type * as AI from "@alchemy.run/ai";
import * as Effect from "effect/Effect";
import * as Stream from "effect/Stream";
import { ChatError, ChatRpcs } from "./Rpcs.ts";

const failed = (error: AI.NotStarted | AI.HarnessError) =>
  ChatError.make({ message: error._tag === "NotStarted" ? "Not started" : error.message });

/** Each procedure is one method of the session. */
export const ChatHandlers = (session: AI.Session) =>
  ChatRpcs.toLayer({
    send: ({ text, requestId }) => session.send(text, { requestId }).pipe(Effect.mapError(failed)),
    steer: ({ text, requestId }) =>
      session.steer(text, { requestId }).pipe(Effect.mapError(failed)),
    withdraw: ({ id }) => session.withdraw(id).pipe(Effect.mapError(failed)),
    interrupt: () => session.interrupt.pipe(Effect.mapError(failed)),
    events: ({ after }) => session.events({ after }).pipe(Stream.mapError(failed)),
    history: (options) => session.history(options).pipe(Effect.mapError(failed)),
  });
```

### Serve it from the session's object

`Cloudflare.RpcDurableObject` serves a group over HTTP and over a WebSocket. Return the handlers for the session the object holds:

```typescript title="src/Engineers.ts"
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Effect from "effect/Effect";
import { ChatHandlers } from "./chat/Handlers.ts";
import { ChatRpcs } from "./chat/Rpcs.ts";
import { Engineer } from "./Engineer.process.ts";
import { Live } from "./Layers.ts";

export default class Engineers extends Cloudflare.RpcDurableObject<Engineers>()(
  "Engineers",
  { schema: ChatRpcs },
  Effect.gen(function* () {
    const engineer = yield* Engineer;
    const state = yield* Cloudflare.DurableObjectState;

    return Effect.sync(() => ChatHandlers(engineer.get(state.id.name ?? "")));
  }).pipe(Effect.provide(Live)),
) {}
```

The object is named after the session's key, so each session has an object of its own. `Live` is the same Layer as in [Where sessions run](/ai/hosting).

### Forward the browser to it

The Worker maps a URL to an object and forwards the request. The same route carries plain HTTP calls and the WebSocket upgrade:

```typescript title="src/Api.ts"
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Effect from "effect/Effect";
import { HttpServerRequest } from "effect/http/HttpServerRequest";
import * as HttpServerResponse from "effect/http/HttpServerResponse";
import Engineers from "./Engineers.ts";

export default class Api extends Cloudflare.Worker<Api>()(
  "Api",
  { main: import.meta.url },
  Effect.gen(function* () {
    const engineers = yield* Engineers;

    return {
      fetch: Effect.gen(function* () {
        const request = yield* HttpServerRequest;
        const id = /^\/sessions\/([\w-]+)$/.exec(new URL(request.url, "http://api").pathname)?.[1];
        if (id === undefined) return HttpServerResponse.empty({ status: 404 });
        return yield* engineers.fetch(id, request);
      }).pipe(Effect.orDie),
    };
  }),
) {}
```

Anyone who can open this route can read and steer that session. Check who is asking before you call `fetch`, or take the id from the signed-in user.

### Connect and follow

In the browser, `RpcWebSocketClient.layer` gives a typed client over one WebSocket. `follow` reads the session's events and resumes after a reconnect:

```typescript title="web/Client.ts"
import type { SessionEvent } from "@alchemy.run/ai/Session";
import * as RpcWebSocketClient from "@alchemy.run/cloudflare/Workers/RpcWebSocketClient";
import * as Context from "effect/Context";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import type * as RpcClient from "effect/rpc/RpcClient";
import type { RpcClientError } from "effect/rpc/RpcClientError";
import * as Socket from "effect/socket/Socket";
import * as Stream from "effect/Stream";
import { ChatRpcs, type ChatError } from "./Rpcs.ts";

/** The typed client of one session. */
export class Chat extends Context.Service<
  Chat,
  RpcClient.FromGroup<typeof ChatRpcs, RpcClientError>
>()("Chat") {}

/** One WebSocket to the session's object, open for as long as the Layer is. */
export const ChatLive = (url: string) =>
  RpcWebSocketClient.layer(Chat, ChatRpcs, url).pipe(
    Layer.provide(Socket.layerWebSocketConstructorGlobal),
  );

/**
 * The session's events for as long as they are read. When the connection
 * drops it asks again from the last item it delivered.
 */
export const follow = (options?: {
  readonly after?: number;
}): Stream.Stream<SessionEvent, ChatError, Chat> =>
  Stream.suspend(() => {
    let after = options?.after;
    const read = (): Stream.Stream<SessionEvent, ChatError, Chat> =>
      Stream.unwrap(Effect.map(Chat, (chat) => chat.events({ after }))).pipe(
        Stream.tap((event) =>
          Effect.sync(() => {
            if (event.type === "item") after = event.seq;
          }),
        ),
        Stream.catchTag("RpcClientError", () =>
          Stream.flatMap(Stream.fromEffect(Effect.sleep("1 second")), read),
        ),
      );
    return read();
  });
```

The first event is the status: `idle` or `working`, and the messages that are queued. Then come the stored items, then each new one as it happens. A change of status follows the items stored with it, so `idle` arrives after the answer.

The stream is the whole picture. A page that folds these events knows the transcript, whether the session is working and what is queued, with no other call.

An idle object is put to sleep with its sockets open, and wakes when the session is sent something. Each item has a `seq`, so `follow` asks again from the last one it delivered and nothing is missed or repeated.

### Send, steer and stop

The client has the procedures you declared:

```typescript title="web/act.ts"
import * as Effect from "effect/Effect";
import { Chat } from "./Client.ts";

export const act = Effect.gen(function* () {
  const chat = yield* Chat;

  yield* chat.send({ text: "Rename the config flag.", requestId: "m-1" });
  yield* chat.steer({ text: "Only in src.", requestId: "m-2" });
  yield* chat.interrupt();
});
```

A `requestId` makes a message exactly-once, so a retry after a lost answer is safe.
