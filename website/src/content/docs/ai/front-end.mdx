---
title: Connect a front end
description: Define an RPC interface over a session with its own Schemas, serve it from the session's Durable Object, and follow the session from a browser or a Foldkit app over one WebSocket.
---

A front end needs two things from a session: a live stream of what it does, and a way to act on it. You define that interface yourself, as an [Effect RPC](/cloudflare/apis/effect-rpc) group. Alchemy AI gives you the Schemas of what a session reports, and Alchemy serves the group over a WebSocket from the session's Durable Object.

## Define the interface

`@alchemy.run/ai/Session` has a Schema for everything a session says about itself: `SessionEvent`, `SessionEntry`, `SessionItem`, `QueuedMessage`, `HistoryOptions` and `SessionPage`. Use them as the results of your own procedures:

```typescript title="src/chat/Rpcs.ts"
import { HistoryOptions, SessionEvent, SessionPage } from "@alchemy.run/ai/Session";
import * as Rpc from "effect/rpc/Rpc";
import * as RpcGroup from "effect/rpc/RpcGroup";
import * as Schema from "effect/Schema";

/** The session could not do what it was asked. */
export class ChatError extends Schema.TaggedClass<ChatError>()("ChatError", {
  message: Schema.String,
}) {}

const Text = { text: Schema.String, requestId: Schema.String };

/** What the front end may ask of one session. */
export class ChatRpcs extends RpcGroup.make(
  Rpc.make("send", { payload: Text, error: ChatError }),
  Rpc.make("steer", { payload: Text, error: ChatError }),
  Rpc.make("withdraw", { payload: { id: Schema.String }, error: ChatError }),
  Rpc.make("interrupt", { error: ChatError }),
  Rpc.make("events", {
    payload: { after: Schema.optional(Schema.Number) },
    success: SessionEvent,
    error: ChatError,
    stream: true,
  }),
  Rpc.make("history", { payload: HistoryOptions, success: SessionPage, error: ChatError }),
) {}
```

`events` is a stream. The interface is yours, so it holds only what this front end may do: leave out `interrupt`, add a field, or put a middleware on it.

## Implement it with a session

Each procedure calls one method of `AI.Session`:

```typescript title="src/chat/Handlers.ts"
import type * as AI from "@alchemy.run/ai";
import * as Effect from "effect/Effect";
import * as Stream from "effect/Stream";
import { ChatError, ChatRpcs } from "./Rpcs.ts";

const failed = (error: AI.NotStarted | AI.HarnessError) =>
  ChatError.make({ message: error._tag === "NotStarted" ? "Not started" : error.message });

/** Each procedure is one method of the session. */
export const ChatHandlers = (session: AI.Session) =>
  ChatRpcs.toLayer({
    send: ({ text, requestId }) => session.send(text, { requestId }).pipe(Effect.mapError(failed)),
    steer: ({ text, requestId }) =>
      session.steer(text, { requestId }).pipe(Effect.mapError(failed)),
    withdraw: ({ id }) => session.withdraw(id).pipe(Effect.mapError(failed)),
    interrupt: () => session.interrupt.pipe(Effect.mapError(failed)),
    events: ({ after }) => session.events({ after }).pipe(Stream.mapError(failed)),
    history: (options) => session.history(options).pipe(Effect.mapError(failed)),
  });
```

## Serve it from the session's object

`Cloudflare.RpcDurableObject` serves a group over HTTP and over a WebSocket. Return the handlers for the session the object holds:

```typescript title="src/Engineers.ts"
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Effect from "effect/Effect";
import { ChatHandlers } from "./chat/Handlers.ts";
import { ChatRpcs } from "./chat/Rpcs.ts";
import { Engineer } from "./Engineer.process.ts";
import { Live } from "./Layers.ts";

export default class Engineers extends Cloudflare.RpcDurableObject<Engineers>()(
  "Engineers",
  { schema: ChatRpcs },
  Effect.gen(function* () {
    const engineer = yield* Engineer;
    const state = yield* Cloudflare.DurableObjectState;

    return Effect.sync(() => ChatHandlers(engineer.get(state.id.name ?? "")));
  }).pipe(Effect.provide(Live)),
) {}
```

The object is named after the session's key, so each session has an object of its own. `Live` is the same Layer as in [Where sessions run](/ai/hosting).

## Forward the browser to it

The Worker maps a URL to an object and forwards the request. The same route carries plain HTTP calls and the WebSocket upgrade:

```typescript title="src/Api.ts"
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Effect from "effect/Effect";
import { HttpServerRequest } from "effect/http/HttpServerRequest";
import * as HttpServerResponse from "effect/http/HttpServerResponse";
import Engineers from "./Engineers.ts";

export default class Api extends Cloudflare.Worker<Api>()(
  "Api",
  { main: import.meta.url },
  Effect.gen(function* () {
    const engineers = yield* Engineers;

    return {
      fetch: Effect.gen(function* () {
        const request = yield* HttpServerRequest;
        const id = /^\/sessions\/([\w-]+)$/.exec(new URL(request.url, "http://api").pathname)?.[1];
        if (id === undefined) return HttpServerResponse.empty({ status: 404 });
        return yield* engineers.fetch(id, request);
      }).pipe(Effect.orDie),
    };
  }),
) {}
```

Anyone who can open this route can read and steer that session. Check who is asking before you call `fetch`, or take the id from the signed-in user.

## Connect and follow

In the browser, `RpcWebSocketClient.layer` gives a typed client over one WebSocket. `follow` reads the session's events and resumes after a reconnect:

```typescript title="web/Client.ts"
import type { SessionEvent } from "@alchemy.run/ai/Session";
import * as RpcWebSocketClient from "@alchemy.run/cloudflare/Workers/RpcWebSocketClient";
import * as Context from "effect/Context";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import type * as RpcClient from "effect/rpc/RpcClient";
import type { RpcClientError } from "effect/rpc/RpcClientError";
import * as Socket from "effect/socket/Socket";
import * as Stream from "effect/Stream";
import { ChatRpcs, type ChatError } from "./Rpcs.ts";

/** The typed client of one session. */
export class Chat extends Context.Service<
  Chat,
  RpcClient.FromGroup<typeof ChatRpcs, RpcClientError>
>()("Chat") {}

/** One WebSocket to the session's object, open for as long as the Layer is. */
export const ChatLive = (url: string) =>
  RpcWebSocketClient.layer(Chat, ChatRpcs, url).pipe(
    Layer.provide(Socket.layerWebSocketConstructorGlobal),
  );

/**
 * The session's events for as long as they are read. When the connection
 * drops it asks again from the last item it delivered.
 */
export const follow = (options?: {
  readonly after?: number;
}): Stream.Stream<SessionEvent, ChatError, Chat> =>
  Stream.suspend(() => {
    let after = options?.after;
    const read = (): Stream.Stream<SessionEvent, ChatError, Chat> =>
      Stream.unwrap(Effect.map(Chat, (chat) => chat.events({ after }))).pipe(
        Stream.tap((event) =>
          Effect.sync(() => {
            if (event.type === "item") after = event.seq;
          }),
        ),
        Stream.catchTag("RpcClientError", () =>
          Stream.flatMap(Stream.fromEffect(Effect.sleep("1 second")), read),
        ),
      );
    return read();
  });
```

The first event is the status: `idle` or `working`, and the messages that are queued. Then come the stored items, then each new one as it happens. A change of status follows the items stored with it, so `idle` arrives after the answer.

The stream is the whole picture. A page that folds these events knows the transcript, whether the session is working and what is queued, with no other call.

An idle object is put to sleep with its sockets open, and wakes when the session is sent something. Each item has a `seq`, so `follow` asks again from the last one it delivered and nothing is missed or repeated.

## Send, steer and stop

The client has the procedures you declared:

```typescript title="web/act.ts"
import * as Effect from "effect/Effect";
import { Chat } from "./Client.ts";

export const act = Effect.gen(function* () {
  const chat = yield* Chat;

  yield* chat.send({ text: "Rename the config flag.", requestId: "m-1" });
  yield* chat.steer({ text: "Only in src.", requestId: "m-2" });
  yield* chat.interrupt();
});
```

A `requestId` makes a message exactly-once, so a retry after a lost answer is safe.

## In a Foldkit app

Each procedure is a Command, and `follow` is a Subscription. The Model keeps the status, the queue and the items:

```typescript title="web/App.ts"
import { QueuedMessage, SessionEntry, SessionEvent } from "@alchemy.run/ai/Session";
import * as Effect from "effect/Effect";
import * as Option from "effect/Option";
import * as Schema from "effect/Schema";
import * as Stream from "effect/Stream";
import { Command, Subscription, type Update } from "foldkit";
import type { Document, HtmlBuilder } from "foldkit/html";
import { defineMessageUnion } from "foldkit/message";
import { modifyFields } from "foldkit/struct";
import { Chat, follow } from "./Client.ts";

// MODEL

export const Flags = Schema.Struct({ page: Schema.String });

export const Model = Schema.Struct({
  /** Names this page's messages, so a retry is never run twice. */
  page: Schema.String,
  sent: Schema.Number,
  draft: Schema.String,
  status: Schema.Literals(["idle", "working"]),
  queued: Schema.Array(QueuedMessage),
  items: Schema.Array(SessionEntry),
  error: Schema.Option(Schema.String),
});
export type Model = typeof Model.Type;

// MESSAGE

export const Message = defineMessageUnion({
  ChangedDraft: { text: Schema.String },
  ClickedSend: {},
  ClickedSteer: {},
  ClickedStop: {},
  ClickedWithdraw: { id: Schema.String },
  ReceivedSessionEvent: { event: SessionEvent },
  CompletedAct: {},
  FailedSession: { reason: Schema.String },
});
export type Message = typeof Message.Type;

// COMMAND

const completed = <E>(effect: Effect.Effect<void, E, Chat>) =>
  effect.pipe(
    Effect.as(Message.CompletedAct()),
    Effect.catch(() => Effect.succeed(Message.FailedSession({ reason: "Not delivered" }))),
  );

const Text = { text: Schema.String, requestId: Schema.String };

/** Queued behind the turn that is running. */
export const Send = Command.define("Send", {
  args: Text,
  messages: [Message.CompletedAct, Message.FailedSession],
  execute: (message) => completed(Effect.flatMap(Chat, (chat) => chat.send(message))),
});

/** Read by the turn that is running, at its next step. */
export const Steer = Command.define("Steer", {
  args: Text,
  messages: [Message.CompletedAct, Message.FailedSession],
  execute: (message) => completed(Effect.flatMap(Chat, (chat) => chat.steer(message))),
});

export const Withdraw = Command.define("Withdraw", {
  args: { id: Schema.String },
  messages: [Message.CompletedAct, Message.FailedSession],
  execute: ({ id }) => completed(Effect.flatMap(Chat, (chat) => chat.withdraw({ id }))),
});

export const Stop = Command.define("Stop", {
  messages: [Message.CompletedAct, Message.FailedSession],
  execute: completed(Effect.flatMap(Chat, (chat) => chat.interrupt())),
});

// UPDATE

type Return = Update.Return<Model, Message, Chat>;

/** A message is named after the page and its count, so a retry is not run twice. */
const say = (model: Model, command: typeof Send | typeof Steer): Return => ({
  model: modifyFields(model, { sent: (sent) => sent + 1, draft: () => "" }),
  commands: [command({ text: model.draft, requestId: `${model.page}:${model.sent}` })],
});

export const update = (model: Model, message: Message) =>
  Message.match<Return>(message, {
    ChangedDraft: ({ text }) => ({ model: modifyFields(model, { draft: () => text }) }),
    ClickedSend: () => say(model, Send),
    ClickedSteer: () => say(model, Steer),
    ClickedStop: () => ({ model, commands: [Stop()] }),
    ClickedWithdraw: ({ id }) => ({ model, commands: [Withdraw({ id })] }),
    ReceivedSessionEvent: ({ event }) => ({
      model:
        event.type === "status"
          ? modifyFields(model, { status: () => event.status, queued: () => event.queued })
          : modifyFields(model, {
              items: (items) => [...items, { seq: event.seq, item: event.item }],
            }),
    }),
    CompletedAct: () => ({ model }),
    FailedSession: ({ reason }) => ({
      model: modifyFields(model, { error: () => Option.some(reason) }),
    }),
  });

// INIT

export const init = (flags: typeof Flags.Type): Return => ({
  model: Model.make({
    page: flags.page,
    sent: 0,
    draft: "",
    status: "idle",
    queued: [],
    items: [],
    error: Option.none(),
  }),
});

// SUBSCRIPTION

export const subscriptions = Subscription.make<Model, Message, Chat>()((entry) => ({
  session: entry(
    {},
    {
      modelToDependencies: () => ({}),
      // The status, every item, then each new one. It resumes by itself after a reconnect.
      dependenciesToStream: () =>
        follow().pipe(
          Stream.map((event) => Message.ReceivedSessionEvent({ event })),
          Stream.catch((error) => Stream.succeed(Message.FailedSession({ reason: error.message }))),
        ),
    },
  ),
}));

// VIEW

const itemView = ({ seq, item }: SessionEntry, h: HtmlBuilder<Message>) =>
  h.keyed("li")(
    String(seq),
    [],
    [
      item.type === "tool"
        ? `${item.name}: ${item.output}`
        : item.type === "assistant" && item.toolCalls.length > 0
          ? `calls ${item.toolCalls.map((call) => call.name).join(", ")}`
          : item.text,
    ],
  );

export const view = (model: Model, h: HtmlBuilder<Message>): Document => ({
  title: model.status === "working" ? "Working" : "Idle",
  body: h.div(
    [],
    [
      h.ul(
        [],
        model.items.map((entry) => itemView(entry, h)),
      ),
      h.ul(
        [],
        model.queued.map((message) =>
          h.keyed("li")(
            message.id,
            [],
            [
              `${message.delivery}: ${message.text}`,
              h.button([h.OnClick(Message.ClickedWithdraw({ id: message.id }))], ["Withdraw"]),
            ],
          ),
        ),
      ),
      h.input([h.Value(model.draft), h.OnInput((text) => Message.ChangedDraft({ text }))]),
      h.button([h.OnClick(Message.ClickedSend())], ["Send"]),
      ...(model.status === "working"
        ? [
            h.button([h.OnClick(Message.ClickedSteer())], ["Steer"]),
            h.button([h.OnClick(Message.ClickedStop())], ["Stop"]),
          ]
        : []),
      h.p([], [Option.getOrElse(model.error, () => "")]),
    ],
  ),
});
```

Provide the client in the app's resources:

```typescript title="web/entry.ts"
import * as Effect from "effect/Effect";
import { Runtime } from "foldkit";
import { Flags, init, Model, subscriptions, update, view } from "./App.ts";
import { ChatLive } from "./Client.ts";

const id = new URLSearchParams(location.search).get("session") ?? "main";

Runtime.run(
  Runtime.makeApplication({
    Model,
    Flags,
    init,
    update,
    view,
    subscriptions,
    resources: ChatLive(`wss://${location.host}/sessions/${id}`),
    container: document.getElementById("root"),
  }),
  // Names this page's messages, so a retry is never run twice.
  { flags: Effect.sync(() => ({ page: crypto.randomUUID() })) },
);
```

## Send from the server too

The object answers the same group to your own services. A Worker, or a [Domain policy](/ai/domain#let-a-policy-ask-for-the-work), gets a client by the session's key:

```typescript
const chat = yield* engineers.getByName("task-7");

yield* chat.send({ text: "Rename the config flag.", requestId: "start" });
```

A browser that is following `task-7` sees that message and everything the session does with it.
