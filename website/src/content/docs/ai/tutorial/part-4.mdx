## Give each session a sandbox

The harness runs in a Durable Object, which has no files and no shell. Tools that need them work in a sandbox. This Layer starts one for each session, from a snapshot that already has the repository:

```typescript title="src/Sandbox.ts"
import * as AIBoat from "@alchemy.run/ai/Boat";
import * as Boat from "@alchemy.run/boat";
import * as Output from "alchemy/Output";
import * as Effect from "effect/Effect";
import { Repo } from "./Repo.ts";

export const SandboxLive = AIBoat.Sandboxes(
  Effect.gen(function* () {
    const repo = yield* Repo;
    return yield* Boat.Snapshot("Checkout", {
      run: [Output.interpolate`git clone ${repo.cloneUrl} ~/repo`],
    });
  }),
);
```

See [Sandboxes](/ai/sandboxes) for the other platforms.

## Declare a tool to search issues

A tool is a contract and a Layer that implements it. This one finds duplicates:

```typescript title="src/Tools.ts"
import * as AI from "@alchemy.run/ai";
import * as GitHub from "@alchemy.run/github";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import * as Schema from "effect/Schema";
import { Repo } from "./Repo.ts";

export class SearchIssues extends AI.Tool<SearchIssues>()("search_issues", {
  description:
    "Search this repository's issues and pull requests. Use it to find duplicates or related work.",
  parameters: Schema.Struct({ query: Schema.String }),
  success: Schema.Struct({
    issues: Schema.Array(
      Schema.Struct({ number: Schema.Number, title: Schema.String, state: Schema.String }),
    ),
  }),
}) {}

export const SearchIssuesLive = SearchIssues.make(
  Effect.gen(function* () {
    const search = yield* GitHub.SearchIssues(yield* Repo);

    return Effect.fn(function* ({ query }) {
      const found = yield* search({ q: query, per_page: 10 }).pipe(Effect.orDie);
      return {
        issues: found.items.map((issue) => ({
          number: issue.number,
          title: issue.title,
          state: issue.state,
        })),
      };
    });
  }),
).pipe(Layer.provide(GitHub.SearchIssuesHttp));
```

## Declare a tool to answer

The session answers by posting a comment. `MARKER` is hidden in each one, so the session's own comments can be told from a person's:

```diff lang="typescript" title="src/Tools.ts"
import { Repo } from "./Repo.ts";
+
+export const MARKER = "<!-- ai-issues -->";
+
+export class PostAnswer extends AI.Tool<PostAnswer>()("post_answer", {
+  description: "Post your answer on the issue as a comment, in Markdown.",
+  parameters: Schema.Struct({ issue: Schema.String, markdown: Schema.String }),
+  success: Schema.Struct({ url: Schema.String }),
+}) {}
+
+export const PostAnswerLive = PostAnswer.make(
+  Effect.gen(function* () {
+    const comment = yield* GitHub.CreateIssueComment(yield* Repo);
+
+    return Effect.fn(function* ({ issue, markdown }) {
+      const posted = yield* comment({
+        issue_number: Number(issue),
+        body: `${markdown}\n\n${MARKER}`,
+      }).pipe(Effect.orDie);
+      return { url: posted.html_url };
+    });
+  }),
+).pipe(Layer.provide(GitHub.CreateIssueCommentHttp));
```

## Describe how an answer reads

How to write an answer is its own process. It is prose with a description, and nothing else:

```typescript title="src/Answering.ts"
import * as AI from "@alchemy.run/ai";

export class Answering extends AI.Process<Answering>()("Answering", {
  description: "How to write an answer on an issue. Follow it before you post one.",
})`
  Write the answer in Markdown and keep it under two hundred words.
  Start with the answer itself, in one sentence.
  Name each file you read as a path in backticks, with a line number where it helps.
  Say what you did not check. Never promise a fix or a date.
` {}
```

## Run it on OpenCode

Every session so far ran on Pi. The harness is one constant in `Agents.ts`:

```diff lang="typescript" title="src/Agents.ts"
import * as DomainCloudflare from "@alchemy.run/domain/Cloudflare";
-import * as Pi from "@alchemy.run/pi";
-import * as PiCloudflare from "@alchemy.run/pi/Cloudflare";
+import * as OpenCode from "@alchemy.run/opencode";
+import * as OpenCodeCloudflare from "@alchemy.run/opencode/Cloudflare";

-const HarnessLive = Layer.mergeAll(Pi.HarnessLive, Pi.CodingTools).pipe(
-  Layer.provide(PiCloudflare.DurableObjectStorage),
-);
+const HarnessLive = Layer.mergeAll(OpenCode.HarnessLive, OpenCode.CodingTools).pipe(
+  Layer.provide(OpenCodeCloudflare.DurableObjectStorage),
+);
```

The process, its prose, the board, the policy and the tools are unchanged. Sessions that already started on Pi stay in Pi's storage; a new harness starts with none.

## What you built

- A board that models the work: issues, replies, labels.
- A policy that decides when an issue is looked after, and an object for each issue that answers.
- A process that says how the work is done, in prose that mentions what it uses.
- A harness you chose in one line.
