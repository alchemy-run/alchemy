---
title: Models
description: Name a model once with AI.Model and back it with any Effect AI LanguageModel Layer, so a harness changes LLM by changing one Layer.
---

A harness runs each conversation on a model. `AI.Model` gives a model a name, and an Effect AI `LanguageModel` Layer says which LLM answers under that name. Conversations store the name, so the LLM behind it can change without touching them.

## Declare a model

A model is a class with a name:

```typescript title="src/models.ts"
import * as AI from "@alchemy.run/ai";

export class Fast extends AI.Model<Fast>()("fast") {}
export class Smart extends AI.Model<Smart>()("smart", { contextWindow: 200_000, images: true }) {}
```

The options tell the harness what the model can take: `contextWindow` (128,000 tokens unless you say otherwise), `maxTokens` for one answer (8,192) and whether it accepts `images` (no).

## Back it with an LLM

`Fast.layer` takes an Effect AI `LanguageModel` Layer, from any provider. For Workers AI, `@alchemy.run/ai/Cloudflare` does it in one call, through the Worker's own AI binding:

```typescript title="src/models.ts"
import * as AI from "@alchemy.run/ai";
import * as AICloudflare from "@alchemy.run/ai/Cloudflare";

export class Fast extends AI.Model<Fast>()("fast") {}

export const FastLive = AICloudflare.WorkersAI(Fast, {
  model: "@cf/meta/llama-3.3-70b-instruct-fp8-fast",
  parameters: { temperature: 0, maxTokens: 1024 },
});
```

The model's key never leaves your runtime. A harness that runs its agent somewhere else, as OpenCode does in a sandbox, sends each model request back to this Layer.

## Route through AI Gateway

An AI Gateway logs, caches and rate-limits requests on their way to a model. `AICloudflare.Gateway` takes the gateway as well:

```typescript title="src/models.ts"
import * as AI from "@alchemy.run/ai";
import * as AICloudflare from "@alchemy.run/ai/Cloudflare";
import * as Cloudflare from "@alchemy.run/cloudflare";

export const Gateway = Cloudflare.AI.Gateway("Gateway", { collectLogs: true });

export class Fast extends AI.Model<Fast>()("fast") {}

export const FastLive = AICloudflare.Gateway(Fast, Gateway, {
  model: "@cf/meta/llama-3.3-70b-instruct-fp8-fast",
});
```

See [AI Gateway](/cloudflare/ai/ai-gateway).

## Use another provider

`Fast.layer` takes any `LanguageModel` Layer, so a provider without a ready-made Layer is a few lines. This is `AICloudflare.WorkersAI` written out:

```typescript title="src/models.ts"
import * as AI from "@alchemy.run/ai";
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";

export class Fast extends AI.Model<Fast>()("fast") {}

export const FastLive = Layer.unwrap(
  Effect.gen(function* () {
    const ai = yield* Cloudflare.Workers.AI();
    return Fast.layer(ai.model({ model: "@cf/meta/llama-3.3-70b-instruct-fp8-fast" }));
  }),
).pipe(Layer.provide(Cloudflare.Workers.AIBinding));
```

The Effect runs where the harness is yielded, so the binding it declares is part of the deploy. See [Effect AI on Cloudflare](/cloudflare/ai/effect-ai), [Bedrock](/aws/ai/bedrock) and [Vertex AI](/gcp/ai/vertex-ai).

## List models on a harness

A harness lists every model its conversations may run on. The first is the default, and each one's Layer is a requirement of the harness:

```typescript
const harness = yield* Pi.Harness({ models: [Fast, Smart] });
```

A conversation or a prompt picks one by reference:

```typescript
yield* harness.configure("pr-142", { model: Smart });
```
