Host your cluster in your AWS account: Postgres runs on RDS, in a VPC of its own or one you give it, and runners run on ECS Fargate in the same VPC. A load balancer, or CloudFront in front of one, serves each pool's gateway, so a Lambda function, a container or a Worker calls the rooms by id.

```typescript title="src/Cluster.ts"
import * as ClusterAWS from "@alchemy.run/effect-cluster/AWS";
import * as Layer from "effect/Layer";

export const Database = ClusterAWS.Database("Cluster");

export const Default = ClusterAWS.EcsPool("Default", { replicas: 2 }).pipe(
  Layer.provide(Database),
);
```

Install `@alchemy.run/aws` and finish [AWS setup](/aws/setup).

## The database

`ClusterAWS.Database` creates a VPC across two Availability Zones, an RDS Postgres instance in it, and one security group every runner joins. That group reaches Postgres and the other runners; nothing else does.

```typescript title="src/Cluster.ts"
import * as ClusterAWS from "@alchemy.run/effect-cluster/AWS";

export const Database = ClusterAWS.Database("Cluster", {
  instanceClass: "db.m7g.large",
  multiAZ: true,
  allocatedStorage: 100,
});
```

A new RDS instance takes 10 to 15 minutes to create.

## Run in your own VPC

Give the database a `network`, and the database, the runners and their gateways run in it. An `EC2.Network` with a NAT gateway puts them in its private subnets, where the runners reach the internet through the NAT:

```typescript title="src/Network.ts"
import * as EC2 from "@alchemy.run/aws/EC2";

export const AppNetwork = EC2.Network("App", {
  cidrBlock: "10.42.0.0/16",
  availabilityZones: 2,
  nat: "single",
});
```

```typescript title="src/Cluster.ts"
import * as ClusterAWS from "@alchemy.run/effect-cluster/AWS";
import * as Layer from "effect/Layer";
import { AppNetwork } from "./Network.ts";

export const Database = ClusterAWS.Database("Cluster", { network: AppNetwork });

export const Default = ClusterAWS.EcsPool("Default", { replicas: 2 }).pipe(
  Layer.provide(Database),
);
```

A VPC another stack owns is a `ref` to its VPC and subnets:

```typescript title="src/Cluster.ts"
import * as EC2 from "@alchemy.run/aws/EC2";
import * as ClusterAWS from "@alchemy.run/effect-cluster/AWS";
import * as Layer from "effect/Layer";

export const Database = ClusterAWS.Database("Cluster", {
  network: {
    vpc: EC2.Vpc.ref("AppVpc", { stack: "network" }),
    subnets: [
      EC2.Subnet.ref("PrivateSubnetA", { stack: "network" }),
      EC2.Subnet.ref("PrivateSubnetB", { stack: "network" }),
    ],
  },
});

export const Default = ClusterAWS.EcsPool("Default", { replicas: 2 }).pipe(
  Layer.provide(Database),
);
```

A VPC nobody manages is a `lookup`:

```typescript title="src/Cluster.ts"
import * as EC2 from "@alchemy.run/aws/EC2";
import * as ClusterAWS from "@alchemy.run/effect-cluster/AWS";
import * as Layer from "effect/Layer";

export const Database = ClusterAWS.Database("Cluster", {
  network: {
    vpc: EC2.Vpc.lookup({ name: "shared" }),
    subnets: [EC2.Subnet.lookup({ name: "private-a" }), EC2.Subnet.lookup({ name: "private-b" })],
  },
});

export const Default = ClusterAWS.EcsPool("Default", { replicas: 2 }).pipe(
  Layer.provide(Database),
);
```

Given resource by resource, runners take no public IP, so the subnets need a NAT gateway (or VPC endpoints) for the runners to pull their image. Subnets without one take `assignPublicIp: true`. An internet-facing gateway's load balancer goes in `publicSubnets`, which default to `subnets`; an `EC2.Network`'s public subnets are used automatically.

## The pool

`EcsPool` runs the pool as an ECS service on Fargate, in the database's VPC:

```typescript title="src/Cluster.ts"
import * as ClusterAWS from "@alchemy.run/effect-cluster/AWS";
import * as Layer from "effect/Layer";

export const Database = ClusterAWS.Database("Cluster");

export const Default = ClusterAWS.EcsPool("Default", {
  replicas: 3,
  cpu: 1024,
  memory: 2048,
  architecture: "ARM64",
}).pipe(Layer.provide(Database));
```

Each pool gets a load balancer in front of its gateway. The runners only take gateway traffic from it, and the gateway checks every call's token.

## Choose the gateway

Without a `gateway`, an internet-facing Application Load Balancer serves the pool's gateway over plain HTTP, and the token crosses the internet unencrypted. Give it a domain and it serves HTTPS on port 443, with an ACM certificate validated in the domain's Route 53 hosted zone:

```typescript title="src/Cluster.ts"
import * as ClusterAWS from "@alchemy.run/effect-cluster/AWS";
import * as Layer from "effect/Layer";

export const Database = ClusterAWS.Database("Cluster");

export const Default = ClusterAWS.EcsPool("Default", {
  replicas: 2,
  gateway: ClusterAWS.LoadBalancerGateway({ domain: "cluster.example.com" }),
}).pipe(Layer.provide(Database));
```

A domain whose DNS lives elsewhere takes that host's [DNS adapter](/infrastructure-as-code/dns-adapters):

```typescript title="src/Cluster.ts"
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as ClusterAWS from "@alchemy.run/effect-cluster/AWS";
import * as Layer from "effect/Layer";

export const Database = ClusterAWS.Database("Cluster");

export const Default = ClusterAWS.EcsPool("Default", {
  replicas: 2,
  gateway: ClusterAWS.LoadBalancerGateway({
    domain: { name: "cluster.example.com", dns: Cloudflare.DNS.Adapter() },
  }),
}).pipe(Layer.provide(Database));
```

Without a domain, `CloudFrontGateway` serves HTTPS on a `*.cloudfront.net` name. The load balancer behind it is internal, and CloudFront reaches it through a VPC origin, so nothing on the internet reaches the load balancer itself:

```typescript title="src/Cluster.ts"
import * as ClusterAWS from "@alchemy.run/effect-cluster/AWS";
import * as Layer from "effect/Layer";

export const Database = ClusterAWS.Database("Cluster");

export const Default = ClusterAWS.EcsPool("Default", {
  replicas: 2,
  gateway: ClusterAWS.CloudFrontGateway(),
}).pipe(Layer.provide(Database));
```

CloudFront cuts a connection that sends nothing for its origin read timeout, 60 seconds here. The gateway writes a keep-alive line every 15 seconds while a call waits or a stream is quiet, so long calls stay open.

When only callers in the VPC call the pool, make the load balancer internal. It admits the VPC's range unless you give it an `ingress`:

```typescript title="src/Cluster.ts"
import * as ClusterAWS from "@alchemy.run/effect-cluster/AWS";
import * as Layer from "effect/Layer";
import { AppNetwork } from "./Network.ts";

export const Database = ClusterAWS.Database("Cluster", { network: AppNetwork });

export const Default = ClusterAWS.EcsPool("Default", {
  replicas: 2,
  gateway: ClusterAWS.LoadBalancerGateway({ scheme: "internal" }),
}).pipe(Layer.provide(Database));
```

## Call it from a Lambda

```typescript title="src/Api.ts"
import * as Lambda from "@alchemy.run/aws/Lambda";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/http/HttpServerResponse";
import { Room } from "./Room.ts";

export default class Api extends Lambda.Function<Api>()(
  "Api",
  { main: import.meta.url, functionUrl: true },
  Effect.gen(function* () {
    const rooms = yield* Room;
    return {
      fetch: Effect.gen(function* () {
        const lobby = yield* rooms.getByName("lobby");
        return yield* HttpServerResponse.json({ members: yield* lobby.Join({ name: "sam" }) });
      }).pipe(Effect.orDie),
    };
  }),
) {}
```

## Call an internal gateway from a Lambda

A Lambda function only reaches an internal gateway from inside the VPC. Join it to the same network: a function's props may be an Effect, so it yields the network and a security group of its own.

```typescript title="src/Api.ts"
import * as EC2 from "@alchemy.run/aws/EC2";
import * as Lambda from "@alchemy.run/aws/Lambda";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/http/HttpServerResponse";
import { AppNetwork } from "./Network.ts";
import { Room } from "./Room.ts";

export default class Api extends Lambda.Function<Api>()(
  "Api",
  Effect.gen(function* () {
    const network = yield* AppNetwork;
    const group = yield* EC2.SecurityGroup("ApiGroup", {
      vpcId: network.vpcId,
      egress: [{ ipProtocol: "-1", cidrIpv4: "0.0.0.0/0" }],
    });
    return {
      main: import.meta.url,
      functionUrl: true,
      vpc: { subnetIds: network.privateSubnetIds, securityGroupIds: [group.groupId] },
    };
  }),
  Effect.gen(function* () {
    const rooms = yield* Room;
    return {
      fetch: Effect.gen(function* () {
        const lobby = yield* rooms.getByName("lobby");
        return yield* HttpServerResponse.json({ members: yield* lobby.Join({ name: "sam" }) });
      }).pipe(Effect.orDie),
    };
  }),
) {}
```

The function reaches the internet through the network's NAT gateway. Nothing joins a caller to the VPC for you: a function that calls pools in two VPCs can only be in one.

Every option, with its default, is in the reference: [Database](/providers/cluster/aws#database), [EcsPool](/providers/cluster/aws#ecspool), [LoadBalancerGateway](/providers/cluster/aws#loadbalancergateway) and [CloudFrontGateway](/providers/cluster/aws#cloudfrontgateway).
