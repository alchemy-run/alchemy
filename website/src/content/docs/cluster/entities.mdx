title: Entities
description: How an Effect Cluster entity is written in Alchemy — its declaration, its two-phase implementation, its instances, and where its code lives.
---

An entity is a class with one instance per id. Every instance runs the same code against its own state, and handles its messages one at a time.

## Declare it

The declaration names the entity and lists the messages it accepts, the same arguments Effect's `Entity.make` takes:

```typescript title="src/Room.ts"
import * as Cluster from "@alchemy.run/effect-cluster";
import { Rpc } from "effect/rpc";
import * as Schema from "effect/Schema";

export class RoomFull extends Schema.TaggedError<RoomFull>()("RoomFull", {
  capacity: Schema.Int,
}) {}

export class Room extends Cluster.Entity<Room>()("Room", [
  Rpc.make("Join", { payload: { name: Schema.String }, success: Schema.Int, error: RoomFull }),
  Rpc.make("Members", { success: Schema.Array(Schema.String) }),
]) {}
```

Callers import the declaration, never the implementation. A Worker that calls the room bundles its schemas, not its code or its runners.

## Implement it

The implementation is a Layer, made with `.make`:

```typescript title="src/RoomLive.ts"
import * as Effect from "effect/Effect";
import * as Ref from "effect/Ref";
import { Default } from "./Cluster.ts";
import { Room, RoomFull } from "./Room.ts";

export default Room.make(
  { main: import.meta.url },
  Effect.gen(function* () {
    return Effect.gen(function* () {
      const members = yield* Ref.make(new Set<string>());
      return Room.of({
        Join: ({ payload }) =>
          Effect.gen(function* () {
            const all = yield* Ref.get(members);
            if (all.size >= 10) return yield* new RoomFull({ capacity: 10 });
            const next = new Set(all).add(payload.name);
            yield* Ref.set(members, next);
            return next.size;
          }),
        Members: () => Effect.map(Ref.get(members), (all) => [...all]),
      });
    });
  }).pipe(Effect.provide(Default)),
);
```

`Room.of` types the handlers against the declaration: each takes the request envelope, with the payload at `payload`, and returns the RPC's success, error or stream.

`main` is the module whose default export is this Layer. The runners import it, so keep the implementation in a file of its own and export it as `default`.

## Two phases

The outer Effect runs once per runner, when it starts. Resolve bindings there: other entities, secrets, Config values.

The inner Effect runs once per instance, on its first message. Its state starts there:

```typescript title="src/RoomLive.ts"
import { Entity } from "effect/cluster";
import * as Effect from "effect/Effect";
import * as Ref from "effect/Ref";
import { Default } from "./Cluster.ts";
import { Room } from "./Room.ts";

export default Room.make(
  { main: import.meta.url },
  Effect.gen(function* () {
    return Effect.gen(function* () {
      const { entityId } = yield* Entity.CurrentAddress;
      yield* Effect.logInfo(`room ${entityId} started`);
      const members = yield* Ref.make(new Set<string>());
      return Room.of({
        Join: ({ payload }) =>
          Ref.modify(members, (all) => {
            const next = new Set(all).add(payload.name);
            return [next.size, next];
          }),
        Members: () => Effect.map(Ref.get(members), (all) => [...all]),
      });
    });
  }).pipe(Effect.provide(Default)),
);
```

`Entity.CurrentAddress` holds the instance's id and shard.

## How long an instance lives

An instance stops after sitting idle for a minute. Its next message starts it again, from the inner Effect, with fresh state. Set how long it waits, and how many of its messages may run at once, on `.make`:

```typescript title="src/RoomLive.ts"
import * as Effect from "effect/Effect";
import * as Ref from "effect/Ref";
import { Default } from "./Cluster.ts";
import { Room } from "./Room.ts";

export default Room.make(
  { main: import.meta.url, maxIdleTime: "10 minutes", concurrency: 1 },
  Effect.gen(function* () {
    return Effect.gen(function* () {
      const members = yield* Ref.make(new Set<string>());
      return Room.of({
        Join: ({ payload }) =>
          Ref.modify(members, (all) => {
            const next = new Set(all).add(payload.name);
            return [next.size, next];
          }),
        Members: () => Effect.map(Ref.get(members), (all) => [...all]),
      });
    });
  }).pipe(Effect.provide(Default)),
);
```

An instance also stops when its runner does, including on every deploy, and when its shard moves to another runner.

## Messages

Each RPC's schema shapes what callers send and get back. Effect Cluster's own annotations and helpers work unchanged:

```typescript title="src/Room.ts"
import * as Cluster from "@alchemy.run/effect-cluster";
import { ClusterSchema } from "effect/cluster";
import { Rpc } from "effect/rpc";
import * as Schema from "effect/Schema";

export class Room extends Cluster.Entity<Room>()("Room", [
  // Written to the database first, delivered at least once, handled once per key.
  Rpc.make("Post", {
    payload: { messageId: Schema.String, text: Schema.String },
    primaryKey: ({ messageId }) => messageId,
  }).annotate(ClusterSchema.Persisted, true),
  // A stream of values back to the caller.
  Rpc.make("History", { success: Schema.String, stream: true }),
]) {}
```

In a handler, `Rpc.fork` lets a message run beside the others, and `Entity.keepAlive` keeps the instance from going idle.

## Use an Effect Cluster entity you already have

A declaration also takes an entity made with Effect's `Entity.make`, and exposes it as `Room.entity`:

```typescript title="src/Room.ts"
import * as Cluster from "@alchemy.run/effect-cluster";
import { Room as RoomEntity } from "./entities/room.ts";

export class Room extends Cluster.Entity<Room>()(RoomEntity) {}
```

To deploy a whole Effect Cluster program as it is, see [Existing programs](/cluster/existing-programs).
