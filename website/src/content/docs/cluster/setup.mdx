Effect Cluster needs no account of its own. You run the database and the runners on a cloud you already use, so setting up means installing the provider and getting that cloud ready.

## Add the provider

Install `@alchemy.run/cluster`:

<PackageManagers add="@alchemy.run/cluster" />

Then add `Cluster.providers()` next to your cloud's providers:

```typescript title="alchemy.run.ts"
import * as Alchemy from "alchemy";
import * as Cluster from "@alchemy.run/cluster";
import * as Docker from "@alchemy.run/docker";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import Api from "./src/Api.ts";
import RoomLive from "./src/RoomLive.ts";

export default Alchemy.Stack(
  "Rooms",
  { providers: Layer.mergeAll(Docker.providers(), Cluster.providers()) },
  Effect.gen(function* () {
    const api = yield* Api;
    return { api: api.name };
  }).pipe(Effect.provide(RoomLive)),
);
```

## Install the package for your cloud

Each cloud has its own entry point, and needs that cloud's provider package:

| Import | Install |
|---|---|
| `@alchemy.run/cluster/Docker` | `@alchemy.run/docker` |
| `@alchemy.run/cluster/AWS` | `@alchemy.run/aws` |
| `@alchemy.run/cluster/GCP` | `@alchemy.run/gcp` |
| `@alchemy.run/cluster/Kubernetes` | `@alchemy.run/kubernetes` |
| `@alchemy.run/cluster/Fly` | `@alchemy.run/fly` |
| `@alchemy.run/cluster/Hetzner` | `@alchemy.run/hetzner` |

Then follow that cloud's setup, for example [AWS setup](/aws/setup) or [Hetzner setup](/hetzner/setup).

## Run a cluster on your machine

The Docker database and runners run on a Docker swarm. Turn swarm mode on once:

```sh
docker swarm init
```

Run `docker info --format '{{.Swarm.LocalNodeState}}'` to check. It prints `active`.

## Use a Postgres you already have

Runners only need a Postgres they can reach. To use one you run elsewhere, such as Neon or an existing RDS instance, pass its URL:

```typescript title="src/Cluster.ts"
import * as Cluster from "@alchemy.run/cluster";
import * as Config from "effect/Config";

export const Database = Cluster.Database.fromUrl({
  url: Config.Redacted("CLUSTER_DATABASE_URL"),
});
```

See [Databases](/cluster/databases).
