`GCP.Function` runs an Effect program as a Cloud Run service. You
write a `fetch` handler, Alchemy builds a container image, pushes it
to Artifact Registry, and deploys a new revision. The service scales
with traffic and down to zero.

:::note
The image is built on your machine, so Docker has to be running when
you deploy. To deploy without Docker, use
[Cloud Functions](/gcp/compute/cloud-functions).
:::

## Declare a service

```typescript
// src/Api.ts
import * as GCP from "@alchemy.run/gcp";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/http/HttpServerResponse";

export default class Api extends GCP.Function<Api>()(
  "Api",
  { main: import.meta.url },
  Effect.gen(function* () {
    return {
      fetch: Effect.succeed(HttpServerResponse.text("Hello from Cloud Run!")),
    };
  }),
) {}
```

`GCP.Function` is the same class as `GCP.Run.Service`. `main` names
the file to bundle.

## Add it to the Stack

```typescript
// alchemy.run.ts
import * as Alchemy from "alchemy";
import * as GCP from "@alchemy.run/gcp";
import * as Effect from "effect/Effect";
import Api from "./src/Api.ts";

export default Alchemy.Stack(
  "MyApp",
  { providers: GCP.providers(), state: GCP.state() },
  Effect.gen(function* () {
    const api = yield* Api;
    return { url: api.uri };
  }),
);
```

`api.uri` is the service's `https://….run.app` URL.

## Make it public

A new service only accepts callers with a Google identity token and
`roles/run.invoker`. Set `invokerIamDisabled` to let anyone call it:

```diff lang="typescript"
export default class Api extends GCP.Function<Api>()(
  "Api",
-  { main: import.meta.url },
+  { main: import.meta.url, invokerIamDisabled: true },
```

Leave it off for internal services. Another service calls a private
one with [`InvokeService`](/gcp/networking/private-services).

## Read the request

`fetch` is an Effect. Get the request from `HttpServerRequest`:

```typescript
import { HttpServerRequest } from "effect/http/HttpServerRequest";

fetch: Effect.gen(function* () {
  const request = yield* HttpServerRequest;
  const url = new URL(request.originalUrl, "http://localhost");

  if (request.method === "POST" && url.pathname === "/echo") {
    const body = yield* request.json;
    return yield* HttpServerResponse.json(body);
  }

  return HttpServerResponse.text("Not found", { status: 404 });
}).pipe(Effect.orDie),
```

For typed routes, use [Effect HTTP](/gcp/apis/effect-http-api) or
[Effect RPC](/gcp/apis/effect-rpc). Both produce a `fetch` handler.

## Bind resources

Declare a resource in the constructor and bind it. The binding returns
a client and grants the service the role it needs on that resource:

```typescript
Effect.gen(function* () {
  const links = yield* GCP.Firestore.Database("Links", {
    type: "FIRESTORE_NATIVE",
  });
  const db = yield* GCP.Firestore.ReadWriteDatabase(links);

  return {
    fetch: Effect.gen(function* () {
      const doc = yield* db.get("links/home");
      return yield* HttpServerResponse.json(doc?.fields ?? {});
    }).pipe(Effect.orDie),
  };
}).pipe(Effect.provide(GCP.Firestore.ReadWriteDatabaseHttp)),
```

Each service gets its own service account. Bindings grant roles to it
and nothing else. See [How bindings grant IAM](/gcp/security/iam).

## Pass environment variables

`env` sets plain container environment variables:

```typescript
{
  main: import.meta.url,
  env: {
    LOG_LEVEL: "debug",
    API_BASE: other.uri,
  },
}
```

Values can be Outputs from other resources. For credentials, use
[Secret Manager](/gcp/security/secrets-kms) instead.

## Choose the region

A service deploys to the Stack's region (your profile's region, else
`us-central1`). Pin it with `location`:

```typescript
{ main: import.meta.url, location: "europe-west1" }
```

Changing `location` replaces the service.

## Tune scaling

Keep warm instances to avoid cold starts, or cap the maximum:

```typescript
{
  main: import.meta.url,
  scaling: { minInstanceCount: 1, maxInstanceCount: 20 },
}
```

## Size the container

Set CPU, memory, timeout, and concurrency on the revision template:

```typescript
{
  main: import.meta.url,
  template: {
    timeout: "60s",
    maxInstanceRequestConcurrency: 40,
    containers: [{ resources: { limits: { cpu: "2", memory: "1Gi" } } }],
  },
}
```

Every template change rolls out a new revision.

## Check health

Cloud Run's default startup probe passes as soon as the port accepts a
connection. Give it an HTTP probe so a revision only takes traffic once
the program can serve:

```typescript
{
  main: import.meta.url,
  template: {
    containers: [
      {
        startupProbe: { httpGet: { path: "/health" }, periodSeconds: 2, failureThreshold: 30 },
        livenessProbe: { httpGet: { path: "/health" }, periodSeconds: 10 },
      },
    ],
  },
}
```

A failing liveness probe restarts the container. Probes can also use
`tcpSocket` or `grpc`. Remove `startupProbe` to go back to the default.

## Add a sidecar

Containers after the first run next to `main` in the same instance and
reach each other on `localhost`. `dependsOn` holds a container back
until the ones it names pass their startup probes:

```typescript
{
  main: import.meta.url,
  template: {
    containers: [
      { dependsOn: ["cache"] },
      {
        name: "cache",
        image: "docker.io/library/redis:7",
        startupProbe: { tcpSocket: { port: 6379 } },
      },
    ],
  },
}
```

Only the first container takes requests.

## Run your own program as a sidecar

A `GCP.Run.Container` is a program of its own, bundled into its own
image. Return methods next to `fetch`:

```typescript
// src/worker.ts
import * as GCP from "@alchemy.run/gcp";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/http/HttpServerResponse";

export default class Worker extends GCP.Run.Container<Worker>()(
  "Worker",
  { main: import.meta.url, port: 3000, startupProbe: { httpGet: { path: "/health" } } },
  Effect.gen(function* () {
    return {
      greet: (name: string) => Effect.succeed(`hello ${name}`),
      fetch: Effect.succeed(HttpServerResponse.text("ok")),
    };
  }),
) {}
```

`GCP.Run.bindContainer` adds it to the service's revision, starts the
service after it, and returns a typed client that calls it on
`localhost`:

```typescript
// src/api.ts
import * as GCP from "@alchemy.run/gcp";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/http/HttpServerResponse";
import Worker from "./worker.ts";

export default class Api extends GCP.Run.Service<Api>()(
  "Api",
  { main: import.meta.url },
  Effect.gen(function* () {
    const worker = yield* GCP.Run.bindContainer(Worker);
    return {
      fetch: Effect.gen(function* () {
        return HttpServerResponse.text(yield* worker.greet("sam"));
      }),
    };
  }),
) {}
```

Bindings inside a Container work as they do in the service: their env
lands on the container and their roles go to the service's account.
For a protocol other than HTTP, `GCP.Run.bindPort(Cache, 6379)` returns
the sidecar's address instead.

## Receive events

Event sources make Google call your service. Each one creates the
delivery (a push subscription, a scheduler job, an Eventarc trigger)
and lets only that delivery in, so the service can stay private:

```typescript
yield* GCP.PubSub.consumeTopicMessages(Orders, (messages) =>
  messages.pipe(Stream.runForEach(({ message }) => handle(message))),
);
// …provided with Effect.provide(GCP.Run.TopicEventSource)
```

See [Pub/Sub](/gcp/messaging/pubsub),
[Cloud Scheduler](/gcp/messaging/scheduler),
[Storage events](/gcp/messaging/storage-events), and
[Eventarc](/gcp/messaging/eventarc).

## Run without `main`

Leave out `main` to deploy any container image:

```typescript
const hello = yield* GCP.Run.Service("Hello", {
  invokerIamDisabled: true,
  template: {
    containers: [{ image: "us-docker.pkg.dev/cloudrun/container/hello" }],
  },
});
```

A `GCP.Run.Container` can run next to the image. List it in
`containers`; its bindings' roles go to the service's account and the
sidecars it binds come along:

```typescript
const worker = yield* Worker;
const proxy = yield* GCP.Run.Service("Proxy", {
  template: {
    containers: [
      { image: proxyImage, ports: [{ containerPort: 8080 }], dependsOn: [worker.name] },
      worker,
    ],
  },
});
```

`worker.name` is an Output. Alchemy deploys `Worker` first and puts
the name it gave the container into `dependsOn`, so the proxy starts
after it. Use the Output rather than writing the name out: the name
comes from the Container's id or its `name` prop. The Container has to
be in the same `containers` list.

A listed Container can wait for another listed Container the same way:

```typescript
const web = yield* GCP.Run.Container("Web", {
  image: "docker.io/library/nginx:1.27-alpine",
  port: 80,
  startupProbe: { tcpSocket: {} },
});
const cache = yield* GCP.Run.Container("Cache", {
  image: "docker.io/library/redis:7-alpine",
  port: 6379,
  startupProbe: { tcpSocket: {} },
  dependsOn: [web.name],
});
const proxy = yield* GCP.Run.Service("Proxy", {
  template: {
    containers: [
      { image: proxyImage, ports: [{ containerPort: 8080 }], dependsOn: [cache.name] },
      cache,
      web,
    ],
  },
});
```

```text
web ✓ → cache ✓ → proxy ✓ → requests
```

## Destroy

`alchemy destroy` deletes the service, its image repository, and the
service account Alchemy created for it, and revokes that account's
roles.
