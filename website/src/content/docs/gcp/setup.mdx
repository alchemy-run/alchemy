Create a GCP project and a service-account key with enough IAM to
create the resources you will deploy (Cloud Run Admin, Storage Admin,
Pub/Sub Admin, and Service Account Admin for per-host `alch-*`
accounts).

Register the provider next to any other clouds:

```typescript
// alchemy.run.ts
import * as Alchemy from "alchemy";
import * as GCP from "alchemy/GCP";
import * as Effect from "effect/Effect";

export const App = Alchemy.Stack(
  "App",
  { providers: GCP.providers(), state: Alchemy.localState() },
  Effect.gen(function* () {
    return {};
  }),
);
```

## Credentials

Run `alchemy profile edit --add GCP`. Choose **Service account JSON**
and point at the key file. Alchemy stores it under
`~/.alchemy/credentials/<profile>/`.

In CI (`CI=true`), Alchemy skips profiles. Set:

- `GOOGLE_PROJECT_ID` — project id
- `GOOGLE_APPLICATION_CREDENTIALS` — path to the key file

or `GOOGLE_ACCESS_TOKEN` plus `GOOGLE_PROJECT_ID` for a short-lived
token.

`GOOGLE_CLOUD_PROJECT` is accepted as an alias of `GOOGLE_PROJECT_ID`.

See [Profiles](/environments/profiles) for how credentials are stored
and switched.
