Install Alchemy, create a Stack with a Cloud Storage bucket, and
deploy it.

## Prerequisites

- [Bun](https://bun.sh) (recommended) or Node.js 22+
- A GCP project and service-account key — see [Setup](/gcp/setup)

## Write the Stack

Create `alchemy.run.ts`:

```typescript
import * as Alchemy from "alchemy";
import * as GCP from "alchemy/GCP";
import * as Effect from "effect/Effect";

export const App = Alchemy.Stack(
  "App",
  { providers: GCP.providers(), state: Alchemy.localState() },
  Effect.gen(function* () {
    const bucket = yield* GCP.Storage.Bucket("assets", {
      forceDestroy: true,
    });
    return { bucketName: bucket.bucketName };
  }),
);
```

`forceDestroy: true` empties the bucket on `alchemy destroy`.

## Deploy

```sh
bun alchemy deploy --profile testing
```

The bucket name is generated from the stack, stage, and logical id.
