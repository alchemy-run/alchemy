Everything in the Stack is owned by Alchemy labels. Destroy it:

```sh
bun alchemy destroy --profile testing
```

The Function is deleted, then the minted `alch-*` runtime service
account, then the topic and the bucket (`forceDestroy` empties
objects first).

If a container image build failed after the service account was
minted, Alchemy deletes that `alch-*` account on the failed
greenfield reconcile so it does not leak.
