Schemaless RPC is the default for calls between services you deploy
together. A runtime returns methods next to `fetch`, another resource
binds it, and the caller gets a typed client. Nothing is validated at
runtime, so a call pays no per-request decode.

## What a member may be

An RPC member is a function, with any arguments, that returns an
`Effect` or a `Stream`. The types reject anything else:

```typescript
import * as Cloudflare from "alchemy/Cloudflare";
import * as Effect from "effect/Effect";
import * as Schedule from "effect/Schedule";
import * as Stream from "effect/Stream";
import * as HttpServerResponse from "effect/unstable/http/HttpServerResponse";

export default class Greeter extends Cloudflare.Worker<Greeter>()(
  "Greeter",
  { main: import.meta.url },
  Effect.gen(function* () {
    return {
      // ✅ a function returning an Effect
      greet: (name: string) => Effect.succeed(`hello ${name}`),
      // ✅ a function returning a Stream
      tick: (n: number) =>
        Stream.iterate(0, (i) => i + 1).pipe(
          Stream.take(n),
          Stream.schedule(Schedule.spaced("100 millis")),
        ),
      // ❌ rejected, a plain value
      // version: "1.0",
      // ❌ rejected, a function returning a plain value
      // shout: (s: string) => s.toUpperCase(),
      // Bare Effects and Streams type-check too, but they serve the host
      // (`fetch` is one), so declare the RPC surface as functions.
      fetch: Effect.gen(function* () {
        return HttpServerResponse.text("ok");
      }),
    };
  }),
) {}
```

A rejected member fails at declaration, as an assignability error on
the constructor Effect you pass to the host class. The pattern is the
same on every [runtime](/infrastructure-as-effects/runtime), and the
deployed runtime satisfies requirements like `RuntimeContext`.

## The typed client

The class carries the type, so there is no schema.
`class Greeter extends Cloudflare.Worker<Greeter>()(...)` gives the
class the construct signature `new (_: never): Shape & ...`, which
makes its instance type exactly the shape the constructor returns.

Yielding the class gives a value that carries that shape as a phantom
type, `Rpc<Shape> = { "~alchemy/rpc": Shape }`. A binder reads it back
and returns the client:

```typescript
// in another resource's Effectful Constructor:
const target = yield* Cloudflare.Workers.bindWorker(Greeter);

// in the interface it returns:
const greeting = yield* target.greet("world"); // typed from Greeter's shape
```

Each pairing that has a stub has its own binder:

- **Worker → Worker**: `Cloudflare.Workers.bindWorker(Class)`.
- **Worker → Durable Object**: `yield* DOClass`, then `.getByName(name)`.
- **Durable Object → Container**: `yield* ContainerClass` inside the Durable Object, with `Cloudflare.Containers.layer(...)` provided.
- **Lambda → MicroVM**: `AWS.Lambda.connectMicrovm(Image, { endpoint, authToken })`.
- **Railway Service or Function**: `Railway.bindService(Class)` or `Railway.bindFunction(Class)`.

Lambda → Lambda and ECS Tasks have no schemaless stub. Use the
`AWS.Lambda.InvokeFunction` binding or [Effect RPC](/apis/effect-rpc)
there. The hub pages show a full caller for each pairing.

Every stub is a Proxy whose get-trap dispatches over the wire, so
every property access is a remote call. The host's own `fetch` and
`connect` pass through to the underlying binding. A stub has no local
fields and consists only of its methods.

## What crosses the wire

RPC uses one wire protocol over two carriers:

- **Native channel**: Cloudflare service bindings and Durable Object stubs move values by structured clone.
- **Fetch transport**: everything else, including Containers and MicroVMs. Each call is a `POST {base}/__rpc__/{name}` whose body is the JSON-encoded argument array. The response is a JSON value, a JSON error envelope, or an NDJSON stream flagged by the `x-alchemy-rpc-stream` header.

Arguments and results must survive the codec:

- Values move by structured clone on the native channel and as JSON on the fetch transport.
- Stream elements are JSON values or `Uint8Array`. The fetch transport base64-tags binary so it round-trips.
- Functions and callbacks don't serialize.
- Class identity is stripped, except for error classes a Durable Object declares (see [Errors over the wire](#errors-over-the-wire)).

Neither the stub nor the server validates at runtime, so nothing
sanitizes what arrives. That is safe between code you deploy together
and type from the same shape. [Trust boundaries](/apis#trust-boundaries)
explains when to add a schema instead.

Railway Services and Functions use a lighter dispatcher on the
private mesh. See [Railway Services](/railway/compute/services#schemaless-rpc)
for its limits and errors.

## Streams

A stub call returns one value that is both an Effect and a Stream.
The call is asynchronous, so the stub can't know which one the remote
method returns. Its declared type mirrors the remote shape, so you use
the value the way the method declares:

```typescript
const greeting = yield* stub.greet(name);           // value method, yield* it as an Effect
const firstFive = stub.tick(n).pipe(Stream.take(5)); // streaming method, pipe it as a Stream
```

- **Backpressure**: Streams are pulled lazily. `Stream.take(5)` works on an infinite remote Stream, and the server stops producing when the client stops consuming.
- **Combinators**: pipe a returned Stream through any `Stream.*` combinator, including straight onto an HTTP response.
- **Bytes**: byte streams (`Uint8Array`) round-trip alongside JSON object streams.
- **Failures**: a mid-stream failure travels as a trailing error marker. It surfaces as `RpcRemoteStreamError`, with the encoded inner error on `.error`. Values emitted before the failure are delivered.

## Errors over the wire

Typed failures cross the wire, so the caller can recover from a tagged
error the callee fails with:

```typescript
import * as Data from "effect/Data";

class KeyMissing extends Data.TaggedError("KeyMissing")<{
  readonly key: string;
}> {}

// callee: a method that fails with a tagged error
get: (key: string) =>
  kv.get(key).pipe(
    Effect.flatMap((value) =>
      value === null
        ? Effect.fail(new KeyMissing({ key }))
        : Effect.succeed(value),
    ),
  ),

// caller: `_tag` and `key` survive the wire
const value = yield* stub.get(key).pipe(
  Effect.catchTag("KeyMissing", (e) => Effect.succeed(`missing: ${e.key}`)),
);
```

- **Tagged errors** keep `_tag` and all own enumerable fields and arrive as plain structs. `Effect.catchTag` matches because it keys on `_tag`.
- **Class identity** doesn't survive by default, so `e instanceof KeyMissing` is `false`. A Cloudflare Durable Object can declare its error classes so callers get real instances. See [Schemaless RPC on Cloudflare › Typed errors across the boundary](/cloudflare/apis/schemaless-rpc#typed-errors-across-the-boundary).
- **Plain `Error`s** keep `name`, `message`, and `stack`.
- **Unknown methods** fail with `RpcCallError`.
- **Defects** are not enveloped. The call rejects and surfaces as `RpcCallError`.
