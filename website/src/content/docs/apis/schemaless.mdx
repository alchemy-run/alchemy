Schemaless RPC is the default for internal communication. Any Function or Server returns `{ fetch, ...rpcs }`; any other Resource that binds to it gets a fully typed client — Worker to Worker, Worker to Durable Object, Container into a Worker, MicroVM into a Lambda Function. Serialization is handled automatically. There is no schema, no runtime checking, and no per-request validation cost.

## The contract

A Function or Server's init Effect returns a Shape: a `fetch` handler plus any number of RPC members, where each member is an Effect, a Stream, or a function returning either.

```typescript
import * as Cloudflare from "alchemy/Cloudflare";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/unstable/http/HttpServerResponse";

export default class BindingTargetWorker extends Cloudflare.Worker<BindingTargetWorker>()(
  "BindingTargetWorker",
  {
    main: import.meta.url,
  },
  Effect.gen(function* () {
    return {
      greet: (name: string) => Effect.succeed(`hello ${name}`),
      fetch: Effect.gen(function* () {
        return HttpServerResponse.text("hello from BindingTargetWorker");
      }),
    };
  }),
) {}
```

The Shape *is* the class instance type: `class T extends Cloudflare.Worker<T>()(...)` makes the class's instance type equal to whatever the init Effect returns, and yielding the class produces a value that carries the Shape — so every binder infers the client type with zero extra declarations.

## Typed clients by binding

Bind the class, get the client — `target.greet(name)` is typed end-to-end from the callee's Shape.

```typescript
import * as Cloudflare from "alchemy/Cloudflare";
import * as Effect from "effect/Effect";
import { HttpServerRequest } from "effect/unstable/http/HttpServerRequest";
import * as HttpServerResponse from "effect/unstable/http/HttpServerResponse";
import BindingTargetWorker from "./binding-target-worker.ts";

export default class BindingEffectCaller extends Cloudflare.Worker<BindingEffectCaller>()(
  "BindingEffectCaller",
  {
    main: import.meta.url,
  },
  Effect.gen(function* () {
    const target = yield* Cloudflare.Workers.bindWorker(BindingTargetWorker);

    return {
      fetch: Effect.gen(function* () {
        const request = yield* HttpServerRequest;
        const name =
          new URL(request.url, "http://x").searchParams.get("name") ?? "world";
        const greeting = yield* target.greet(name);
        return HttpServerResponse.text(String(greeting));
      }),
    };
  }),
) {}
```

`bindWorker` registers a service Binding on the host at plan time and returns a proxy typed as the target's Shape that resolves the binding stub from the Worker's environment at call time. At runtime, calls ride Cloudflare's native JSRPC over the service-binding fabric — they never touch the public internet.

## Every runtime pair

### Worker → Durable Object

A Durable Object's Shape mixes value methods and streaming methods freely.

```typescript
import * as Cloudflare from "alchemy/Cloudflare";
import * as Effect from "effect/Effect";
import * as Schedule from "effect/Schedule";
import * as Stream from "effect/Stream";

const KV = Cloudflare.KV.Namespace("DurableObjectWorkerEnvironmentKV", {
  title: "durable-object-worker-environment-kv",
});

export class WorkerEnvironmentKVObject extends Cloudflare.DurableObject<WorkerEnvironmentKVObject>()(
  "WorkerEnvironmentKVObject",
  Effect.gen(function* () {
    const kv = yield* Cloudflare.KV.ReadWriteNamespace(KV);

    return Effect.gen(function* () {
      return {
        put: (key: string, value: string) => kv.put(key, value),
        get: (key: string) => kv.get(key),
        tick: (n: number) =>
          Stream.iterate(0, (i) => i + 1).pipe(
            Stream.take(n),
            Stream.schedule(Schedule.spaced("100 millis")),
          ),
      };
    });
  }).pipe(Effect.provide(Cloudflare.KV.ReadWriteNamespaceBinding)),
) {}
```

`getByName(name)` returns a stub mirroring the Shape: value methods `yield*` as Effects, and a streaming method's result forwards straight onto an HTTP response (condensed from the fixture's two routes):

```typescript
Effect.gen(function* () {
  const objects = yield* WorkerEnvironmentKVObject;

  return {
    fetch: Effect.gen(function* () {
      // value methods yield* as Effects:
      const object = objects.getByName("default");
      yield* object.put(key, "ok").pipe(Effect.orDie);
      const value = yield* object.get(key).pipe(Effect.orDie);

      // streaming methods pipe as Streams — forwarded onto the response:
      const stream = objects
        .getByName("tick")
        .tick(n)
        .pipe(
          Stream.map((i) => `${i}\n`),
          Stream.encodeText,
        );
      return HttpServerResponse.stream(stream, {
        headers: { "content-type": "text/plain" },
      });
    }),
  };
})
```

Wiring details live in [Durable Objects](/cloudflare/compute/durable-objects#schemaless-rpc); to bind another script's Durable Object with `Counter.from(WorkerA)`, see [Cross-Worker Durable Objects](/cloudflare/compute/cross-worker-durable-object).

### Container into a Worker

Containers run inside Durable Objects, so the shape is Container → Durable Object → Worker: `Cloudflare.Containers.layer(MyContainer, ...)` is provided on a Durable Object, and a Worker fronts the DO. The Container declares its Shape as a type parameter:

```typescript
export class MyContainer extends Cloudflare.Container<
  MyContainer,
  {
    ping: () => Effect.Effect<string>;
    readObject: (
      key: string,
    ) => Effect.Effect<string | null, never, RuntimeContext>;
  }
>()("EffectfulContainer") {}
```

The Durable Object yields the class and calls it like any other typed client:

```typescript
Effect.gen(function* () {
  const container = yield* MyContainer;

  return Effect.gen(function* () {
    return {
      ping: () => container.ping(),
      // Read the object from inside the container over RPC.
      readObjectRpc: (key: string) => container.readObject(key),
    };
  });
}).pipe(
  Effect.provide(
    Cloudflare.Containers.layer(MyContainer, { enableInternet: true }),
  ),
)
```

Image builds, ports, and lifecycle live in [Containers](/cloudflare/compute/containers).

### MicroVM into a Lambda Function

A MicroVM image declares its Shape the same way:

```typescript
export class Sandbox extends AWS.Lambda.MicrovmImage<
  Sandbox,
  {
    hello: (message: string) => Effect.Effect<string>;
  }
>()("MicrovmSandbox") {}
```

The Lambda Function connects to a running instance and gets the typed stub:

```typescript
const sandbox = yield* AWS.Lambda.connectMicrovm(Sandbox, {
  endpoint: vm.endpoint,
  authToken,
});
const reply = yield* sandbox.hello(message).pipe(
  Effect.retry({
    schedule: Schedule.exponential("500 millis"),
    times: 8,
  }),
);
```

Launching, suspending, and authenticating MicroVMs is covered in [MicroVMs](/aws/compute/microvms).

### Everything else

- **Dynamically-loaded Workers** get the same typed stub over the loader entrypoint — a Worker loaded at runtime speaks schemaless RPC exactly like a statically bound one.
- **Non-Effect callers**: `Cloudflare.toRpcAsync` wraps a binding stub in a Promise-shaped proxy, and plain async Workers can call `env.TARGET.greet(name)` directly over the service binding — see [Vite SPA](/cloudflare/frontend/vite-spa).

## Streams and errors over the wire

Streams work in both directions. The stub can't know synchronously whether the remote method returns a value or a Stream — the call is asynchronous — so every stub call is typed as *both*: its declared type mirrors the remote Shape verbatim, which means value methods `yield*` as Effects and streaming methods `.pipe` through `Stream.*` combinators, including forwarding a returned Stream straight onto an HTTP response as shown above. A failure mid-stream travels as a trailing error marker and surfaces on the consumer as `RpcRemoteStreamError`.

Typed failures cross the wire intact: `Effect.fail(new MyTaggedError(...))` on the callee is recoverable on the caller with `_tag` and all own enumerable fields preserved — but as a plain struct, not a class instance. The following pair illustrates the codec behavior (verified by the wire-codec unit tests):

```typescript
class KeyMissing extends Data.TaggedError("KeyMissing")<{
  readonly key: string;
}> {}

// callee — a Durable Object method that fails with a tagged error:
get: (key: string) =>
  kv.get(key).pipe(
    Effect.flatMap((value) =>
      value === null
        ? Effect.fail(new KeyMissing({ key }))
        : Effect.succeed(value),
    ),
  ),

// caller — `_tag` and `key` survive the wire; class identity does not:
const value = yield* object.get(key).pipe(
  Effect.catchTag("KeyMissing", (e) =>
    Effect.succeed(`missing: ${e.key}`),
  ),
);
```

`Effect.catchTag` matches because `_tag` is preserved; `e instanceof KeyMissing` is `false` because the decoded error is a plain struct. Plain `Error`s keep `name`/`message`/`stack`. Defects are not enveloped — on native JSRPC the call rejects and surfaces as `RpcCallError`; on the fetch transport they fail the response.

## Limits (and the point)

Values must survive the wire codec:

- **Native JSRPC** (Worker → Worker, Worker → Durable Object) carries values by structured clone.
- **The fetch transport** (Containers, MicroVMs) carries each call as `POST /__rpc__/{name}` with a JSON args array; responses are JSON, and streams are NDJSON.
- **Stream elements** must be JSON values or `Uint8Array`.
- **Class identity is always stripped** — a `Schema.Class` instance arrives as a plain struct.
- **Functions and callbacks don't serialize** — every property access on the stub is a remote method call, nothing more.

There is no runtime validation of arguments or results anywhere. That is the point — no schema to maintain, no per-request decode cost — and the trade-off: nothing sanitizes what arrives. When data crosses a trust boundary — exposed to a web app or an external service — or when class identity must survive the hop, reach for [Effect RPC](/apis/effect-rpc).
