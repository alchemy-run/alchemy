PlanetScale is likely the fastest managed Postgres and MySQL you can buy, at a price that undercuts the large clouds. Its Metal clusters run on local NVMe drives instead of network storage. Its MySQL is built on Vitess, which shards a database across many servers so it can outgrow one machine. And every database can be branched like code, so schema changes are tested and deployed like a pull request.

## A taste

A database, a branch for this stage, and a role to connect with:

```typescript title="alchemy.run.ts"
const database = yield* Planetscale.PostgresDatabase("app-db", {
  region: { slug: "us-east" },
  clusterSize: "PS_10",
  migrations: "./migrations",
});

const branch = yield* Planetscale.PostgresBranch("app-branch", { database, isProduction: false });

const role = yield* Planetscale.PostgresRole("app-role", {
  database,
  branch,
  inheritedRoles: ["postgres"],
});
```

The role's `origin` connects anything that speaks Postgres. On Cloudflare, give it to Hyperdrive:

```typescript title="alchemy.run.ts"
const hyperdrive = yield* Cloudflare.Hyperdrive.Connection("app-hyperdrive", { origin: role.origin });
```

## Where to start

**New to PlanetScale?** [What is PlanetScale?](/planetscale/what-is-planetscale) walks through organizations, databases, engines, branches, credentials, connections, migrations and backups, once each, and shows how Alchemy models every one.

**Ready to connect?** [Setup](/planetscale/setup) adds PlanetScale to your profile.

**Want the whole picture?** Start with the engine you use: [Postgres](/planetscale/data/postgres) or [MySQL](/planetscale/data/mysql). Then how you work with a database: [Credentials](/planetscale/data/credentials), [Migrations](/planetscale/data/migrations) and [Backups & restores](/planetscale/data/backups).

**Building an app?** [Preview branches per PR](/planetscale/guides/preview-branches) gives every pull request its own branch, and [Drizzle ORM](/planetscale/guides/drizzle) adds typed queries and generated migrations. On Cloudflare, [Hyperdrive](/cloudflare/data/hyperdrive) connects a Worker to the database.

Every resource is in the generated [API reference](/providers).
