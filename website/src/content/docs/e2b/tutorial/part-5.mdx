## Deploy once per test file

```typescript title="test/integ.test.ts"
import { expect } from "bun:test";
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as E2B from "@alchemy.run/e2b";
import * as Test from "@alchemy.run/test/Bun";
import * as Alchemy from "alchemy";
import * as Effect from "effect/Effect";
import * as HttpClientRequest from "effect/http/HttpClientRequest";
import * as Layer from "effect/Layer";
import Stack from "../alchemy.run.ts";

const { test, beforeAll, afterAll, deploy, destroy } = Test.make({
  providers: Layer.mergeAll(Cloudflare.providers(), E2B.providers()),
  state: Alchemy.localState(),
});

const stack = beforeAll(deploy(Stack));
afterAll.skipIf(!!process.env.NO_DESTROY)(destroy(Stack));
```

The test deploys the Stack to a stage of its own, template and snapshot included, and destroys it afterwards.

## Check a sandbox starts from Warm

```typescript title="test/integ.test.ts"
test(
  "starts each sandbox from the Warm snapshot",
  Effect.gen(function* () {
    const { url } = yield* stack;
    const res = yield* Test.executeWhenReady(
      HttpClientRequest.post(`${url}/run`).pipe(HttpClientRequest.bodyText("pnpm --version")),
    );
    const body = (yield* res.json) as { exitCode: number };
    expect(body.exitCode).toBe(0);
  }),
  { timeout: 180_000 },
);
```

`pnpm` is only there if the sandbox booted from `Warm`. The Worker kills the sandbox when the request ends, so none is left behind.

## Run it

<PackageManagers script={`bun test`} />

The first run builds the template, which takes a minute or two. Set `NO_DESTROY=1` to keep the deployment, and its builds, between runs while you iterate.
