---
title: drift
description: Detect infrastructure drift by re-observing the cloud, and repair it with deploy --detect-drift.
---

```sh
alchemy drift [options]
```

Re-observe every deployed resource and compare the live cloud state
against what alchemy last persisted. The result renders exactly like a
deploy plan: unchanged resources are no-ops, out-of-band edits show as
**drifted**, and resources deleted behind alchemy's back show as
**missing**.

`drift` only reports. It never changes the cloud or state, and it doesn't
run your stack program.

To repair drift, run [`alchemy deploy --detect-drift`](/cli/deploy). It runs
the same check and, once you approve (or pass `--yes`), restores drifted and
missing resources to the last deployed state, then deploys. The deploy
refreshes the stack's outputs, so they point at any resource the repair
recreated.

## Exit codes

| Code | Meaning                                            |
| ---- | -------------------------------------------------- |
| `0`  | No drift                                           |
| `1`  | The check failed, e.g. a resource couldn't be read |
| `2`  | Drift was found                                    |

A scheduled job can alert on `2` without parsing the plan.

## Flags

| Option                | Description                                                        |
| --------------------- | ------------------------------------------------------------------ |
| `--stage <name>`      | Stage to check (defaults to `$ALCHEMY_STAGE` or `live_$USER`)       |
| `--profile <name>`    | Auth profile to use (defaults to `$ALCHEMY_PROFILE` or `default`) |
| `--env-file <path>`   | Load environment variables from a file                             |
| `--config, -c <file>` | Stack file to check (defaults to `alchemy.run.ts`)                 |

## Examples

```sh
# Report drift for the default stage
alchemy drift

# Check production; exits 2 when it has drifted
alchemy drift --stage prod

# Repair drift and deploy, without a prompt
alchemy deploy --stage prod --detect-drift --yes
```
