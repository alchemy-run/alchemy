[better-auth](https://better-auth.com) signs users in with GitHub, Google and many other providers, and keeps their sessions in your database. A Domain Api reads that session in middleware, so every command and view knows who is asking.

Take a small notes app on Cloudflare, with an [Effect UI](https://ui.effect.website) UI: users sign in with GitHub or Google and write notes only they can read. The whole app is in [`examples/cloudflare-domain-better-auth`](https://github.com/alchemy-run/alchemy/tree/main/examples/cloudflare-domain-better-auth).

## Declare who is asking

```typescript

/** A user's id, as better-auth assigns it. */
export const UserId = Schema.String.pipe(Schema.brand("UserId"));
export type UserId = typeof UserId.Type;
```

```typescript
// src/CurrentUser.context.ts
import * as Domain from "@alchemy.run/domain";
import * as Schema from "effect/Schema";
import { UserId } from "./User.id.ts";

/** The signed-in user behind a request. */
export class CurrentUser extends Domain.RequestContext<CurrentUser>()(
  "Notes/CurrentUser",
  Schema.Struct({ userId: UserId, name: Schema.String }),
) {}
```

`CurrentUser` is the user behind a request. It has a schema, so it travels with each command to the notebook that decides it.

## Declare the middleware

```typescript
// src/Session.middleware.ts
import * as RpcMiddleware from "effect/rpc/RpcMiddleware";
import * as Schema from "effect/Schema";
import { CurrentUser } from "./CurrentUser.context.ts";

/** The request has no session. */
export class Unauthorized extends Schema.TaggedError<Unauthorized>()("Unauthorized", {}) {}

/** Provides the signed-in user, from the session cookie better-auth set. */
export class Session extends RpcMiddleware.Service<Session, { provides: CurrentUser }>()(
  "Notes/Session",
  { error: Unauthorized },
) {}
```

`Session` provides `CurrentUser`, or fails with `Unauthorized`. The domain only declares it; the Worker implements it with better-auth below.

```typescript
export class NoteWritten extends Domain.Event("NoteWritten", {
  text: Schema.String,
  author: Schema.String,
}) {}

/** Write a note in your own notebook. */
export class WriteNote extends Domain.Command("WriteNote", {
  middleware: [Session],
  input: { userId: UserId, text: Schema.NonEmptyString },
  events: [NoteWritten],
  rejects: [NotYours],
}) {}
```

Listing `Session` makes the Api run it before every `WriteNote`.

## Check the user in decide

```typescript
// src/Notebook.aggregate.ts
import * as Domain from "@alchemy.run/domain";
import * as Effect from "effect/Effect";
import * as Schema from "effect/Schema";
import { CurrentUser } from "./CurrentUser.context.ts";
import { NotYours } from "./NotYours.rejection.ts";
import { UserId } from "./User.id.ts";
import { NoteWritten, WriteNote } from "./WriteNote.command.ts";

/** Each user's notebook, keyed by their id. */
export class Notebook extends Domain.Aggregate("Notebook", {
  id: UserId,
  state: Schema.Struct({ notes: Schema.Int }),
  initial: { notes: 0 },
  commands: [WriteNote],
  keyOf: (cmd) => cmd.userId,
  decide: {
    WriteNote: Effect.fn(function* (_, cmd, { id }) {
      const user = yield* CurrentUser;
      if (user.userId !== id) return yield* new NotYours();
      return [new NoteWritten({ text: cmd.text, author: user.name })];
    }),
  },
  evolve: {
    NoteWritten: (s) => ({ notes: s.notes + 1 }),
  },
}) {}
```

Each user has a notebook keyed by their id. `decide` reads `CurrentUser` and refuses a notebook that isn't theirs.

## Guard a view

```typescript
// src/Notes.view.ts
import * as Domain from "@alchemy.run/domain";
import * as Effect from "effect/Effect";
import * as Schema from "effect/Schema";
import { CurrentUser } from "./CurrentUser.context.ts";
import { Notebook } from "./Notebook.aggregate.ts";
import { NotYours } from "./NotYours.rejection.ts";
import { Session } from "./Session.middleware.ts";

/** The notes in a notebook. Only its owner may read them. */
export class Notes extends Domain.View("Notes", {
  from: [Notebook],
  key: Notebook,
  middleware: [Session],
  rejects: [NotYours],
  state: Schema.Struct({ notes: Schema.Array(Schema.String) }),
  initial: { notes: [] },
  evolve: {
    NoteWritten: (v, e) => ({ notes: [...v.notes, e.text] }),
  },
}) {}

/** Only a notebook's owner reads its notes. */
export const NotesLive = Notes.toLayer(
  Effect.succeed(
    Effect.fn(function* (request) {
      const user = yield* CurrentUser;
      if (request.key.id !== user.userId) return yield* new NotYours();
    }),
  ),
);
```

## Configure better-auth

```typescript
// src/Auth.ts
import { BetterAuth, type BetterAuthApiError } from "@alchemy.run/better-auth";
import type { RuntimeContext } from "alchemy";
import type { HttpEffect } from "alchemy/Http";
import * as Config from "effect/Config";
import * as Context from "effect/Context";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import * as Option from "effect/Option";
import * as Redacted from "effect/Redacted";

/** What the Worker needs from better-auth: its routes, and the session behind a request. */
export class Auth extends Context.Service<
  Auth,
  {
    readonly fetch: HttpEffect<RuntimeContext>;
    readonly getSession: (
      headers: Headers,
    ) => Effect.Effect<
      { readonly user: { readonly id: string; readonly name: string } } | null,
      BetterAuthApiError,
      RuntimeContext
    >;
  }
>()("Notes/Auth") {}

/** better-auth with GitHub and Google sign-in, its tables in the Worker's database. */
export const AuthLive = Layer.effect(
  Auth,
  Effect.gen(function* () {
    const baseURL = yield* Config.String("AUTH_BASE_URL").pipe(Config.option);
    return yield* BetterAuth({
      basePath: "/api/auth",
      baseURL: Option.getOrUndefined(baseURL),
      socialProviders: {
        github: {
          clientId: yield* Config.String("GITHUB_CLIENT_ID"),
          clientSecret: Redacted.value(yield* Config.Redacted("GITHUB_CLIENT_SECRET")),
        },
        google: {
          clientId: yield* Config.String("GOOGLE_CLIENT_ID"),
          clientSecret: Redacted.value(yield* Config.Redacted("GOOGLE_CLIENT_SECRET")),
        },
      },
    });
  }),
);
```

`AuthLive` creates better-auth with GitHub and Google. The `Auth` service names the two things the Worker needs from it: its routes and the session behind a request.

## Check the session

```typescript
// src/Session.ts
import { RuntimeContext } from "alchemy";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import { Auth } from "./Auth.ts";
import { CurrentUser } from "./CurrentUser.context.ts";
import { Session, Unauthorized } from "./Session.middleware.ts";
import { UserId } from "./User.id.ts";

/** The {@link Session} middleware: the user better-auth signed in, or Unauthorized. */
export const SessionLive = Layer.effect(
  Session,
  Effect.gen(function* () {
    const auth = yield* Auth;
    return (effect, { headers }) =>
      Effect.gen(function* () {
        const session = yield* auth
          .getSession(new Headers(Object.entries(headers)))
          .pipe(Effect.orDie);
        if (session === null) return yield* new Unauthorized();
        return yield* effect.pipe(
          Effect.provideService(CurrentUser, {
            userId: UserId.make(session.user.id),
            name: session.user.name,
          }),
        );
      }).pipe(Effect.provide(RuntimeContext.phantom));
  }),
);
```

`SessionLive` asks better-auth for the session behind the request's cookie. No session is `Unauthorized`; a session becomes `CurrentUser`.

## Serve the Api from a Worker

```typescript
// src/Database.ts
import * as Cloudflare from "@alchemy.run/cloudflare";

/** better-auth's users, accounts and sessions. */
export const AuthDb = Cloudflare.D1.Database("AuthDb");
```

```typescript
// src/NotesWorker.ts
import { CloudflareD1 } from "@alchemy.run/better-auth/CloudflareD1";
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as DomainCloudflare from "@alchemy.run/domain/Cloudflare";
import * as Effect from "effect/Effect";
import { HttpServerRequest } from "effect/http/HttpServerRequest";
import * as Layer from "effect/Layer";
import { Auth, AuthLive } from "./Auth.ts";
import { AuthDb } from "./Database.ts";
import { NotesModel } from "./Notes.model.ts";
import { NotesLive } from "./Notes.view.ts";
import { NotesApi } from "./NotesApi.api.ts";
import { SessionLive } from "./Session.ts";

const ServerLive = SessionLive.pipe(
  Layer.provideMerge(AuthLive),
  Layer.provideMerge(NotesModel.layer(NotesLive)),
  Layer.provide(Layer.mergeAll(DomainCloudflare.layerDurableObjects(), CloudflareD1(AuthDb))),
);

/** Serves better-auth's routes under /api/auth, and the NotesApi under /api. */
export default class NotesWorker extends Cloudflare.Worker<NotesWorker>()(
  "NotesWorker",
  {
    main: import.meta.url,
    compatibility: { flags: ["nodejs_compat"] },
  },
  Effect.gen(function* () {
    const auth = yield* Auth;
    const api = yield* NotesApi;
    return {
      fetch: Effect.gen(function* () {
        const request = yield* HttpServerRequest;
        const path = new URL(request.url, "http://localhost").pathname;
        if (path.startsWith("/api/auth/")) return yield* auth.fetch;
        return yield* api.fetch;
      }),
    };
  }).pipe(Effect.provide(ServerLive)),
) {}
```

The Notes Worker serves better-auth's routes under `/api/auth` and the NotesApi under `/api`. `CloudflareD1(AuthDb)` keeps users and sessions in D1 and migrates its tables on deploy.

## Write the app

```typescript
// src/web/Notes.ts
import * as DomainEffectUI from "@alchemy.run/domain/EffectUI";
import { Command, Component, UiSchema } from "@effect/ui";
import { Html } from "@effect/ui/html";
import * as Effect from "effect/Effect";
import * as Option from "effect/Option";
import * as AsyncResult from "effect/reactivity/AsyncResult";
import * as Schema from "effect/Schema";
import { NotesApi } from "../NotesApi.api.ts";
import { UserId } from "../User.id.ts";
import { auth } from "./auth.ts";

/** The NotesApi as Effect UI Commands and queries: `WriteNote`, and the `Notes` View. */
export const NotesUI = DomainEffectUI.make(NotesApi);

export const User = Schema.Struct({ userId: UserId, name: Schema.String });
export type User = typeof User.Type;

const Provider = Schema.Literals(["github", "google"]);

export const NotesMessage = UiSchema.TaggedEnum({
  ClickedSignIn: { provider: Provider },
  ClickedSignOut: {},
  ChangedDraft: { text: Schema.String },
  SubmittedNote: {},
  SucceededWriteNote: {},
  Failed: { reason: Schema.String },
});

/** Send the browser to GitHub or Google; better-auth brings it back to `/` signed in. */
export const SignIn = Command.make(
  "notes/SignIn",
  { args: { provider: Provider } },
  ({ provider }) =>
    Effect.promise(() => auth.signIn.social({ provider, callbackURL: "/" })).pipe(
      Effect.map((result) =>
        NotesMessage.Failed({ reason: result.error?.message ?? "Redirecting" }),
      ),
    ),
);

/** Clear better-auth's session, then start over signed out. */
export const SignOut = Command.make("notes/SignOut", { args: {} }, () =>
  Effect.promise(() => auth.signOut()).pipe(
    Effect.andThen(Effect.sync(() => location.reload())),
    Effect.as(Component.noop),
  ),
);

/**
 * A signed-in user's notebook. The `Notes` View is a query: it shows the notes and follows
 * them live, and a written note arrives through it.
 */
export const NotebookNoDeps = Html.component({
  name: "Notebook",
  props: Schema.Struct({ user: User }),
  model: Schema.Struct({ draft: Schema.String, error: Schema.NullOr(Schema.String) }),
  message: NotesMessage,
  queries: {
    notes: { query: NotesUI.Notes, args: ({ props }) => ({ key: props.user.userId }) },
  },
}).make({
  init: () => ({ draft: "", error: null }),
  update: {
    ClickedSignIn: ($) => $.model,
    ClickedSignOut: ($) => $.run(SignOut.make({})),
    ChangedDraft: ($, { text }) => $.evolve({ draft: text }),
    SubmittedNote: ($) =>
      $.model.draft.trim() === ""
        ? $.model
        : $.evolve({ draft: "" }).run(
            // The session cookie goes with the call. A refusal keeps its reason.
            NotesUI.WriteNote.make({
              input: { userId: $.props.user.userId, text: $.model.draft },
            }).pipe(
              Command.match({
                onSuccess: () => NotesMessage.SucceededWriteNote(),
                onFailure: (failure) => NotesMessage.Failed({ reason: failure._tag }),
              }),
            ),
          ),
    // The note arrives through the View; success only clears an error.
    SucceededWriteNote: ($) => $.evolve({ error: null }),
    Failed: ($, { reason }) => $.evolve({ error: reason }),
  },
  view: (h, model) =>
    h.div(
      h.h1("Notes"),
      h.p(`Signed in as ${h.props.user.name}`),
      h.form.on("submit", NotesMessage.SubmittedNote()).children(
        h.input
          .attrs({ placeholder: "Write a note", "aria-label": "Note" })
          .value(model.draft)
          .on("input", ({ value }) => NotesMessage.ChangedDraft({ text: value })),
        h.button.attr("type", "submit").children("Save"),
      ),
      h.ul.attr("aria-label", "Notes").children(
        ...Option.match(AsyncResult.value(h.queries.notes), {
          onNone: () => [],
          onSome: ({ state }) =>
            Option.match(state, { onNone: () => [], onSome: ({ notes }) => notes }),
        }).map((note) => h.li(note)),
      ),
      h.button.on("click", NotesMessage.ClickedSignOut()).children("Sign out"),
      model.error !== null && h.p.attr("role", "alert").children(model.error),
    ),
});

/** The notebook with its Commands and queries; the entry provides the NotesApi client. */
export const Notebook = NotebookNoDeps.pipe(Component.provide(NotesUI.layer));

/** The app: sign-in buttons, or the signed-in user's notebook. */
export const NotesApp = Html.component({
  name: "NotesApp",
  props: Schema.Struct({ user: Schema.NullOr(User) }),
  model: Schema.Struct({ error: Schema.NullOr(Schema.String) }),
  message: NotesMessage,
}).make({
  init: () => ({ error: null }),
  update: {
    ClickedSignIn: ($, { provider }) => $.run(SignIn.make({ provider })),
    ClickedSignOut: ($) => $.model,
    ChangedDraft: ($) => $.model,
    SubmittedNote: ($) => $.model,
    SucceededWriteNote: ($) => $.model,
    Failed: ($, { reason }) => $.evolve({ error: reason }),
  },
  view: (h, model) =>
    h.props.user === null
      ? h.div(
          h.h1("Notes"),
          h.button
            .on("click", NotesMessage.ClickedSignIn({ provider: "github" }))
            .children("Sign in with GitHub"),
          h.button
            .on("click", NotesMessage.ClickedSignIn({ provider: "google" }))
            .children("Sign in with Google"),
          model.error !== null && h.p.attr("role", "alert").children(model.error),
        )
      : Notebook(h, { key: h.props.user.userId, props: { user: h.props.user } }),
});
```

`NotesUI` turns the NotesApi into Effect UI services with `@alchemy.run/domain/EffectUI`: a `WriteNote` Command and a `Notes` query. `SignIn` hands the browser to better-auth, which sends it to GitHub or Google and back to `/` signed in. The `Notebook` reads the `Notes` View as a query, so a new note arrives from the View, including notes written on another device; a command's success only clears an error. See [Integrate with Effect UI](/domain/effect-ui) for how Commands, queries and the client fit together.

## Start the app

```typescript
// src/web/entry.ts
import * as Domain from "@alchemy.run/domain";
import { BrowserHost } from "@effect/ui/html";
import * as Effect from "effect/Effect";
import * as FetchHttpClient from "effect/http/FetchHttpClient";
import * as Layer from "effect/Layer";
import * as Socket from "effect/socket/Socket";
import { NotesApi } from "../NotesApi.api.ts";
import { UserId } from "../User.id.ts";
import { auth } from "./auth.ts";
import { NotesApp } from "./Notes.ts";

// The session cookie is first-party, so every call and watch on /api carries it.
const NotesConnection = NotesApi.layerClient.pipe(
  Layer.provide(Domain.protocolWebSocket(`${location.origin}/api`)),
  Layer.provide(Layer.mergeAll(FetchHttpClient.layer, Socket.layerWebSocketConstructorGlobal)),
);

// Who better-auth says is signed in, before the app mounts.
const Main = Layer.unwrap(
  Effect.promise(() => auth.getSession()).pipe(
    Effect.map(({ data }) =>
      BrowserHost.mount(
        NotesApp,
        { user: data ? { userId: UserId.make(data.user.id), name: data.user.name } : null },
        document.getElementById("root")!,
      ),
    ),
  ),
).pipe(Layer.provide(NotesConnection));

Layer.launch(Main).pipe(Effect.runFork);
```

The app asks better-auth who is signed in, then mounts with that user as its props, connected to the NotesApi on its own origin. `Domain.protocolWebSocket` sends commands over HTTP and opens a WebSocket for each live read; the browser sends the session cookie with both.

## Serve the app and the Api from one origin

```typescript
// src/web/worker.ts
interface Fetcher {
  fetch(request: Request): Promise<Response>;
}

/**
 * The app's Worker: the Effect UI build, plus `/api` (better-auth's routes and
 * the NotesApi) forwarded to the Notes Worker. One origin for both, so the
 * session cookie is first-party and reaches every call and watch.
 */
export default {
  fetch(request: Request, env: { readonly ASSETS: Fetcher; readonly NOTES: Fetcher }) {
    const { pathname } = new URL(request.url);
    return pathname.startsWith("/api") ? env.NOTES.fetch(request) : env.ASSETS.fetch(request);
  },
};
```

The app's Worker serves the built page and forwards `/api` to the Notes Worker. One origin keeps better-auth's session cookie first-party, so it reaches every call and watch, and GitHub and Google send users back to the app's own URL.

## Declare the stack

```typescript
// alchemy.run.ts
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as DomainCloudflare from "@alchemy.run/domain/Cloudflare";
import * as Alchemy from "alchemy";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import NotesWorker from "./src/NotesWorker.ts";

export default Alchemy.Stack(
  "DomainBetterAuth",
  {
    providers: Layer.mergeAll(Cloudflare.providers(), DomainCloudflare.providers()),
    state: Cloudflare.state(),
  },
  Effect.gen(function* () {
    const notes = yield* NotesWorker;
    // The Effect UI app, built with Vite. Its Worker serves the build and
    // forwards /api to the Notes Worker, so the app and the Api share one origin.
    const app = yield* Cloudflare.Website.EffectUI("NotesApp", {
      main: "src/web/worker.ts",
      env: { NOTES: notes },
      assets: { runWorkerFirst: ["/api", "/api/*"] },
    });
    return { url: app.url.as<string>() };
  }),
);
```

`Cloudflare.Website.EffectUI` builds the app with Vite and deploys its Worker. `runWorkerFirst` sends `/api` through the Worker instead of the static files.

## Register a GitHub OAuth App

```text
http://localhost:1338/api/auth/callback/github
```

`alchemy dev` serves the app at the URL it prints, `http://localhost:1338` here. In GitHub **Settings → Developer settings → OAuth Apps → New OAuth App**, set the **Authorization callback URL** to that URL plus `/api/auth/callback/github`. [Sign in with GitHub](/better-auth/sign-in-providers/github#register-the-oauth-app) covers the form.

## Register a Google client

```text
http://localhost:1338/api/auth/callback/google
```

In the Google Cloud console, create a **Web application** client under **Google Auth platform → Clients** with the app's URL plus `/api/auth/callback/google` as its redirect URI. [Sign in with Google](/better-auth/sign-in-providers/google#name-the-app-on-the-consent-screen) covers the consent screen and client.

## Test the app

```typescript
// test/Notes.app.test.ts
import { HtmlLocator, HtmlScene } from "@effect/ui/html/testing";
import { Story } from "@effect/ui/testing";
import { describe, expect, it } from "@effect/vitest";
import * as Effect from "effect/Effect";
import * as Option from "effect/Option";
import { NotYours } from "../src/NotYours.rejection.ts";
import { UserId } from "../src/User.id.ts";
import { NotebookNoDeps, NotesApp, NotesMessage, NotesUI, SignIn } from "../src/web/Notes.ts";

const sam = { userId: UserId.make("u-sam"), name: "Sam" };
const notes = (...notes: Array<string>) => ({
  state: Option.some({ notes }),
  cursor: notes.length,
});
const note = HtmlLocator.role("textbox", { name: "Note" });
const listed = HtmlLocator.role("list", { name: "Notes" });

describe("NotesApp", () => {
  it.effect("signing in sends the browser to the chosen provider", () =>
    Effect.gen(function* () {
      const s = yield* Story.make(NotesApp, { user: null });
      s.send(NotesMessage.ClickedSignIn({ provider: "github" })).expectExact(SignIn);
      expect(s.pending[0]!.command.args).toEqual({ provider: "github" });
      s.resolve(SignIn, NotesMessage.Failed({ reason: "Redirecting" }));
      expect(s.model.error).toBe("Redirecting");
    }),
  );
});

describe("Notebook", () => {
  it.effect("writes a note to the user's notebook, and shows it from the View", () =>
    Effect.gen(function* () {
      const s = yield* HtmlScene.make(NotebookNoDeps, { user: sam });
      s.loaded("notes", notes())
        .type(note, "buy milk")
        .click(HtmlLocator.role("button", { name: "Save" }))
        .expectExact(NotesUI.WriteNote)
        .expect(note)
        .toHaveValue("");
      expect(s.pending[0]!.command.args).toMatchObject({
        input: { userId: sam.userId, text: "buy milk" },
      });
      // The note arrives through the View, not the command's answer.
      s.resolve(NotesUI.WriteNote, {
        commandId: "c-1",
        reply: undefined,
        receipt: { stream: "Notebook/u-sam", version: 1 },
        commits: [{ stream: "Notebook/u-sam", version: 1 }],
      })
        .expect(listed)
        .toHaveText("")
        .loaded("notes", notes("buy milk"))
        .expect(listed)
        .toHaveText("buy milk");
    }),
  );

  it.effect("shows why a note was refused", () =>
    Effect.gen(function* () {
      const s = yield* HtmlScene.make(NotebookNoDeps, { user: sam });
      s.loaded("notes", notes())
        .type(note, "not mine")
        .click(HtmlLocator.role("button", { name: "Save" }))
        .fail(NotesUI.WriteNote, { _tag: "Rejected", commandId: "c-1", rejection: new NotYours() })
        .expect(HtmlLocator.role("alert"))
        .toHaveText("Rejected");
    }),
  );
});
```

A Story drives a component's `update` and a Scene drives its view, with no browser or server. Every Command a step runs stays pending until the test resolves or fails it, and a query has no result until the test loads one, so each test says exactly what the app did and what came back.

## Test sign-in

A test can't sign in to GitHub or Google, so the example's test runs a local OpenID Connect provider with [`oauth2-mock-server`](https://www.npmjs.com/package/oauth2-mock-server) and adds it to better-auth with its `genericOAuth` plugin. The test signs users in through the real redirect, callback and session cookie, then calls the NotesApi over HTTP: a user reads their own notes, no session is `Unauthorized`, and someone else's notebook is `NotYours`. See [`test/SignIn.test.ts`](https://github.com/alchemy-run/alchemy/tree/main/examples/cloudflare-domain-better-auth/test/SignIn.test.ts).
