Every command and read starts with a question: who is asking? Middleware answers it before the request reaches the domain, and provides the answer as a request context that `decide` and `validate` read.

## Declare who is asking

A request context is a service that travels with the request into the domain. It has a schema, because a command carries it to wherever its aggregate runs.

```typescript
// packages/domain/src/CurrentActor.context.ts
import * as Domain from "@alchemy.run/domain";
import { Actor } from "./Actor.ts";

/**
 * Who is making the current request. `Session` provides it; commands read it
 * in `decide` and views in `validate`. Senders without a session (policies)
 * provide it themselves.
 */
export class CurrentActor extends Domain.RequestContext<CurrentActor>()(
  "Bank/CurrentActor",
  Actor,
) {}
```

```typescript
// packages/domain/src/Actor.ts
import * as Schema from "effect/Schema";
import { CustomerId } from "./Customer/Customer.id.ts";

/**
 * Who is acting. `Session` provides it as the `CurrentActor` of each
 * request; events that need an audit trail record it as `by`.
 */
export const Actor = Schema.Union([
  Schema.TaggedStruct("Customer", { customerId: CustomerId }),
  Schema.TaggedStruct("Agent", { agentId: Schema.String }),
  Schema.TaggedStruct("System", { name: Schema.String }),
]);
export type Actor = typeof Actor.Type;

export const customer = (customerId: string): Actor => ({
  _tag: "Customer",
  customerId: CustomerId.make(customerId),
});
export const agent = (agentId: string): Actor => ({ _tag: "Agent", agentId });
export const system = (name: string): Actor => ({ _tag: "System", name });
```

## Authenticate with middleware

`Session` is middleware that provides `CurrentActor`. Browsers send a session cookie; scripts and tests send an `Authorization` header.

```typescript
// packages/domain/src/Session.middleware.ts
import * as Headers from "effect/http/Headers";
import * as RpcMiddleware from "effect/rpc/RpcMiddleware";
import * as Schema from "effect/Schema";
import { CurrentActor } from "./CurrentActor.context.ts";

/** The request has no session. */
export class Unauthorized extends Schema.TaggedError<Unauthorized>()("Unauthorized", {}) {}

/** The cookie that carries a customer's session in a browser. */
export const SESSION_COOKIE = "bank_session";

/**
 * Authenticates a request, from a customer or a support agent, and provides
 * who is making it as the {@link CurrentActor}. Authorization is up to each
 * command's `decide` and each view's `validate`.
 *
 * Browsers authenticate with the session cookie, which also reaches live
 * reads: a WebSocket upgrade carries cookies, never a header a client sets.
 * Other clients (tests, support tooling) send `Authorization` instead.
 */
export class Session extends RpcMiddleware.Service<Session, { provides: CurrentActor }>()(
  "Bank/Session",
  { error: Unauthorized },
) {}

/** Client side, for clients that are not browsers: send this token with every call. */
export const sessionClient = (token: string) =>
  RpcMiddleware.layerClient(Session, ({ request, next }) =>
    next({ ...request, headers: Headers.set(request.headers, "authorization", `Bearer ${token}`) }),
  );
```

The Worker that serves the Api provides `SessionLive`. A client that isn't a browser adds `sessionClient` to attach its header.

## Guard commands and views

List the middleware on each command and view that needs it. Middleware runs in order, and what it provides is what `decide` and `validate` may read.

```typescript
// packages/domain/src/Account/SetNickname.command.ts
import * as Domain from "@alchemy.run/domain";
import * as Schema from "effect/Schema";
import { Session } from "../Session.middleware.ts";
import { AccountId } from "./Account.id.ts";
import { NotOwner } from "./NotOwner.rejection.ts";

export class NicknameSet extends Domain.Event("NicknameSet", { nickname: Schema.String }) {}

export class SetNickname extends Domain.Command("SetNickname", {
  target: AccountId,
  middleware: [Session],
  input: { nickname: Schema.String },
  events: [NicknameSet],
  rejects: [NotOwner],
}) {}
```

`decide` then checks the actor against the account. See [Aggregate](/domain/aggregate#decide).

## Sign browsers in with a cookie

`sessionRoute` sets the session cookie. `HttpOnly` keeps it from scripts, and `SameSite=Strict` keeps it off requests from other sites, WebSocket upgrades included. The Worker sends `/api/session` to it.

Cookies only work when the app and the Api share an origin. The app's Worker serves the page and forwards `/api` to the bank.

```typescript
// packages/web/src/worker.ts
interface Fetcher {
  fetch(request: Request): Promise<Response>;
}

/**
 * The app's Worker: the client build, plus `/api` forwarded to the bank over
 * a service binding. One origin for both, so the session cookie is
 * first-party and reaches every call and every live read's WebSocket.
 */
export default {
  fetch(request: Request, env: { readonly ASSETS: Fetcher; readonly BANK: Fetcher }) {
    const { pathname } = new URL(request.url);
    return pathname.startsWith("/api") ? env.BANK.fetch(request) : env.ASSETS.fetch(request);
  },
};
```

```typescript
// alchemy.run.ts
import BankWorker from "@bank/server/BankWorker";
import * as Alchemy from "alchemy";
import * as Axiom from "@alchemy.run/axiom";
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Stripe from "@alchemy.run/stripe";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";

export default Alchemy.Stack(
  "CloudflareDomainExample",
  {
    providers: Layer.mergeAll(Cloudflare.providers(), Stripe.providers(), Axiom.providers()),
    state: Alchemy.localState(),
  },
  Effect.gen(function* () {
    const bank = yield* BankWorker;
    // The foldkit app, built with Vite. Its Worker serves the build and
    // forwards /api to the bank, so the app and the Api share one origin.
    const app = yield* Cloudflare.Website.Foldkit("BankApp", {
      rootDir: "packages/web",
      main: "src/worker.ts",
      env: { BANK: bank },
      assets: { runWorkerFirst: ["/api", "/api/*"] },
    });
    return { url: bank.url.as<string>(), app: app.url.as<string>() };
  }),
);
```

`env: { BANK: bank }` gives the app's Worker a binding to the bank, and `runWorkerFirst` sends `/api` through it.

## Keep tokens out of URLs

A browser can't set headers on a WebSocket, and a URL ends up in logs. A live read authenticates with what its WebSocket upgrade carries: in a browser, the session cookie. Scripts and tests send `Authorization`, which they can set on their WebSockets too. See [Testing an Api](/domain/testing-apis#test-a-deployment).

## Authenticate another service

A backend service that calls the Api has no session. It signs each request with a secret it shares with the Api, and middleware checks the signature. Service calls stay on the Api, typed and guarded like every other call.

Both sides sign the same text: the RPC's tag, the calling service, a timestamp, a nonce, and the payload as the RPC's own schema encodes it. Don't sign the HTTP body: one NDJSON body can carry several requests.

```typescript
// packages/domain/src/ServiceAuth.signature.ts
import * as Effect from "effect/Effect";
import type * as Rpc from "effect/rpc/Rpc";
import * as Schema from "effect/Schema";

/** What a signature covers, besides the RPC and its payload. */
export interface Signed {
  readonly service: string;
  readonly timestamp: string;
  readonly nonce: string;
}

const bytes = (text: string) => new TextEncoder().encode(text);
const hmacKey = (secret: string) =>
  crypto.subtle.importKey("raw", bytes(secret), { name: "HMAC", hash: "SHA-256" }, false, [
    "sign",
    "verify",
  ]);

export const signedText = (rpc: Rpc.AnyWithProps, payload: unknown, signed: Signed) =>
  Schema.encodeUnknownEffect(Schema.toCodecJson(rpc.payloadSchema as Schema.Codec<unknown>))(
    payload,
  ).pipe(
    Effect.map((json) =>
      [rpc._tag, signed.service, signed.timestamp, signed.nonce, JSON.stringify(json)].join("\n"),
    ),
    Effect.orDie,
  );

export const sign = (secret: string, text: string) =>
  Effect.promise(async () => {
    const mac = await crypto.subtle.sign("HMAC", await hmacKey(secret), bytes(text));
    return Array.from(new Uint8Array(mac), (b) => b.toString(16).padStart(2, "0")).join("");
  });

/** `crypto.subtle.verify` compares in constant time. */
export const verify = (secret: string, text: string, signature: string) =>
  Effect.promise(async () => {
    if (!/^[0-9a-f]{64}$/.test(signature)) return false;
    const mac = new Uint8Array(signature.match(/../g)!.map((pair) => parseInt(pair, 16)));
    return crypto.subtle.verify("HMAC", await hmacKey(secret), mac, bytes(text));
  });
```

Declare who is calling, the middleware, and its client half. `requiredForClient: true` makes every client provide the signing half, so an unsigned client doesn't type-check.

```typescript
// packages/domain/src/ServiceAuth.middleware.ts
import * as Domain from "@alchemy.run/domain";
import * as Clock from "effect/Clock";
import * as Effect from "effect/Effect";
import * as Headers from "effect/http/Headers";
import * as RpcMiddleware from "effect/rpc/RpcMiddleware";
import * as Schema from "effect/Schema";
import { sign, signedText } from "./ServiceAuth.signature.ts";

/** Which service sent the request, and the nonce it signed. */
export class Caller extends Domain.RequestContext<Caller>()(
  "Bank/Caller",
  Schema.Struct({ service: Schema.String, nonce: Schema.String }),
) {}

/** The request isn't signed by a service the Api knows. */
export class BadSignature extends Schema.TaggedError<BadSignature>()("BadSignature", {}) {}

/** Authenticates a request another service signed. Its client signs every call. */
export class ServiceAuth extends RpcMiddleware.Service<ServiceAuth, { provides: Caller }>()(
  "Bank/ServiceAuth",
  { error: BadSignature, requiredForClient: true },
) {}

/** Client side: sign every call as `service`. */
export const serviceAuthClient = (service: string, secret: string) =>
  RpcMiddleware.layerClient(ServiceAuth, ({ rpc, request, next }) =>
    Effect.gen(function* () {
      const timestamp = String(yield* Clock.currentTimeMillis);
      const nonce = crypto.randomUUID();
      const text = yield* signedText(rpc, request.payload, { service, timestamp, nonce });
      return yield* next({
        ...request,
        headers: Headers.setAll(request.headers, {
          "x-service": service,
          "x-timestamp": timestamp,
          "x-nonce": nonce,
          "x-signature": yield* sign(secret, text),
        }),
      });
    }),
  );
```

The Worker checks each request. It refuses an unknown service, a timestamp more than five minutes off, a wrong signature, and a nonce it has seen, then provides the `Caller`. It remembers a nonce until its signature expires, so a request can't be replayed while it's still valid.

```typescript
// packages/server/src/ServiceAuth.ts
import { BadSignature, Caller, ServiceAuth } from "@bank/domain/ServiceAuth.middleware";
import { signedText, verify } from "@bank/domain/ServiceAuth.signature";
import * as Clock from "effect/Clock";
import * as Context from "effect/Context";
import * as Effect from "effect/Effect";
import * as Headers from "effect/http/Headers";
import * as Layer from "effect/Layer";
import * as Option from "effect/Option";

/** How far a signature's timestamp may be from the Worker's clock, either way. */
const MAX_AGE_MS = 5 * 60_000;

/** Nonces already used. `claim` records one until `until`, or returns `false` if it's there. */
export class NonceStore extends Context.Service<
  NonceStore,
  { readonly claim: (nonce: string, until: number) => Effect.Effect<boolean> }
>()("Bank/NonceStore") {}

export const ServiceAuthLive = (secrets: Readonly<Record<string, string>>) =>
  Layer.effect(
    ServiceAuth,
    Effect.gen(function* () {
      const nonces = yield* NonceStore;
      return (effect, { rpc, payload, headers }) =>
        Effect.gen(function* () {
          const header = (name: string) => Option.getOrUndefined(Headers.get(headers, name));
          const service = header("x-service");
          const timestamp = header("x-timestamp");
          const nonce = header("x-nonce");
          const signature = header("x-signature");
          // Own keys only: `secrets["constructor"]` is a function anyone can sign with.
          const secret =
            service !== undefined && Object.hasOwn(secrets, service) ? secrets[service] : undefined;
          if (!service || !secret || !timestamp || !nonce || !signature) {
            return yield* new BadSignature();
          }
          const sentAt = Number(timestamp);
          if (!(Math.abs((yield* Clock.currentTimeMillis) - sentAt) <= MAX_AGE_MS)) {
            return yield* new BadSignature();
          }
          const text = yield* signedText(rpc, payload, { service, timestamp, nonce });
          if (!(yield* verify(secret, text, signature))) return yield* new BadSignature();
          if (!(yield* nonces.claim(nonce, sentAt + MAX_AGE_MS))) return yield* new BadSignature();
          return yield* Effect.provideService(effect, Caller, { service, nonce });
        });
    }),
  );
```

Keep `NonceStore` in a Durable Object. Every Worker instance must see the same nonces, and `claim` must check and record in one step: in an eventually consistent store like KV, two copies of a request can both pass. Give each calling service its own secret, and read the secrets from secret bindings or `Config.Redacted`, not from code.

List `ServiceAuth` on the commands and reads other services may use. A payroll service pays salaries into accounts, and `decide` reads the `Caller` to record which service paid:

```typescript
// packages/domain/src/Account/PaySalary.command.ts
import * as Domain from "@alchemy.run/domain";
import * as Schema from "effect/Schema";
import { Cents } from "../Money.ts";
import { ServiceAuth } from "../ServiceAuth.middleware.ts";
import { AccountId } from "./Account.id.ts";
import { NotOpen } from "./NotOpen.rejection.ts";

export class SalaryPaid extends Domain.Event("SalaryPaid", {
  amount: Cents,
  paidBy: Schema.String,
}) {}

/** Another service pays a salary into an account. */
export class PaySalary extends Domain.Command("PaySalary", {
  target: AccountId,
  middleware: [ServiceAuth],
  input: { amount: Cents },
  events: [SalaryPaid],
  rejects: [NotOpen],
}) {}
```

```typescript
// packages/domain/src/InternalApi.api.ts
import * as Domain from "@alchemy.run/domain";
import { PaySalary } from "./Account/PaySalary.command.ts";

/** What other services reach, signed with `ServiceAuth`. */
export class InternalApi extends Domain.Api("InternalApi", PaySalary) {}
```

The calling service connects with the client half and its secret:

```typescript
// payroll/src/InternalApi.client.ts
import * as Domain from "@alchemy.run/domain";
import { InternalApi } from "@bank/domain/InternalApi.api";
import { serviceAuthClient } from "@bank/domain/ServiceAuth.middleware";
import * as Config from "effect/Config";
import * as Effect from "effect/Effect";
import * as FetchHttpClient from "effect/http/FetchHttpClient";
import * as Layer from "effect/Layer";
import * as Redacted from "effect/Redacted";

export const InternalApiClient = Layer.unwrap(
  Effect.gen(function* () {
    const secret = yield* Config.Redacted("BANK_SERVICE_SECRET");
    return InternalApi.layerClient.pipe(
      Layer.provide(Domain.protocolHttp("https://bank.example.com/internal")),
      Layer.provide(
        Layer.mergeAll(FetchHttpClient.layer, serviceAuthClient("payroll", Redacted.value(secret))),
      ),
    );
  }),
);
```

Use `Domain.protocolHttp`: `Domain.protocolWebSocket` opens live reads without the headers client middleware sets, so a signed `watch` must stream over HTTP.

## Act without a session

A policy has no request, so it provides `CurrentActor` itself before sending a command that needs one, usually as the system. See [Policy](/domain/policy#react-to-a-view).
