A story is a specification you can run: given some history, when a command is sent, then these events are recorded. It runs your real model in memory, with its policies, a clock you control, and outside systems you answer yourself.

## Create a story runner

Give `Story.make` your model, its policies' Layer, and the ports its policies call.

```typescript
// test/withdrawals.test.ts
import { it } from "@effect/vitest";
import { Story } from "alchemy/Domain/Story";
import { Account } from "../src/Account/Account.ts";
import { AccountSummary } from "../src/Account/AccountSummary.ts";
import { MoneyDeposited } from "../src/Account/DepositMoney.ts";
import { InsufficientFunds } from "../src/Account/InsufficientFunds.ts";
import { AccountOpened } from "../src/Account/OpenAccount.ts";
import { Statement } from "../src/Account/Statement.ts";
import { MoneyWithdrawn, WithdrawMoney } from "../src/Account/WithdrawMoney.ts";
import { customer } from "../src/Actor.ts";
import { Bank, BankPolicies } from "../src/Bank.ts";
import { CurrentActor } from "../src/CurrentActor.ts";
import { CustomerId } from "../src/Customer/CustomerId.ts";
import { FraudCheck } from "../src/Fraud/FraudCheck.ts";
import { Payments } from "../src/Settlement/Payments.ts";

const story = Story.make(Bank, { layer: BankPolicies, ports: [FraudCheck, Payments] });
const account = Account.ref("a-1");
const opened = new AccountOpened({ customerId: CustomerId.make("c-1"), owner: "sam" });
const asSam = Story.provide(CurrentActor, customer("c-1"));

it.effect("a withdrawal replies with the balance and updates the views", () =>
  story(
    Story.given(account, opened, new MoneyDeposited({ amount: 100, balanceAfter: 100 })),
    asSam,
    Story.when(account, new WithdrawMoney({ amount: 30 })),
    Story.then(account, new MoneyWithdrawn({ amount: 30, balanceAfter: 70 })),
    Story.replied({ balance: 70 }),
    Story.view(AccountSummary, account, { balance: 70 }),
    Story.emitted(Statement, account, [
      { kind: "deposit", amount: 100, balance: 100 },
      { kind: "withdrawal", amount: 30, balance: 70 },
    ]),
  ),
);

it.effect("an overdraft is rejected with the evidence", () =>
  story(
    Story.given(account, opened, new MoneyDeposited({ amount: 50, balanceAfter: 50 })),
    asSam,
    Story.when(account, new WithdrawMoney({ amount: 80 })),
    Story.rejected(new InsufficientFunds({ balance: 50, requested: 80 })),
  ),
);
```

Run stories with Vitest and `@effect/vitest`: each story is an Effect, so `it.effect` runs it.

## Use the steps

| Step | Does |
| --- | --- |
| `given(ref, ...events)` | Records history on an instance before the story starts. It reaches views, never policies. |
| `provide(service, value)` | Provides a service to the following commands, as their middleware would, such as `CurrentActor` |
| `when(ref, command)` | Sends a command. Policies run until they finish or wait on a port. |
| `then(ref, ...events)` | Checks the next events recorded on an instance. With no events, checks nothing new was recorded. |
| `rejected(rejection)` | Checks the last command was rejected with exactly this |
| `replied(reply)` | Checks the last command's reply |
| `state(ref, assert)` | Checks an instance's current state |
| `view(view, ref, expected)` | Checks a view key's state, or part of it |
| `emitted(view, ref, expected)` | Checks every event a view key has emitted |
| `expectCall(op, args)` | Checks a policy called a port and is waiting for the answer |
| `resolve(op, value)` | Answers the oldest waiting call to a port |
| `clock(at)` | Moves the clock; scheduled commands that are now due fire |

## Answer outside systems

Port calls wait until you answer them, so you decide what the outside world says, and when.

```typescript
// test/fraud.test.ts
import { it } from "@effect/vitest";
import { Story } from "alchemy/Domain/Story";
import { Account } from "../src/Account/Account.ts";
import { MoneyDeposited } from "../src/Account/DepositMoney.ts";
import { AccountFrozen } from "../src/Account/FreezeAccount.ts";
import { AccountOpened } from "../src/Account/OpenAccount.ts";
import { MoneyWithdrawn, WithdrawMoney } from "../src/Account/WithdrawMoney.ts";
import { customer, system } from "../src/Actor.ts";
import { Bank, BankPolicies } from "../src/Bank.ts";
import { CurrentActor } from "../src/CurrentActor.ts";
import { CustomerId } from "../src/Customer/CustomerId.ts";
import { FraudCheck } from "../src/Fraud/FraudCheck.ts";
import { Payments } from "../src/Settlement/Payments.ts";

const story = Story.make(Bank, { layer: BankPolicies, ports: [FraudCheck, Payments] });
const account = Account.ref("a-1");

it.effect("a risky withdrawal freezes the account", () =>
  story(
    Story.given(
      account,
      new AccountOpened({ customerId: CustomerId.make("c-1"), owner: "sam" }),
      new MoneyDeposited({ amount: 90_000, balanceAfter: 90_000 }),
    ),
    Story.provide(CurrentActor, customer("c-1")),
    Story.when(account, new WithdrawMoney({ amount: 60_000 })),
    Story.then(account, new MoneyWithdrawn({ amount: 60_000, balanceAfter: 30_000 })),
    Story.expectCall(FraudCheck.score, { accountId: account.id, amount: 60_000 }),
    Story.resolve(FraudCheck.score, { risk: 0.95 }),
    Story.then(account, new AccountFrozen({ reason: "fraud risk 0.95", by: system("FraudReview") })),
  ),
);
```

## Move the clock

A story's clock starts at `2026-01-01T00:00:00Z`, and `Story.clock` moves it. Commands are stamped with it, so time-based rules like a daily limit are easy to test, and scheduled commands fire when it passes their time. See [Deadlines](/domain/deadlines).

## Trust a passing story

A story fails if a command is rejected and no `rejected` step checks it, or if a port call is left waiting at the end. A passing story has accounted for every outcome.
