Customers will reach the bank from outside. Give every request a signed-in customer, check ownership on every command and read, and expose the bank through an Api.

## Know who is asking

```typescript
// src/CurrentActor.ts
import * as Domain from "alchemy/Domain";
import * as Schema from "effect/Schema";
import { CustomerId } from "./Customer.ts";

export class CurrentActor extends Domain.RequestContext<CurrentActor>()(
  "Bank/CurrentActor",
  Schema.Struct({ customerId: CustomerId }),
) {}
```

`CurrentActor` is the customer behind a request. It has a schema because it travels with each command to the account that decides it.

## Authenticate requests

```typescript
// src/Session.ts
import * as Effect from "effect/Effect";
import * as Headers from "effect/http/Headers";
import * as Layer from "effect/Layer";
import * as Option from "effect/Option";
import * as RpcMiddleware from "effect/rpc/RpcMiddleware";
import * as Schema from "effect/Schema";
import { CurrentActor } from "./CurrentActor.ts";
import { CustomerId } from "./Customer.ts";

export class Unauthorized extends Schema.TaggedError<Unauthorized>()("Unauthorized", {}) {}

export class Session extends RpcMiddleware.Service<Session, { provides: CurrentActor }>()(
  "Bank/Session",
  { error: Unauthorized },
) {}

// Demo only: trusts `Authorization: Bearer <customer id>`. Verify a real session in production.
export const SessionLive = Layer.succeed(Session, (effect, { headers }) =>
  Option.match(Headers.get(headers, "authorization"), {
    onNone: () => Effect.fail(new Unauthorized()),
    onSome: (value) =>
      value.startsWith("Bearer ")
        ? Effect.provideService(effect, CurrentActor, {
            customerId: CustomerId.make(value.slice("Bearer ".length)),
          })
        : Effect.fail(new Unauthorized()),
  }),
);

export const sessionClient = (customerId: string) =>
  RpcMiddleware.layerClient(Session, ({ request, next }) =>
    next({ ...request, headers: Headers.set(request.headers, "authorization", `Bearer ${customerId}`) }),
  );
```

`Session` is middleware: it runs before a command or read and provides `CurrentActor`. `SessionLive` is the server side, and `sessionClient` attaches the header from a client. [Part 6](/domain/tutorial/part-6) replaces the header with a browser cookie.

A view guards its reads the same way. `validate` runs on every read, and again on every change while a client watches. A summary that has no owner yet reads as empty, so a new customer can watch for their account to appear.

## Expose an Api

```typescript
// src/BankApi.ts
import * as Domain from "alchemy/Domain";
import { DepositMoney, WithdrawMoney } from "./Account.ts";
import { AccountSummary } from "./AccountSummary.ts";
import { RegisterCustomer } from "./Customer.ts";

export class BankApi extends Domain.Api(
  "BankApi",
  RegisterCustomer,
  DepositMoney,
  WithdrawMoney,
  AccountSummary,
) {}
```

An Api lists what a client may reach. Nothing in it needs a handler: the account decides the commands, and the model hosts the view.

## Test the Api

```typescript
// test/BankApi.test.ts
import { expect, it } from "@effect/vitest";
import * as Domain from "alchemy/Domain";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import type * as Scope from "effect/Scope";
import * as Stream from "effect/Stream";
import { AccountId } from "../src/Account.ts";
import { Bank, BankPolicies } from "../src/Bank.ts";
import { BankApi } from "../src/BankApi.ts";
import { CustomerId } from "../src/Customer.ts";
import { SessionLive, sessionClient } from "../src/Session.ts";

// The bank in memory, with the same middleware a Worker would serve.
const World = SessionLive.pipe(
  Layer.provideMerge(Bank.layer(BankPolicies).pipe(Layer.provide(Domain.InMemory))),
);

const signedInAs = (customerId: string) =>
  BankApi.testClient.pipe(Effect.provide(sessionClient(customerId)));

const inBank = <A, E>(effect: Effect.Effect<A, E, Scope.Scope | Layer.Success<typeof World>>) =>
  effect.pipe(Effect.scoped, Effect.provide(World));

it.live("a customer registers, deposits, and reads only their own balance", () =>
  inBank(
    Effect.gen(function* () {
      const sam = yield* signedInAs("c-1");
      yield* sam.RegisterCustomer({ target: CustomerId.make("c-1"), name: "sam" });

      // The policy opens the account shortly after; wait for its summary.
      const accountId = AccountId.make("c-1-main");
      yield* sam.AccountSummary.watch(accountId).pipe(
        Stream.filter((summary) => summary?.owner === "c-1"),
        Stream.runHead,
      );

      const { reply } = yield* sam.DepositMoney({ target: accountId, amount: 100 });
      expect(reply.balance).toBe(100);

      const alex = yield* signedInAs("c-2");
      const refused = yield* alex.AccountSummary.get(accountId).pipe(Effect.flip);
      expect(refused._tag).toBe("NotOwner");
    }),
  ),
);
```

`testClient` calls the Api in the same process, through the real middleware. Each client is signed in as one customer, and someone else's balance comes back as `NotOwner`.

```sh
bun vitest run
```

Every request now has a customer, every command and read checks it, and clients reach the bank through one typed Api.
