---
title: Aggregate
description: Decide commands against current state, record events, and keep every rule of one entity consistent.
---

An aggregate is one entity that decides: a bank account, a customer, a transfer. It takes a command, checks it against its current state, and records events or returns a rejection. Each instance handles one command at a time, so its rules always hold.

## Declare an aggregate

Give it an id, a state with its starting value, the commands it handles, and two functions: `decide` and `evolve`.

```typescript
// src/Account.ts
import * as Domain from "alchemy/Domain";
import * as Effect from "effect/Effect";
import * as Schema from "effect/Schema";
import { CurrentActor } from "./CurrentActor.ts";
import { Session } from "./Session.ts";

export const AccountId = Schema.String.pipe(Schema.brand("AccountId"));

export class AccountOpened extends Domain.Event("AccountOpened", {
  data: { owner: Schema.String },
}) {}

export class MoneyDeposited extends Domain.Event("MoneyDeposited", {
  data: { amount: Schema.Int, balanceAfter: Schema.Int },
}) {}

export class MoneyWithdrawn extends Domain.Event("MoneyWithdrawn", {
  data: { amount: Schema.Int, balanceAfter: Schema.Int },
}) {}

export class AlreadyOpen extends Domain.Rejection("AlreadyOpen") {}
export class NotOpen extends Domain.Rejection("NotOpen") {}
export class NotOwner extends Domain.Rejection("NotOwner") {}
export class InsufficientFunds extends Domain.Rejection("InsufficientFunds", {
  data: { balance: Schema.Int, requested: Schema.Int },
}) {}

export class OpenAccount extends Domain.Command("OpenAccount", {
  target: AccountId,
  middleware: [Session],
  events: [AccountOpened],
  rejects: [AlreadyOpen],
}) {}

export class DepositMoney extends Domain.Command("DepositMoney", {
  target: AccountId,
  middleware: [Session],
  input: { amount: Schema.Int },
  events: [MoneyDeposited],
  rejects: [NotOpen, NotOwner],
  reply: { balance: Schema.Int },
}) {}

export class WithdrawMoney extends Domain.Command("WithdrawMoney", {
  target: AccountId,
  middleware: [Session],
  input: { amount: Schema.Int },
  events: [MoneyWithdrawn],
  rejects: [NotOpen, NotOwner, InsufficientFunds],
  reply: { balance: Schema.Int },
}) {}

const State = Schema.Union([
  Schema.TaggedStruct("Unopened", {}),
  Schema.TaggedStruct("Open", { owner: Schema.String, balance: Schema.Int }),
]);
type State = typeof State.Type;

// The open account, if the current user owns it.
const owned = Effect.fn(function* (s: State) {
  if (s._tag !== "Open") return yield* new NotOpen();
  const actor = yield* CurrentActor;
  if (actor.userId !== s.owner) return yield* new NotOwner();
  return s;
});

// An event can only follow an open account; anything else is a bug.
const mustBeOpen = (s: State) => {
  if (s._tag !== "Open") throw new Error(`expected an open account, got ${s._tag}`);
  return s;
};

export class Account extends Domain.Aggregate("Account", {
  id: AccountId,
  state: State,
  initial: { _tag: "Unopened" },
  commands: [OpenAccount, DepositMoney, WithdrawMoney],
  decide: {
    OpenAccount: Effect.fn(function* (s) {
      if (s._tag !== "Unopened") return yield* new AlreadyOpen();
      const actor = yield* CurrentActor;
      return [new AccountOpened({ owner: actor.userId })];
    }),
    DepositMoney: Effect.fn(function* (s, cmd) {
      const open = yield* owned(s);
      return [new MoneyDeposited({ amount: cmd.amount, balanceAfter: open.balance + cmd.amount })];
    }),
    WithdrawMoney: Effect.fn(function* (s, cmd) {
      const open = yield* owned(s);
      if (cmd.amount > open.balance) {
        return yield* new InsufficientFunds({ balance: open.balance, requested: cmd.amount });
      }
      return [new MoneyWithdrawn({ amount: cmd.amount, balanceAfter: open.balance - cmd.amount })];
    }),
  },
  evolve: {
    AccountOpened: (_, e) => ({ _tag: "Open" as const, owner: e.owner, balance: 0 }),
    MoneyDeposited: (s, e) => ({ ...mustBeOpen(s), balance: e.balanceAfter }),
    MoneyWithdrawn: (s, e) => ({ ...mustBeOpen(s), balance: e.balanceAfter }),
  },
  reply: {
    DepositMoney: (s) => ({ balance: mustBeOpen(s).balance }),
    WithdrawMoney: (s) => ({ balance: mustBeOpen(s).balance }),
  },
  read: {
    middleware: [Session],
    rejects: [NotOwner],
    validate: Effect.fn(function* (_request, s) {
      const actor = yield* CurrentActor;
      if (s._tag === "Open" && actor.userId !== s.owner) return yield* new NotOwner();
    }),
  },
}) {}
```



## Decide

`decide` has one handler per command. It returns the events to record, or a rejection. Return an empty array when there's nothing to do.

A handler can be a plain function, or an `Effect.fn` that reads what the command's middleware provides. Here `Session` provides `CurrentActor`, so `DepositMoney` checks that the caller owns the account. See [Sessions and middleware](/domain/sessions).

## Evolve

`evolve` has one handler per event. It returns the next state and never refuses: the event already happened. An event that can't follow the current state is a bug, so `mustBeOpen` throws, and the command that recorded it is rolled back.

## Reply

`reply` answers the caller from the state after the events. Clients get it from `send` and from the Api.

## Read it through an Api

`read` lets an Api expose the account itself, so a client can get it, watch it, and follow its events. `validate` judges every read and every change while a client watches.

```typescript
// src/AccountApi.ts
import * as Domain from "alchemy/Domain";
import { Account, DepositMoney, OpenAccount, WithdrawMoney } from "./Account.ts";

export class AccountApi extends Domain.Api(
  "AccountApi",
  OpenAccount,
  DepositMoney,
  WithdrawMoney,
  Account,
) {}
```

A client calls `bank.DepositMoney({ target, amount })` and reads with `bank.Account.get(id)`, `bank.Account.watch(id)` and `bank.Account.events(id)`. See [Api](/domain/api).

## Send commands from your own code

The model provides each aggregate as a service. `yield* Account` gives you its client.

```typescript
// src/deposit.ts
import * as Effect from "effect/Effect";
import { Account, AccountId, DepositMoney } from "./Account.ts";
import { CurrentActor } from "./CurrentActor.ts";

export const deposit = Effect.fn(function* (userId: string, accountId: string, amount: number) {
  const accounts = yield* Account;
  const { reply } = yield* accounts
    .send(AccountId.make(accountId), new DepositMoney({ amount }))
    .pipe(Effect.provideService(CurrentActor, { userId }));
  return reply.balance;
});
```

`send` succeeds with a receipt once the events are committed: the stream, its new version, the events, and the reply. It fails with one of the command's declared rejections. Outside an Api, you provide what the middleware would, here the `CurrentActor`.

`accounts.state(id)` reads the current state, and `accounts.schedule(id, command, { after })` sends a command later. See [Deadlines](/domain/deadlines).

## Keep it consistent

Each instance is a consistency boundary. Commands to one account run one at a time, and the events, the new state and the reply commit together. Nothing spans two instances at once: moving money between accounts is a [saga](/domain/sagas).

Put every rule that must hold immediately in `decide`, even one that reacts to the instance's own events. Use a [policy](/domain/policy) only for work that may happen shortly after.
