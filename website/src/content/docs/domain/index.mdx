`alchemy/Domain` models your business in its own terms. Commands ask for changes, aggregates decide them, and events record what happened. Views, projections and policies then answer questions, feed your own stores, and apply the business's rules about what to do next.

The same model runs in memory for tests and on Cloudflare Durable Objects in production, with one ordered partition per key.

## A taste

A command declares what it asks for and every way it can end:

```typescript title="src/DepositMoney.ts"
export class MoneyDeposited extends Domain.Event("MoneyDeposited", {
  data: { amount: Schema.Int, balanceAfter: Schema.Int },
}) {}

export class DepositMoney extends Domain.Command("DepositMoney", {
  target: AccountId,
  input: { amount: Schema.Int },
  events: [MoneyDeposited],
  rejects: [NotOpen],
  reply: { balance: Schema.Int },
}) {}
```

The account aggregate decides it against its current state:

```typescript title="src/Account.ts"
DepositMoney: (s, cmd) =>
  s._tag !== "Open"
    ? new NotOpen()
    : [new MoneyDeposited({ amount: cmd.amount, balanceAfter: s.balance + cmd.amount })],
```

And a story tests it in memory, in the business's own words: given this history, when this command, then these events.

```typescript title="test/Account.test.ts"
it.effect("deposits into an open account and replies with the balance", () =>
  story(
    Story.given(account, new AccountOpened({ owner: "sam" })),
    Story.when(account, new DepositMoney({ amount: 100 })),
    Story.then(account, new MoneyDeposited({ amount: 100, balanceAfter: 100 })),
    Story.replied({ balance: 100 }),
  ),
);
```

**Want to build one?** The [tutorial](/domain/tutorial/part-1) builds a bank step by step, from a single account on your machine to an Api deployed on Cloudflare with a browser app.

**Know the ideas and want the API?** [Domain Model](/domain/model) shows how a model runs, and each building block has its own page: [Command](/domain/command), [Event](/domain/event), [Aggregate](/domain/aggregate), [View](/domain/view), [Projection](/domain/projection), [Stream](/domain/stream), [Policy](/domain/policy) and [Api](/domain/api).
