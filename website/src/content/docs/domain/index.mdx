`alchemy/Domain` is a domain-driven design framework. You model your business in its own terms: commands that ask for changes, aggregates that decide them, events that record what happened, views that answer questions, and policies that apply the business's rules about what to do when something happens. The same model runs in memory for tests and on Cloudflare in production.
