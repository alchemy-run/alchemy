title: Api
description: Expose commands and views to one kind of client, serve them from a Worker, and call them with a typed client.
---

An Api is what one kind of client may reach: the commands it may send, and the views and aggregates it may read. Nothing in an Api needs a handler. Aggregates handle the commands, and the model hosts the views.

## Declare an Api

List its commands, views, and aggregates with a `read` contract.

```typescript
// src/CustomerApi/CustomerApi.ts
import * as Domain from "alchemy/Domain";
import { Account } from "../Account/Account.ts";
import { AccountSummary } from "../Account/AccountSummary.ts";
import { CloseAccount } from "../Account/CloseAccount.ts";
import { DepositMoney } from "../Account/DepositMoney.ts";
import { Statement } from "../Account/Statement.ts";
import { WithdrawMoney } from "../Account/WithdrawMoney.ts";
import { CustomerDashboard } from "../Customer/CustomerDashboard.ts";
import { RegisterCustomer } from "../Customer/RegisterCustomer.ts";
import { AccountTransfers } from "../Transfer/AccountTransfers.ts";
import { RequestTransfer } from "../Transfer/RequestTransfer.ts";
import { TransferStatus } from "../Transfer/TransferStatus.ts";

/**
 * What the customer app reaches: commands to change things, and the Account
 * aggregate and views to read and watch. Each entry authorizes itself,
 * through its `decide` or `validate`.
 */
export class CustomerApi extends Domain.Api(
  "CustomerApi",
  RegisterCustomer,
  DepositMoney,
  WithdrawMoney,
  CloseAccount,
  RequestTransfer,
  Account,
  CustomerDashboard,
  AccountSummary,
  Statement,
  AccountTransfers,
  TransferStatus,
) {}
```

Each entry guards itself. A command's middleware and `decide` decide what a caller may do; a view's middleware and `validate` decide what a caller may see. Give each kind of client its own Api, like `SupportApi` for support agents.

## Serve it from a Worker

`httpEffect` serves the Api over HTTP, with live reads over WebSockets.

```typescript
// src/BankWorker.ts
import * as Cloudflare from "alchemy/Cloudflare";
import * as DomainCloudflare from "alchemy/Domain/Cloudflare";
import * as Stripe from "alchemy/Stripe";
import * as Effect from "effect/Effect";
import { HttpServerRequest } from "effect/http/HttpServerRequest";
import * as HttpServerResponse from "effect/http/HttpServerResponse";
import * as Layer from "effect/Layer";
import { Bank, BankPolicies } from "./Bank.ts";
import { CustomerApi } from "./CustomerApi/CustomerApi.ts";
import { SiftFraudCheck } from "./Fraud/SiftFraudCheck.ts";
import { MfaChallengeLive } from "./MfaChallenge.ts";
import { SessionLive, sessionRoute } from "./Session.ts";
import { StripePayments } from "./Settlement/StripePayments.ts";
import { StripeSettlements } from "./Settlement/StripeSettlements.ts";
import { SupportApi } from "./SupportApi/SupportApi.ts";

/**
 * Everything the Worker serves: the middleware both Apis declare, and the
 * Bank hosted on Durable Objects. Swap `DomainCloudflare.DurableObjects` for
 * `Domain.InMemory` and nothing else changes.
 */
const BankLive = Layer.mergeAll(SessionLive, MfaChallengeLive, Stripe.ConsumeEventsLive).pipe(
  Layer.provideMerge(Bank.layer(BankPolicies)),
  Layer.provide(Layer.mergeAll(DomainCloudflare.DurableObjects, SiftFraudCheck, StripePayments)),
);

export default class BankWorker extends Cloudflare.Worker<BankWorker>()(
  "BankWorker",
  { main: import.meta.url },
  Effect.gen(function* () {
    const customerApi = yield* CustomerApi.httpEffect;
    const supportApi = yield* SupportApi.httpEffect;
    // Claims POST /webhooks/stripe and provisions the Stripe webhook endpoint.
    yield* StripeSettlements;
    return {
      // The foldkit app reaches /api through its own Worker, on its own origin,
      // so the session cookie needs no cross-origin allowances.
      fetch: Effect.gen(function* () {
        const request = yield* HttpServerRequest;
        const path = new URL(request.url, "http://localhost").pathname;
        if (path === "/api/session") return yield* sessionRoute;
        if (path.startsWith("/api")) return yield* customerApi;
        if (path.startsWith("/support")) return yield* supportApi;
        return HttpServerResponse.text("Not Found", { status: 404 });
      }),
    };
  }).pipe(Effect.provide(BankLive)),
) {}
```

The Worker provides the middleware the entries declare, here `SessionLive` and `MfaChallengeLive`, along with the hosted model.

## Call it

The client is typed from the Api. Commands are methods, and each view or aggregate is a namespace with its reads.

```typescript
// test/script.ts
import * as Domain from "alchemy/Domain";
import * as Effect from "effect/Effect";
import * as FetchHttpClient from "effect/http/FetchHttpClient";
import * as Layer from "effect/Layer";
import * as Socket from "effect/socket/Socket";
import * as Stream from "effect/Stream";
import { AccountId } from "../src/Account/AccountId.ts";
import { CustomerApi } from "../src/CustomerApi/CustomerApi.ts";
import { sessionClient } from "../src/Session.ts";

const accountId = AccountId.make("c-1-main");

const program = Effect.gen(function* () {
  const bank = yield* CustomerApi.client;
  const { reply } = yield* bank.DepositMoney({ target: accountId, amount: 1_000 });
  yield* Effect.log(`balance ${reply.balance}`);
  yield* bank.AccountSummary.watch(accountId).pipe(
    Stream.take(1),
    Stream.runForEach((summary) => Effect.log(`watched balance ${summary?.balance}`)),
  );
});

const Connection = Layer.mergeAll(
  Domain.protocolWebSocket("https://bank.example.com/api"),
  sessionClient("customer:c-1"),
).pipe(Layer.provide(Layer.mergeAll(FetchHttpClient.layer, Socket.layerWebSocketConstructorGlobal)));

Effect.runPromise(program.pipe(Effect.scoped, Effect.provide(Connection)));
```

`sessionClient` attaches the session for a client that isn't a browser. A browser sends its session cookie instead. See [Sessions and middleware](/domain/sessions).

## Choose a protocol

`Domain.protocolWebSocket` sends commands, `get` and `list` over HTTP, and opens a WebSocket for each `watch` and `events`. The aggregate or view that owns the key pushes every change down it. If the connection drops, the client reconnects and carries on from the last change it saw.

`Domain.protocolHttp` sends everything over HTTP, and streams `watch` and `events` as long-running responses.

## Provide the client to an app

`CustomerApi.Client` is the client as a service, and `CustomerApi.layerClient` builds it for the life of a Layer. Code that sends commands reads `CustomerApi.Client` and leaves the connection to whoever provides it. See [Integrate with foldkit](/domain/foldkit).

## Handle what can go wrong

A call fails with one of three things: a rejection the entry declares, like `InsufficientFunds`; an error from its middleware, like `Unauthorized`; or an `RpcClientError` when the server can't be reached. Each is typed, so `Effect.catchTag` handles exactly the cases you expect.
