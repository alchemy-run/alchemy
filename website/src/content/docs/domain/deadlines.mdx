---
title: Deadlines
description: Give a waiting process a time limit with a scheduled command, and let the aggregate decide whether the deadline or the action wins.
---

A saga that waits needs a deadline. A large transfer waits for a support agent's approval, and expires if nobody approves it within 24 hours. Schedule a command for the deadline, and let the aggregate decide whichever comes first.

## Declare a command that reports the deadline

A scheduled command fires when nobody is waiting for its answer, so it never rejects. It reports a fact, and records nothing when the fact no longer applies.

```typescript
// src/Transfer/ExpireTransfer.ts
import * as Domain from "alchemy/Domain";
import { TransferFailed } from "./FailTransfer.ts";
import { TransferId } from "./TransferId.ts";

/**
 * The approval window closed. Scheduled by `TransferApprovalDeadline`; it
 * reports a fact, so it never rejects, and it records nothing if the transfer
 * was approved in time.
 */
export class ExpireTransfer extends Domain.Command("ExpireTransfer", {
  target: TransferId,
  events: [TransferFailed],
}) {}
```

## Schedule it

A policy schedules the command when the waiting starts.

```typescript
// src/Transfer/TransferApprovalDeadline.ts
import * as Domain from "alchemy/Domain";
import * as Effect from "effect/Effect";
import { ExpireTransfer } from "./ExpireTransfer.ts";
import { TransferRequested } from "./RequestTransfer.ts";
import { Transfer } from "./Transfer.ts";

/** How long a support agent has to approve a large transfer. */
export const APPROVAL_WINDOW = "24 hours";

/**
 * Whenever a transfer needs approval, expire it if nobody approves it in time.
 * The Transfer decides the race: approval and expiry are commands on the same
 * instance, so exactly one of them wins.
 */
export class TransferApprovalDeadline extends Domain.Policy("TransferApprovalDeadline", {
  from: Transfer,
  on: [TransferRequested],
}) {}

export const TransferApprovalDeadlineLive = TransferApprovalDeadline.toLayer(
  Effect.gen(function* () {
    const transfers = yield* Transfer;
    return Effect.fn(function* ({ source, event }) {
      if (!event.needsApproval) return;
      yield* transfers.schedule(source, new ExpireTransfer(), { after: APPROVAL_WINDOW });
    });
  }),
);
```

The schedule is durable: it fires even if everything restarted in between. Scheduling again with the same command id replaces the earlier one.

## Let the aggregate decide the race

Approval and expiry are both commands on the same transfer, which handles one at a time. Whichever arrives first changes the transfer's state, and the other finds nothing to do: `ExpireTransfer` records nothing for an approved transfer, and `ApproveTransfer` rejects an expired one with `NotAwaitingApproval`.

```typescript
// src/Transfer/ApproveTransfer.ts
import * as Domain from "alchemy/Domain";
import { AccountId } from "../Account/AccountId.ts";
import { NotPermitted } from "../Account/ChangeOwner.ts";
import { Actor } from "../Actor.ts";
import { Cents } from "../Money.ts";
import { Session } from "../Session.ts";
import { TransferId } from "./TransferId.ts";

/** The transfer is not waiting for approval: it never needed it, or it expired. */
export class NotAwaitingApproval extends Domain.Rejection("NotAwaitingApproval") {}

/** Carries the transfer so `TransferExecution` can carry it out. */
export class TransferApproved extends Domain.Event("TransferApproved", {
  data: {
    transferId: TransferId,
    from: AccountId,
    to: AccountId,
    amount: Cents,
    requestedBy: Actor,
    approvedBy: Actor,
  },
}) {}

/** A support agent approves a large transfer before its approval window closes. */
export class ApproveTransfer extends Domain.Command("ApproveTransfer", {
  target: TransferId,
  middleware: [Session],
  events: [TransferApproved],
  rejects: [NotAwaitingApproval, NotPermitted],
}) {}
```

## Test it with the clock

A story has its own clock. `Story.clock` moves it, and any scheduled command that's now due fires.

```typescript
// test/deadlines.test.ts
import { it } from "@effect/vitest";
import { Story } from "alchemy/Domain/Story";
import { Account } from "../src/Account/Account.ts";
import { MoneyDeposited } from "../src/Account/DepositMoney.ts";
import { AccountOpened } from "../src/Account/OpenAccount.ts";
import { agent, customer } from "../src/Actor.ts";
import * as Layer from "effect/Layer";
import { Bank, BankHandlers } from "../src/Bank.ts";
import { MemoryLedgerStore } from "../src/Ledger/LedgerStore.ts";
import { CurrentActor } from "../src/CurrentActor.ts";
import { CustomerId } from "../src/Customer/CustomerId.ts";
import { FraudCheck } from "../src/Fraud/FraudCheck.ts";
import { Payments } from "../src/Settlement/Payments.ts";
import { ApproveTransfer, NotAwaitingApproval } from "../src/Transfer/ApproveTransfer.ts";
import { TransferFailed } from "../src/Transfer/FailTransfer.ts";
import { RequestTransfer, TransferRequested } from "../src/Transfer/RequestTransfer.ts";
import { Transfer } from "../src/Transfer/Transfer.ts";

const story = Story.make(Bank, {
  layer: BankHandlers.pipe(Layer.provide(MemoryLedgerStore)),
  externalSystems: [FraudCheck, Payments],
});
const sam = customer("c-1");
const from = Account.ref("a-1");
const to = Account.ref("a-2");
const transfer = Transfer.ref("t-1");
const opened = (customerId: string) =>
  new AccountOpened({ customerId: CustomerId.make(customerId), owner: customerId });

it.effect("an unapproved transfer expires when its window closes", () =>
  story(
    Story.clock("2026-01-01T09:00:00Z"),
    Story.given(from, opened("c-1"), new MoneyDeposited({ amount: 100_000, balanceAfter: 100_000 })),
    Story.given(to, opened("c-2")),
    Story.provide(CurrentActor, sam),
    Story.when(transfer, new RequestTransfer({ from: from.id, to: to.id, amount: 20_000 })),
    Story.then(
      transfer,
      new TransferRequested({
        transferId: transfer.id,
        from: from.id,
        to: to.id,
        amount: 20_000,
        requestedBy: sam,
        needsApproval: true,
      }),
    ),
    // A minute before the deadline, nothing has happened.
    Story.clock("2026-01-02T08:59:00Z"),
    Story.then(transfer),
    // At the deadline, the transfer expires.
    Story.clock("2026-01-02T09:00:00Z"),
    Story.then(transfer, new TransferFailed({ transferId: transfer.id, reason: "not approved in time" })),
    // Approval now comes too late.
    Story.provide(CurrentActor, agent("support-7")),
    Story.when(transfer, new ApproveTransfer()),
    Story.rejected(new NotAwaitingApproval()),
  ),
);
```

`Story.then(transfer)` with no events checks that nothing new was recorded.

:::note
Scheduling is covered in [Command](/domain/command#schedule-it). Deadlines usually belong to a [saga](/domain/sagas).
:::
