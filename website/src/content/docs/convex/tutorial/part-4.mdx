A stage is a separate copy of your Stack. With Convex, each one gets its own data.

## Deploy a second stage

```sh
bun alchemy deploy --stage pr-42
```

`type: "preview"` makes one deployment per stage, named after the stage. `pr-42` starts with no data.

## Use prod for production

Previews expire, and Convex removes them. Use `type: "prod"` for real data:

```typescript
// src/Backend.ts
import * as Convex from "@alchemy.run/convex";
import { Stack } from "alchemy/Stack";
import * as Effect from "effect/Effect";

export const Backend = Effect.gen(function* () {
  const { stage } = yield* Stack;
  const project = yield* Convex.Project("Project");
  return yield* Convex.Deployment("Backend", {
    project,
    type: stage === "prod" ? "prod" : "preview",
  });
});
```

A prod deployment has `deletionProtection` on, so `alchemy destroy` fails rather than deleting its data.

## Remove a stage

```sh
bun alchemy destroy --stage pr-42
```
