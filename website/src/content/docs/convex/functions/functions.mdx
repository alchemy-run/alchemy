A deployment runs the code last **pushed** to it. A push bundles your `convex/` folder, sends the functions and the schema, and Convex checks the existing documents against the new schema before it switches over. `Convex.Functions` pushes with your project's own `convex` CLI, and also sets the deployment's environment variables, since `auth.config.ts` may read them.

## Push to a deployment

```typescript title="alchemy.run.ts"
yield* Convex.Functions("Functions", {
  deployment,
  rootDir: "./packages/backend",
});
```

`rootDir` holds `convex/` and a `package.json` that lists `convex`. In a monorepo, point it at the package.

## The key it pushes with

On Convex Cloud, each push gets its own deploy key, limited to pushing and environment variables. It expires after two hours, and Alchemy deletes it once the push ends, so no key is kept in state. A self-hosted backend uses its admin key.

## When it pushes

A push runs when a file not ignored by git changes in `rootDir`, or when a variable does. An unchanged folder doesn't push. Choose the files yourself with `memo`:

```typescript
yield* Convex.Functions("Functions", {
  deployment,
  rootDir: ".",
  memo: { include: ["convex/**", "src/**", "package.json"] },
});
```

## Push to the right deployment

The CLI runs without any `CONVEX_*` variable or Convex login from your machine, and reads its key from a private file. A `.env.local` that selects another deployment can't redirect the push. If the CLI still reports a different deployment, the deploy fails with `PushTargetMismatch`.

## Handle a failed push

A failed push fails the deploy with `CodePushFailed`, and shows the end of Convex's output with the key and your secret variables removed. Variables the deploy changed go back to their earlier values.

## Bind resources from your functions

When your actions bind other resources, pass their Layer as `functions`, and the push sets what those bindings need. See [Bind another cloud from an action](/convex/functions/queries-mutations-actions#bind-another-cloud-from-an-action).
