## Service-to-service calls (`ConnectService`)

Bind any [`WebService`](/providers/render/reference/compute#webservice), [`PrivateService`](/providers/render/reference/compute#privateservice), [`StaticSite`](/providers/render/reference/compute#staticsite), or [`ServicePreview`](/providers/render/reference/previews#servicepreview) to inject `RENDER_SERVICE_<ID>_URL` and `RENDER_SERVICE_<ID>_SLUG` and issue relative HTTP requests:

```typescript
// src/proxy.ts
import * as Render from "@alchemy.run/render";
import * as Effect from "effect/Effect";
import * as HttpClientRequest from "effect/http/HttpClientRequest";

export const PrivateApi = Render.PrivateService("PrivateApi", {
  plan: "starter",
  region: "oregon",
  runtimeSource: { image: { imagePath: "docker.io/nginxdemos/hello", tag: "plain-text" } },
});

export const Gateway = Render.WebService(
  "Gateway",
  {
    plan: "free",
    region: "oregon",
    runtimeSource: { image: { imagePath: "docker.io/nginxdemos/hello", tag: "plain-text" } },
  },
  Effect.gen(function* () {
    const backend = yield* Render.ConnectService(PrivateApi);
    return {
      fetch: backend.fetch(HttpClientRequest.get("/health")).pipe(Effect.orDie),
    };
  }).pipe(Effect.provide(Render.ConnectServiceHttp)),
);
```

## Custom domains, allow lists, and Dedicated IPs

Pass `customDomains` and `ipAllowList` directly on [`WebService`](/providers/render/reference/compute#webservice), [`Postgres`](/providers/render/reference/postgres#postgres), or [`KeyValue`](/providers/render/reference/key-value#keyvalue). Manage workspace static outbound IP associations with [`Render.DedicatedIp`](/providers/render/reference/networking#dedicatedip).
