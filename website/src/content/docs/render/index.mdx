Render hosts web services, private internal services, background workers, cron jobs, static sites, ephemeral preview environments, durable step-based Workflows, `render.yaml` Blueprints, managed Postgres databases, and managed Key Value instances in isolated project environments.

Every Render resource supports crash-recovery `read` lookups with `Unowned` conflict protection, Effect Schema runtime response validation, and live/historical log inspection (`alchemy logs` / `alchemy logs --tail`) across compute services, Workflows, Postgres, and Key Value instances.

## Quick examples

### Full-stack service, Postgres, and Key Value

Provision a project environment, Postgres database with PgBouncer pooling and migrations, Key Value store, and Web Service with runtime bindings:

```typescript title="alchemy.run.ts"
const project = yield* Render.Project("App", {
  name: "my-app",
});

const db = yield* Render.Postgres("Database", {
  environmentId: project.environments.production.id,
  plan: "basic_256mb",
  region: "oregon",
  connectionPool: "pgbouncer",
  migrations: "./migrations",
});

const cache = yield* Render.KeyValue("Cache", {
  environmentId: project.environments.production.id,
  plan: "starter",
  region: "oregon",
});

const api = yield* Render.WebService("Api", {
  environmentId: project.environments.production.id,
  plan: "starter",
  region: "oregon",
  healthCheckPath: "/health",
  runtimeSource: {
    image: { imagePath: "ghcr.io/org/api", tag: "latest" },
  },
});
```

### Workflows, previews, and runtime bindings

Declare a Render `Workflow`, clone an image-backed `ServicePreview` for pull requests, or bind databases, internal services, Key Value stores, and Workflow tasks into Effect handlers:

```typescript title="alchemy.run.ts"
const jobs = yield* Render.Workflow("Jobs", {
  name: "background-jobs",
  region: "oregon",
  runtime: "node",
  repo: "https://github.com/org/workflows",
  buildCommand: "pnpm install && pnpm build",
  runCommand: "node dist/workflows.js",
});

const preview = yield* Render.ServicePreview("PrPreview", {
  baseServiceId: api.id,
  imagePath: "ghcr.io/org/api:pr-42",
  plan: "starter",
});
```

```typescript title="src/handler.ts"
const program = Effect.gen(function* () {
  const dbConn = yield* Render.ConnectPostgres(db);
  const internal = yield* Render.ConnectService(privateApi);
  const kv = yield* Render.ReadWriteKeyValue(cache);
  const workflow = yield* Render.RunWorkflowTask(jobs);

  const run = yield* workflow.runAndWait("send-welcome", { userId: "usr_123" });
  return { dbConn, internal, kv, run };
});
```
