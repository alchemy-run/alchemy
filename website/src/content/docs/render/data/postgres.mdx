## Create Postgres with migrations

Install `pg` and `@effect/sql-pg` to run SQL migrations automatically during provisioning and updates:

```typescript
// src/db.ts
import * as Render from "@alchemy.run/render";

export const MainDb = Render.Postgres("MainDb", {
  plan: "basic_256mb",
  region: "oregon",
  version: "16",
  connectionPool: "pgbouncer",
  diskSizeGB: 5,
  ipAllowList: [{ cidrBlock: "0.0.0.0/0", description: "public-tls" }],
  migrations: "./migrations",
});
```

:::caution[Replacing properties on Postgres]
Changing `region`, `version`, `databaseName`, `databaseUser`, or `restoreFrom` replaces the database instance.
:::

## Bind ConnectPostgres to a service

Yield [`Render.ConnectPostgres`](/providers/render/reference/postgres#connectpostgres) inside a `Render.WebService` constructor and provide `Render.ConnectPostgresHttp`:

```typescript
// src/api.ts
import * as Render from "@alchemy.run/render";
import * as Effect from "effect/Effect";
import { MainDb } from "./db.ts";

export const Api = Render.WebService(
  "Api",
  {
    plan: "free",
    region: "oregon",
    runtimeSource: { image: { imagePath: "docker.io/nginxdemos/hello", tag: "plain-text" } },
  },
  Effect.gen(function* () {
    const conn = yield* Render.ConnectPostgres(MainDb);
    return { conn };
  }).pipe(Effect.provide(Render.ConnectPostgresHttp)),
);
```

On Render hosts, `ConnectPostgres` binds `DATABASE_URL`, `RENDER_POSTGRES_<ID>_INTERNAL`, `RENDER_POSTGRES_<ID>_EXTERNAL`, and pooled `:6432` URLs. On foreign hosts, it injects the external TLS URL.
