## Query and tail resource logs

All Render compute resources, Workflows, Postgres databases, and Key Value stores implement Alchemy's log and tail interface:

<PackageManagers
  script={`{run} alchemy logs Web --limit 100
{run} alchemy logs Web --tail`}
/>

## Webhooks and workspace notifications

Subscribe external automation endpoints with [`Render.Webhook`](/providers/render/reference/observability-events#webhook) and tune workspace deployment alerts with [`Render.NotificationSetting`](/providers/render/reference/notifications#notificationsetting):

```typescript
// src/webhooks.ts
import * as Render from "@alchemy.run/render";

export const DeployHook = Render.Webhook("DeployHook", {
  name: "deploy-events",
  url: "https://example.com/webhooks/render",
  enabled: true,
  eventFilter: ["deploy_ended"],
});
```

Workspace-level and resource-scoped forwarding to syslog or OpenTelemetry collectors is managed through [`Render.LogStream`](/providers/render/reference/observability#logstream) and [`Render.MetricsStream`](/providers/render/reference/observability#metricsstream).
