Neon is serverless Postgres. It keeps your data separate from the compute that queries it, so compute scales with load and stops when idle, and a whole database, data included, can be branched in a second. Around the database, Neon also runs Functions, object storage, user sign-in, an HTTP Data API and an AI gateway, each attached to a branch.

## A taste

A project and a branch, with migrations applied on deploy:

```typescript title="alchemy.run.ts"
const project = yield* Neon.Project("app-db", { region: "aws-us-east-1" });
const branch = yield* Neon.Branch("app-branch", { project, migrations: "./migrations" });
```

A role for the app, and a Function on the branch:

```typescript title="alchemy.run.ts"
const app = yield* Neon.Role("App", { branch });
const api = yield* Neon.Function("Api", { branch, main: "./src/api.ts" });
```

Or connect from somewhere else. A branch's `origin` goes to Cloudflare Hyperdrive, which does its own pooling:

```typescript title="alchemy.run.ts"
const hyperdrive = yield* Cloudflare.Hyperdrive.Connection("app-hyperdrive", {
  origin: branch.origin,
  dev: branch.pooledOrigin,
});
```

## Where to start

**New to Neon?** [What is Neon?](/neon/what-is-neon) walks through projects, branches, computes, roles, connections, migrations, and the Functions, storage, Auth and AI Gateway around them, once each, and shows how Alchemy models every one.

**Want to build one?** The [upload tutorial](/neon/tutorial) combines a Vite frontend, private files, signed-in users, SQL records and an upload-triggered Function. Start with [Setup](/neon/setup) for credentials and the prerequisites for each feature.

**Want the whole picture?** Start with the database: [Branching](/neon/data/branching), [Connections](/neon/data/connections), [Roles](/neon/data/roles) and [Migrations](/neon/data/migrations). Then the organization around it: [Organization governance](/neon/governance).

**Going to production?** The guides cover [Production Auth](/neon/guides/production-auth), [AI Gateway setup](/neon/guides/ai-gateway), [Private networking](/neon/guides/private-networking), [Custom domains](/neon/guides/custom-domains), [State and recovery](/neon/guides/state-recovery), [Preview branches per PR](/neon/guides/preview-branches) and [Drizzle ORM](/neon/guides/drizzle).

**Building a website?** Every supported framework deploys as a Neon Function, from [Vite](/neon/frontend/vite) to [Next.js](/neon/frontend/nextjs).

Every resource is in the generated [API reference](/providers).
