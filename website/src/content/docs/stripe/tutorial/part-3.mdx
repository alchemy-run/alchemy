In [Part 2](/stripe/tutorial/part-2) the catalog lives in Stripe. A
Worker reads it back over HTTP through Alchemy bindings — there is
no native Stripe Worker binding.

You need a Cloudflare account for this part. The Stripe resources
stay where they are.

## Move the Product to a module

So far the Product lives inside the Stack's generator. To let the
Worker reference it, declare it at **module scope**. Create
`src/product.ts`:

```typescript
// src/product.ts
import * as Stripe from "alchemy/Stripe";

export const Pro = Stripe.Product("Pro", {
  name: "Pro",
  description: "Billed monthly",
});
```

The logical id is still `Pro`, so Alchemy recognizes it as the same
Product you deployed in Part 1.

## Create the Worker file

A Worker is a class with an Effect `fetch` handler. Create
`src/api.ts`:

```typescript
// src/api.ts
import * as Cloudflare from "alchemy/Cloudflare";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/unstable/http/HttpServerResponse";

export default class Api extends Cloudflare.Worker<Api>()(
  "Api",
  {
    main: import.meta.url,
  },
  Effect.gen(function* () {
    return {
      fetch: Effect.gen(function* () {
        return HttpServerResponse.text("ok");
      }),
    };
  }),
) {}
```

`main: import.meta.url` is required in `alchemy dev`. Inline
`script` is deploy-only.

## Bind RetrieveProduct

Yield `Pro` inside the Worker and pass it to
`Stripe.RetrieveProduct`. That registers `products_read` on the host
token and returns a callable:

```diff lang="typescript"
// src/api.ts
import * as Cloudflare from "alchemy/Cloudflare";
+import * as Stripe from "alchemy/Stripe";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/unstable/http/HttpServerResponse";
+import { Pro } from "./product.ts";

export default class Api extends Cloudflare.Worker<Api>()(
  "Api",
  {
    main: import.meta.url,
  },
  Effect.gen(function* () {
+    const product = yield* Pro;
+    const retrieveProduct = yield* Stripe.RetrieveProduct(product);
    return {
      fetch: Effect.gen(function* () {
        return HttpServerResponse.text("ok");
      }),
    };
  }),
) {}
```

The callable requires `RuntimeContext` — it only runs inside the
deployed Worker.

## Handle GET /product

Call `retrieveProduct()` from `fetch`:

```diff lang="typescript"
+import { HttpServerRequest } from "effect/unstable/http/HttpServerRequest";
 import * as HttpServerResponse from "effect/unstable/http/HttpServerResponse";
```

```diff lang="typescript"
      fetch: Effect.gen(function* () {
+        const request = yield* HttpServerRequest;
+        if (request.url.startsWith("/product")) {
+          const live = yield* retrieveProduct().pipe(Effect.orDie);
+          return yield* HttpServerResponse.json({
+            id: live.id,
+            name: live.name,
+          });
+        }
        return HttpServerResponse.text("ok");
      }),
```

`Effect.orDie` turns a Stripe error into a 500 for this tutorial.

## Merge Cloudflare providers

The Worker needs `Cloudflare.providers()` next to Stripe:

```diff lang="typescript"
// alchemy.run.ts
import * as Alchemy from "alchemy";
+import * as Cloudflare from "alchemy/Cloudflare";
import * as Stripe from "alchemy/Stripe";
import * as Effect from "effect/Effect";
+import * as Layer from "effect/Layer";
import { Pro } from "./src/product.ts";

export default Alchemy.Stack(
  "MyApp",
  {
-    providers: Stripe.providers(),
+    providers: Layer.mergeAll(Cloudflare.providers(), Stripe.providers()),
    state: Alchemy.localState(),
  },
```

## Handle POST /customers

```diff lang="typescript"
        if (request.url.startsWith("/product")) {
          const live = yield* retrieveProduct().pipe(Effect.orDie);
          return yield* HttpServerResponse.json({
            id: live.id,
            name: live.name,
          });
        }
+        if (request.method === "POST" && request.url.startsWith("/customers")) {
+          const body = (yield* request.json) as { email?: string; name?: string };
+          if (!body.email) {
+            return yield* HttpServerResponse.json(
+              { error: "email is required" },
+              { status: 400 },
+            );
+          }
+          const customer = yield* createCustomer({
+            email: body.email,
+            ...(body.name !== undefined ? { name: body.name } : {}),
+          }).pipe(Effect.orDie);
+          return yield* HttpServerResponse.json(
+            { id: customer.id, email: customer.email },
+            { status: 201 },
+          );
+        }
        return HttpServerResponse.text("ok");
```

Redeploy, then:

```sh
curl -X POST "$(bun alchemy inspect MyApp url)/customers" \
  -H "content-type: application/json" \
  -d '{"email":"ada@example.com"}'
```

## Recap

The Worker retrieves the bound Product and creates Customers at
runtime. Each capability is its own `Binding.Service` plus `*Http`
layer. In [Part 4](/stripe/tutorial/part-4) you'll add a
WebhookEndpoint that points at this Worker.
