In [Part 1](/stripe/tutorial/part-1) the Product lives in the Stack
generator. Catalog belongs next to the Worker that will sell it —
the same shape as `examples/stripe-billing`. You need a Cloudflare
account for this part.

## Create the Worker

A Worker is a class with an Effect `fetch` handler. Create
`src/api.ts` and yield the same Product (`Pro`) inside it:

```typescript
// src/api.ts
import * as Cloudflare from "alchemy/Cloudflare";
import * as Stripe from "alchemy/Stripe";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/unstable/http/HttpServerResponse";

export default class Api extends Cloudflare.Worker<Api>()(
  "Api",
  {
    main: import.meta.url,
  },
  Effect.gen(function* () {
    const product = yield* Stripe.Product("Pro", {
      name: "Pro",
      description: "Billed monthly",
    });
    return {
      fetch: Effect.gen(function* () {
        return HttpServerResponse.text("ok");
      }),
    };
  }),
) {}
```

`main: import.meta.url` is required in `alchemy dev`. The logical id
`Pro` is the Product from Part 1.

## Merge Cloudflare providers

The Worker needs `Cloudflare.providers()` next to Stripe:

```diff lang="typescript"
// alchemy.run.ts
import * as Alchemy from "alchemy";
+import * as Cloudflare from "alchemy/Cloudflare";
import * as Stripe from "alchemy/Stripe";
import * as Effect from "effect/Effect";
+import * as Layer from "effect/Layer";

export default Alchemy.Stack(
  "MyApp",
  {
-    providers: Stripe.providers(),
+    providers: Layer.mergeAll(Cloudflare.providers(), Stripe.providers()),
    state: Alchemy.localState(),
  },
```

## Yield the Worker

Import `Api` and drop the Product from the Stack — it now lives on
the Worker:

```diff lang="typescript"
import * as Layer from "effect/Layer";
+import Api from "./src/api.ts";

export default Alchemy.Stack(
  "MyApp",
  {
    providers: Layer.mergeAll(Cloudflare.providers(), Stripe.providers()),
    state: Alchemy.localState(),
  },
  Effect.gen(function* () {
-    const product = yield* Stripe.Product("Pro", {
-      name: "Pro",
-      description: "Billed monthly",
-    });
-
-    return {
-      productId: product.id,
-      name: product.name,
-    };
+    const api = yield* Api;
+    return {
+      url: api.url.as<string>(),
+    };
  }),
);
```

## Add a Price

A Price belongs to a Product. Pass the Product so Alchemy creates
it first:

```diff lang="typescript"
// src/api.ts
Effect.gen(function* () {
  const product = yield* Stripe.Product("Pro", {
    name: "Pro",
    description: "Billed monthly",
  });
+  const price = yield* Stripe.Price("ProMonthly", {
+    product,
+    currency: "usd",
+    unitAmount: 2000,
+  });
  return {
    fetch: Effect.gen(function* () {
      return HttpServerResponse.text("ok");
    }),
  };
}),
```

`unitAmount` is in the currency's minor units — `2000` with
`"usd"` is $20.00. `product`, `currency`, and `unitAmount` are
create-only: changing them replaces the Price.

## Make it recurring

Omit `recurring` for a one-time charge. Add `interval: "month"` for
a subscription price:

```diff lang="typescript"
const price = yield* Stripe.Price("ProMonthly", {
  product,
  currency: "usd",
  unitAmount: 2000,
+  recurring: { interval: "month" },
});
```

Destroy deactivates a used Price (`active: false`) because Stripe
will not delete one that has been billed.

## Add a Coupon

A Coupon is independent of the Product — it discounts invoices and
Checkout:

```diff lang="typescript"
const price = yield* Stripe.Price("ProMonthly", {
  product,
  currency: "usd",
  unitAmount: 2000,
  recurring: { interval: "month" },
});
+const coupon = yield* Stripe.Coupon("Launch20", {
+  percentOff: 20,
+  duration: "once",
+  name: "Launch 20%",
+});
return {
  fetch: Effect.gen(function* () {
    return HttpServerResponse.text("ok");
  }),
};
```

`percentOff: 20` and `duration: "once"` is 20% off the first
invoice.

## Deploy

```sh
bun alchemy deploy
```
