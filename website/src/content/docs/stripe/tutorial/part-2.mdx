In [Part 1](/stripe/tutorial/part-1) you deployed a Product. A
Product is not sellable on its own — Stripe charges a **Price**.
Then a **Coupon** takes a percentage off.

## Add a Price

A Price belongs to a Product. Pass `product.id` (an Output) so
Alchemy creates the Product first:

```diff lang="typescript"
  Effect.gen(function* () {
    const product = yield* Stripe.Product("Pro", {
      name: "Pro",
      description: "Billed monthly",
    });
+    const price = yield* Stripe.Price("ProMonthly", {
+      product: product.id,
+      currency: "usd",
+      unitAmount: 2000,
+    });

    return {
      productId: product.id,
      name: product.name,
    };
  }),
```

`unitAmount` is in the currency's minor units — `2000` with
`"usd"` is $20.00. `product`, `currency`, and `unitAmount` are
create-only: changing them replaces the Price.

## Make it recurring

Omit `recurring` for a one-time charge. Add `interval: "month"` for
a subscription price:

```diff lang="typescript"
    const price = yield* Stripe.Price("ProMonthly", {
      product: product.id,
      currency: "usd",
      unitAmount: 2000,
+      recurring: { interval: "month" },
    });
```

`interval` is create-only too. Destroy deactivates a used Price
(`active: false`) because Stripe will not delete one that has been
billed.

## Return the Price id

Expose `price.id` (`price_…`) next to the Product:

```diff lang="typescript"
    return {
      productId: product.id,
      name: product.name,
+      priceId: price.id,
    };
```

## Add a Coupon

A Coupon is independent of the Product — it discounts invoices and
Checkout:

```diff lang="typescript"
    const price = yield* Stripe.Price("ProMonthly", {
      product: product.id,
      currency: "usd",
      unitAmount: 2000,
      recurring: { interval: "month" },
    });
+    const coupon = yield* Stripe.Coupon("Launch20", {
+      percentOff: 20,
+      duration: "once",
+      name: "Launch 20%",
+    });

    return {
      productId: product.id,
      name: product.name,
      priceId: price.id,
    };
```

`percentOff: 20` and `duration: "once"` is 20% off the first
invoice. Use `amountOff` plus `currency` for a fixed discount.

## Return the Coupon id

```diff lang="typescript"
    return {
      productId: product.id,
      name: product.name,
      priceId: price.id,
+      couponId: coupon.id,
    };
```

## Deploy

```sh
bun alchemy deploy
```
