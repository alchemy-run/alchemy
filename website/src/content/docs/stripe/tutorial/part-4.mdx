In [Part 3](/stripe/tutorial/part-3) `POST /customers` creates a
Stripe Customer. Handle the `customer.created` webhook on the same
Worker.

## Subscribe with consumeEvents

Call `consumeEvents` in the Worker init. Pass event **classes**:

```diff lang="typescript"
// src/api.ts
const retrieveProduct = yield* Stripe.RetrieveProduct(product);
const createCustomer = yield* Stripe.CreateCustomer();
+yield* Stripe.consumeEvents(
+  "Events",
+  { events: [Stripe.CustomerCreated] },
+  Effect.fn(function* (event) {
+    yield* Effect.log(event.type);
+  }),
+);
return {
```

The handler runs once per delivery. `event` is a `CustomerCreated`.

## Provide ConsumeEventsLive

```diff lang="typescript"
// src/api.ts
-  }).pipe(Effect.provide(Stripe.RetrieveProductHttp)),
+  }).pipe(
+    Effect.provide([
+      Stripe.RetrieveProductHttp,
+      Stripe.CreateCustomerHttp,
+      Stripe.ConsumeEventsLive,
+    ]),
+  ),
) {}
```

This yields a `WebhookEndpoint` pointed at the Worker and verifies
`Stripe-Signature`. See [Handle webhook events](/stripe/guides/webhooks).
