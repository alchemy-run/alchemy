---
title: Handle webhook events
description: consumeEvents provisions the WebhookEndpoint and runs one Effect per Stripe delivery.
---

Webhooks are two levels:

1. **`WebhookEndpoint`** — the lifecycle resource that owns the Stripe
   endpoint (URL, enabled events, signing secret).
2. **`consumeEvents`** — the event source. One Effect runs per
   delivery, keyed by the event class.

For the common case you only write level 2 — `consumeEvents` creates
the `WebhookEndpoint` pointing at the Worker and binds its minted
secret. Use a bare `WebhookEndpoint` only when you already have a URL
you own.

## Subscribe on the Worker

Pass event **classes** — not `"customer.created"` strings:

```typescript
// src/api.ts
import * as Stripe from "alchemy/Stripe";
import * as Effect from "effect/Effect";

// inside a Cloudflare.Worker's Effect.gen
yield* Stripe.consumeEvents(
  "Events",
  {
    events: [Stripe.CustomerCreated, Stripe.InvoicePaid],
  },
  Effect.fn(function* (event) {
    // event: CustomerCreated | InvoicePaid
    yield* Effect.log(event.type);
  }),
);
```

The handler is `Effect`-per-event: Stripe POSTs a delivery, the
listener verifies `Stripe-Signature`, and your handler runs once with
the typed event.

Provide `Stripe.ConsumeEventsLive` on the Worker Effect:

```typescript
}).pipe(
  Effect.provide([
    Stripe.RetrieveProductHttp,
    Stripe.ConsumeEventsLive,
  ]),
)
```

That is the whole setup. `consumeEvents` derives the delivery URL from
`worker.url`, enables the selected event types, and stores the signing
secret on the Worker.

## Endpoint resource only

Manage the endpoint yourself when you need a URL you already have:

```typescript
// alchemy.run.ts
const webhook = yield* Stripe.WebhookEndpoint("Events", {
  url: "https://example.com/webhooks/stripe",
  enabledEvents: ["customer.created"],
});
```

Declare the endpoint, then bind its secret to a Worker:

```typescript
const api = yield* Api;
const webhook = yield* Stripe.WebhookEndpoint("Events", {
  url: Output.interpolate`${api.url}/webhooks/stripe`,
  enabledEvents: [Stripe.CustomerCreated],
});
yield* Stripe.bindWebhookSecret(api, webhook.secret);
```
