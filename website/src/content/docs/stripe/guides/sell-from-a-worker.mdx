---
title: Sell from a Worker
description: Read the catalog and create customers over HTTP from a Cloudflare Worker.
---

You want a Worker that returns the live Product and creates Customers.
Put the catalog on the Worker, bind `RetrieveProduct` and
`CreateCustomer`, and provide the `*Http` layers on the Worker Effect.

## Bind the catalog

```typescript
// src/api.ts
import * as Cloudflare from "alchemy/Cloudflare";
import * as Stripe from "alchemy/Stripe";
import * as Effect from "effect/Effect";

export default class Api extends Cloudflare.Worker<Api>()(
  "Api",
  { main: import.meta.url },
  Effect.gen(function* () {
    const product = yield* Stripe.Product("Pro", {
      name: "Pro",
      description: "Billed monthly",
    });
    const retrieveProduct = yield* Stripe.RetrieveProduct(product);
    const createCustomer = yield* Stripe.CreateCustomer();

    return {
      fetch: Effect.gen(function* () {
        // routes below
      }),
    };
  }),
) {}
```

`Stripe.Product` declares the catalog item on this Worker. The
`retrieveProduct` and `createCustomer` bindings are the runtime clients
your routes will call.

## Serve the product

```typescript
import { HttpServerRequest } from "effect/unstable/http/HttpServerRequest";
import * as HttpServerResponse from "effect/unstable/http/HttpServerResponse";

// inside the Worker's fetch
const request = yield* HttpServerRequest;
if (request.url.startsWith("/product")) {
  const live = yield* retrieveProduct().pipe(Effect.orDie);
  return yield* HttpServerResponse.json({
    id: live.id,
    name: live.name,
  });
}
```

`retrieveProduct()` is request-scoped — call it from `fetch`, not at
plan time.

## Create customers

```typescript
if (request.method === "POST" && request.url.startsWith("/customers")) {
  const body = (yield* request.json) as { email?: string };
  if (!body.email) {
    return yield* HttpServerResponse.json(
      { error: "email is required" },
      { status: 400 },
    );
  }
  const customer = yield* createCustomer({
    email: body.email,
  }).pipe(Effect.orDie);
  return yield* HttpServerResponse.json(
    { id: customer.id, email: customer.email },
    { status: 201 },
  );
}
```

`createCustomer` takes the Stripe request body directly and returns the
new customer.

## Provide the HTTP layers

```typescript
}).pipe(
  Effect.provide([
    Stripe.RetrieveProductHttp,
    Stripe.CreateCustomerHttp,
  ]),
)
```

Provide every `*Http` layer on the Worker Effect, not the Stack. Yield
the Worker from the Stack with
`Layer.mergeAll(Cloudflare.providers(), Stripe.providers())`.

The host gets a [`RestrictedApiKey`](/providers/stripe/restrictedapikey)
named `{Worker}StripeToken`. Permissions come from each capability
(`products_read`, `customers_write`). The secret is
`yield* token.value` — an Output, same as R2/KV HTTP tokens.

See the [tutorial](/stripe/tutorial/part-3) for the step-by-step
version of this Worker.
