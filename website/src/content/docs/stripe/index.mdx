Stripe catalog, customers, and webhooks as Stack resources. With
alchemy you declare products, prices, and webhook endpoints next to
the Worker that sells them — a price change is a reviewable diff,
and destroy tears the test catalog down with the stage.

New here? [Set up credentials](/stripe/setup) first.

## Resources

A `Product` is the catalog item. A `Price` is what you charge for
it. Omit `name` and Alchemy generates one from the stack, stage, and
logical id:

```typescript
const product = yield* Stripe.Product("Pro", {
  name: "Pro",
  description: "Billed monthly",
});

const price = yield* Stripe.Price("ProMonthly", {
  product: product.id,
  currency: "usd",
  unitAmount: 2000,
  recurring: { interval: "month" },
});
```

`Coupon`, `PromotionCode`, and `PaymentLink` complete a checkout
catalog — see [Catalog](/stripe/guides/catalog). `Customer` is the
buyer. `WebhookEndpoint` is the HTTPS destination Stripe POSTs
events to — see [Webhooks](/stripe/guides/webhooks).

HTTP bindings (`RetrieveProduct`, `CreateCustomer`, …) run inside a
Worker or Lambda. Provide the matching `*Http` layer on the host
Effect — see [Bindings](/stripe/guides/bindings).
