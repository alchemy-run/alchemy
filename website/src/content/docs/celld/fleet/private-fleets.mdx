Not every Worker should face the internet. An internal API, or a backend for
your other services, should be reachable only from inside your network. A
fleet without `ingress` is exactly that: it has no public endpoint at all.

This chapter covers how a private fleet is reached, how a Lambda Function
calls into it, and how to put it in the VPC your services already use.

## Leave out ingress

A fleet is private unless you ask for `ingress`.

```typescript title="src/fleet.ts"
export class Cells extends Celld.Fleet<Cells>()("Cells", {
  instances: 2,
}) {}
```

`app.url` is then the fleet's private URL, such as
`http://fleet.prod-cells.celld.internal:8080`. Its name only resolves inside
the fleet's VPC, so nothing outside can even look it up.

## Call it from your other services

A service in the VPC needs three things to call in: a route to the nodes, a
security group the nodes accept, and the Worker's gateway secret.
`Celld.bindWorker` gives a Lambda Function all three.

```typescript title="src/backend.ts"
const api = yield* Celld.bindWorker(App, Api);
const response = yield* api.fetch(HttpClientRequest.get("/hello"));
```

The Function joins the fleet's subnets and its callers' security group, and
receives the URL and secret in its environment.
[Call from AWS Lambda](/celld/networking/call-from-lambda) walks through it.

The secret matters for more than `fetch`. Any caller that reaches the private
URL can call a Worker's `fetch`, but its Durable Object and RPC routes need
the gateway secret too. The operator port the
[management runner](/celld/fleet/management) uses is on a separate port that
callers can't reach.

## Share your existing VPC

A fleet in its own network can only be called by services that join it. To
let the services you already run call it, put the fleet in their VPC.

```typescript title="src/fleet.ts"
export class Cells extends Celld.Fleet<Cells>()("Cells", {
  vpc: {
    vpcId: "vpc-0123456789abcdef0",
    subnetIds: ["subnet-aaa", "subnet-bbb"],
    securityGroupIds: ["sg-0123456789abcdef0"],
  },
}) {}
```

The groups in `securityGroupIds` must allow fleet traffic on port 8080.

On Fargate, the private name round-robins across nodes through DNS, so a
long-lived connection stays on one node. Reaching a private fleet from
outside the VPC takes a VPN, peering, or switching on public
[ingress](/celld/networking/domains).
