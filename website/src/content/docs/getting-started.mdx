deploy an R2 Bucket to Cloudflare. The
[Cloudflare tutorial](/cloudflare/tutorial/part-2) continues from the

## Prerequisites

- [Bun](https://bun.sh) or Node.js 22.15+
- A [Cloudflare](https://dash.cloudflare.com/sign-up) account

## Create your stack

Every Alchemy program starts with a stack. Create `alchemy.run.ts`:

```typescript
// alchemy.run.ts
import * as Alchemy from "alchemy";
import * as Cloudflare from "alchemy/Cloudflare";
import * as Effect from "effect/Effect";

export default Alchemy.Stack(
  "MyApp", // the stack's name
  {
    providers: Cloudflare.providers(), // required, lets the stack create Cloudflare resources
    state: Cloudflare.state(), // required, where Alchemy records what it deployed
  },
  Effect.gen(function* () {
    // declares an R2 Bucket with the logical ID "Bucket"
    const bucket = yield* Cloudflare.R2.Bucket("Bucket");

    // printed as the stack's outputs after the deploy
    return {
      bucketName: bucket.bucketName,
    };
  }),
);
```

The stack is an Effect that yields resources and returns outputs. See
[Stacks](/infrastructure-as-code/stack) for the other options. See
[State Store](/state-store) to choose where state lives.

## Connect Cloudflare

Sign in to Cloudflare and save the credentials to your `default`
[profile](/environments/profiles):

Choose OAuth to sign in through the browser, or paste an API token. If
`CLOUDFLARE_ACCOUNT_ID` and `CLOUDFLARE_API_TOKEN` are set in your
shell or `.env`, Alchemy uses them instead of the profile. See
[Environment variables outside CI](/environments/profiles#environment-variables-outside-ci).

Run `alchemy deploy` to create the Bucket:

  <TabItem label="bun" icon="bun">
    <Code code="bun alchemy deploy" lang="sh" />
  </TabItem>

    <Code code="npx alchemy deploy" lang="sh" />
  </TabItem>
  <TabItem label="pnpm" icon="pnpm">
    <Code code="pnpm alchemy deploy" lang="sh" />
  </TabItem>
  <TabItem label="yarn" icon="seti:yarn">
    <Code code="yarn alchemy deploy" lang="sh" />
  </TabItem>
</Tabs>

The first deploy on an account asks to create the
`alchemy-state-store` Worker once. Every stack and stage on the account
shares it, so choose Deploy. See
[First-run bootstrap](/state-store#first-run-bootstrap).

Alchemy then shows the plan, asks for confirmation, and creates the
Bucket:

[s2]bucketName: "myapp-bucket-a1b2c3d4e5",
}`} />

You now have a live R2 Bucket on Cloudflare.

## Clean up

If you don't continue to the
[tutorial](/cloudflare/tutorial/part-2), delete the Bucket:

<Tabs syncKey="pkgManager">
  <TabItem label="bun" icon="bun">
    <Code code="bun alchemy destroy" lang="sh" />
  </TabItem>
  <TabItem label="npm" icon="npm">
    <Code code="npx alchemy destroy" lang="sh" />
  </TabItem>
  <TabItem label="pnpm" icon="pnpm">
    <Code code="pnpm alchemy destroy" lang="sh" />
  </TabItem>
  <TabItem label="yarn" icon="seti:yarn">
    <Code code="yarn alchemy destroy" lang="sh" />
  </TabItem>
</Tabs>

`alchemy destroy` deletes every resource in the stack for the same
default stage that `alchemy deploy` used. The state-store Worker isn't part of your
stack, so it stays. See [destroy](/cli/destroy).
