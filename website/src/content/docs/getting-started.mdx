## Create your Stack

Every Alchemy program starts with a Stack. Create `alchemy.run.ts`:

```typescript
// alchemy.run.ts
import * as Alchemy from "alchemy";
import * as Cloudflare from "alchemy/Cloudflare";
import * as Effect from "effect/Effect";

export default Alchemy.Stack(
  "MyApp",
  {
    providers: Cloudflare.providers(),
    state: Cloudflare.state(),
  },
  Effect.gen(function* () {
    const bucket = yield* Cloudflare.R2.Bucket("Bucket");

    return {
      bucketName: bucket.bucketName,
    };
  }),
);
```

`"MyApp"` is the Stack's name. `providers: Cloudflare.providers()`
lets the Stack create Cloudflare resources. `state: Cloudflare.state()`
picks where Alchemy records what it deployed. Both options are
required. `yield* Cloudflare.R2.Bucket("Bucket")` declares a Bucket
with the logical ID `Bucket`. The object you return is printed as the
Stack's outputs after the deploy. See
[Stacks](/infrastructure-as-code/stack) and
[State Store](/state-store).

## Deploy

Run `alchemy deploy` to create the Bucket on Cloudflare:

<Tabs syncKey="pkgManager">
  <TabItem label="bun" icon="bun">
    <Code code="bun alchemy deploy" lang="sh" />
  </TabItem>
  <TabItem label="npm" icon="npm">
    <Code code="npx alchemy deploy" lang="sh" />
  </TabItem>
  <TabItem label="pnpm" icon="pnpm">
    <Code code="pnpm alchemy deploy" lang="sh" />
  </TabItem>
  <TabItem label="yarn" icon="seti:yarn">
    <Code code="yarn alchemy deploy" lang="sh" />
  </TabItem>
</Tabs>

Connect Cloudflare first with `alchemy profile edit --add Cloudflare`.
Sign in with OAuth in the browser or paste an API token. The
credentials are saved to your `default`
[profile](/environments/profiles) in
`~/.alchemy/profiles/default/cloudflare.json`. You don't need
environment variables. If `CLOUDFLARE_ACCOUNT_ID` and
`CLOUDFLARE_API_TOKEN` are set in your shell or `.env`, Alchemy uses
them instead of the profile. See
[Environment variables outside CI](/environments/profiles#environment-variables-outside-ci).
Login only happens through the `profile` command. A deploy with
nothing configured fails and prints the exact command to run.

The first deploy on an account also asks to deploy Alchemy's
state-store Worker, `alchemy-state-store`. It is created once per
account and shared by every Stack and stage. Choose Deploy. See
[First-run bootstrap](/state-store#first-run-bootstrap). To keep state
on disk instead, use `State.localState()` from `alchemy/State`.

Once you're authenticated, Alchemy shows a plan, asks for
confirmation, and provisions the resource:

<Terminal content={`[u]Plan[/u]: [g]1 to create[/g]
[g]+[/g] [b]Bucket[/b] [d](Cloudflare.R2.Bucket)[/d]

Proceed?
◉ Yes ○ No
[g]✓[/g] [b]Bucket[/b] [d](Cloudflare.R2.Bucket)[/d] [g]created[/g]
{
[s2]bucketName: "myapp-bucket-a1b2c3d4e5",
}`} />

You now have a live R2 Bucket on Cloudflare.

See [CLI](/cli) for the full command reference.

:::tip
To re-run the credential prompt later (e.g. to switch from OAuth to
an API token), use `alchemy profile edit --reconfigure Cloudflare`.
For a separate profile, run `alchemy profile create prod` followed by
`alchemy profile edit --profile prod`.
See [Profiles](/environments/profiles) for the full picture.
:::

## Clean up

Run `alchemy destroy` to remove what you deployed:

<Tabs syncKey="pkgManager">
  <TabItem label="bun" icon="bun">
    <Code code="bun alchemy destroy" lang="sh" />
  </TabItem>
  <TabItem label="npm" icon="npm">
    <Code code="npx alchemy destroy" lang="sh" />
  </TabItem>
  <TabItem label="pnpm" icon="pnpm">
    <Code code="pnpm alchemy destroy" lang="sh" />
  </TabItem>
  <TabItem label="yarn" icon="seti:yarn">
    <Code code="yarn alchemy destroy" lang="sh" />
  </TabItem>
</Tabs>

This deletes every resource in the Stack for the same default stage
that `alchemy deploy` used. R2 refuses to delete a Bucket that still
holds objects (`BucketNotEmpty`) unless the Bucket sets
`forceDestroy: true`. The shared state-store Worker is not part of your
Stack and stays. See [destroy](/cli/destroy).
