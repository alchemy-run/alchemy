## Install

Alchemy installs its core runtime separately from provider packages.
This page imports `alchemy/Cloudflare`, so the install command includes
the Cloudflare packages that provide the resource API, local Worker
runtime, Worker bundling plugins, and Worker type definitions.

## Create your Stack

Every Alchemy program starts with a Stack — create `alchemy.run.ts`:

```typescript
// alchemy.run.ts
import * as Alchemy from "alchemy";
import * as Cloudflare from "alchemy/Cloudflare";
import * as Effect from "effect/Effect";

export default Alchemy.Stack(
  "MyApp",
  {
    providers: Cloudflare.providers(),
    state: Cloudflare.state(),
  },
  Effect.gen(function* () {
    const bucket = yield* Cloudflare.R2Bucket("Bucket");

    return {
      bucketName: bucket.bucketName,
    };
  }),
);
```

## Deploy

Run `alchemy deploy` to create the Bucket on Cloudflare:

  <TabItem label="bun" icon="bun">
    <Code code="bun alchemy deploy" lang="sh" />
  </TabItem>
  <TabItem label="npm" icon="npm">
    <Code code="npx alchemy deploy" lang="sh" />
  </TabItem>
  <TabItem label="pnpm" icon="pnpm">
    <Code code="pnpm alchemy deploy" lang="sh" />
  </TabItem>
  <TabItem label="yarn" icon="seti:yarn">
    <Code code="yarn alchemy deploy" lang="sh" />
  </TabItem>
</Tabs>

The first time you deploy, Alchemy walks each provider in your stack
(here, Cloudflare) through an interactive login and saves the
credentials to your **`default`** [profile](/concepts/profiles) at
`~/.alchemy/profiles.json`. For Cloudflare you can sign in with
OAuth in the browser or paste an API token — no environment
variables required.

Once you're authenticated, Alchemy shows a plan, asks for
confirmation, and provisions the resource:

<Terminal content={`[u]Plan[/u]: [g]1 to create[/g]
[g]+[/g] [b]Bucket[/b] [d](Cloudflare.R2Bucket)[/d]

Proceed?
◉ Yes ○ No
[g]✓[/g] [b]Bucket[/b] [d](Cloudflare.R2Bucket)[/d] [g]created[/g]
{
[s2]bucketName: "myapp-bucket-a1b2c3d4e5",
}`} />

That's it — you have a live R2 Bucket on Cloudflare.

:::tip
To re-run the credential prompt later (e.g. to switch from OAuth to
an API token, or to add a `prod` profile) use
`alchemy login --configure` or `alchemy login --profile prod --configure`.
See [Profiles](/concepts/profiles) for the full picture.
:::
