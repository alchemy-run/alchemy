In this part you install Alchemy, create a Stack with an Object Storage
Bucket, and deploy it to your STACKIT project.

## Prerequisites

- [Bun](https://bun.sh) or Node.js 24.11.1+
- A STACKIT project and a service-account key that can create what you
  deploy. See [Setup](/stackit/setup).

:::note[Cost]
Object Storage bills what you store. An empty Bucket holds nothing.
:::

## Create the Stack

Every Alchemy program starts with a `Stack`. Create `alchemy.run.ts`:

```typescript
// alchemy.run.ts
import * as Alchemy from "alchemy";
import * as Stackit from "@alchemy.run/stackit";
import * as Effect from "effect/Effect";

export default Alchemy.Stack(
  "MyApp",
  {
    providers: Stackit.providers(),
    state: Alchemy.localState(),
  },
  Effect.gen(function* () {
    // resources go here next
  }),
);
```

The first argument, `"MyApp"`, names the Stack. Alchemy uses it as a
prefix when it generates names for your resources.

`Stackit.providers()` registers every STACKIT resource.

## Where state lives

`state: Alchemy.localState()` keeps deploy state on disk under `.alchemy/`
next to your code. Add it to `.gitignore`:

```sh
echo ".alchemy/" >> .gitignore
```

:::note[Other state stores]
STACKIT has no state store of its own. Local state suits one person on one
machine, and [Part 5](/stackit/tutorial/part-5) moves it somewhere CI can
reach. See [State store](/state-store).
:::

## Connect your project

Point Alchemy at your project once:

```sh
bun alchemy profile edit --add Stackit
```

Alchemy asks for the path to your service-account key file and your
project ID. The choice is saved to your `default`
[profile](/environments/profiles).

## Add a Bucket

Declare an Object Storage Bucket inside the Stack:

```diff lang="typescript"
// alchemy.run.ts
import * as Alchemy from "alchemy";
import * as Stackit from "@alchemy.run/stackit";
import * as Effect from "effect/Effect";

export default Alchemy.Stack(
  "MyApp",
  {
    providers: Stackit.providers(),
    state: Alchemy.localState(),
  },
  Effect.gen(function* () {
+    const bucket = yield* Stackit.ObjectStorage.Bucket("Bucket", {});
  }),
);
```

`Bucket` is the logical id. Alchemy generates a unique bucket name from the
Stack, stage, and logical id. The first deploy also enables Object Storage
for your project.

## Return Stack outputs

Return the values you want to see after a deploy:

```diff lang="typescript"
// alchemy.run.ts
Effect.gen(function* () {
  const bucket = yield* Stackit.ObjectStorage.Bucket("Bucket", {});
+
+  return {
+    bucketName: bucket.bucketName,
+  };
}),
```

`bucket.bucketName` is an Output. It resolves during the deploy and prints
with the rest of the outputs.

## Destroy (optional)

`destroy` deletes everything the Stack created:

```sh
bun alchemy destroy
```

Deploy again afterwards if you try it. Part 2 builds on the Bucket.

## Recap

You now have:

- An `alchemy.run.ts` with a Stack and an Object Storage Bucket
- A Bucket in your STACKIT project
- Stack outputs showing the Bucket name

In [Part 2](/stackit/tutorial/part-2), you put an HTTP handler on a Function
that reads and writes objects in this Bucket.
