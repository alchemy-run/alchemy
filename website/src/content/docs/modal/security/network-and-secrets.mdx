---
title: Network & secrets
description: Limit what a sandbox can reach and give it credentials it can't read.
---

## Block the network

```typescript
const sandbox = yield* sandboxes.create({ blockNetwork: true });
```

## Allow only some destinations

```typescript
const sandbox = yield* sandboxes.create({
  allowedDomains: ["github.com", "registry.npmjs.org"],
  cidrAllowlist: ["10.0.0.0/8"],
});
```

Change it while the sandbox runs with `sandbox.setNetworkAccess(...)`.

## Store a secret

```typescript
// src/Storage.ts
import * as Modal from "@alchemy.run/modal";
import * as Redacted from "effect/Redacted";

export const OpenAI = Modal.Secret("OpenAI", {
  env: { OPENAI_API_KEY: Redacted.make("sk-...") },
});
```

## Inject it into requests

```typescript
// construction phase: read the Secret's id
const openaiId = yield* (yield* OpenAI).secretId;
// in a handler
const openai = { secretId: yield* openaiId };
const sandbox = yield* sandboxes.create({
  outboundPolicy: {
    routes: [
      {
        https: {
          domains: ["api.openai.com"],
          headerReplacements: [{ secret: openai, headers: { Authorization: "Bearer $OPENAI_API_KEY" } }],
        },
      },
      { any: {} },
    ],
  },
});
```

Modal adds the header on the way out. Code in the sandbox never sees the key.

## Or expose it as environment variables

```typescript
const sandbox = yield* sandboxes.create({ secrets: [openai] });
```

## A secret per user

```typescript
const secrets = yield* Modal.CreateSecret(Agents);
const github = yield* secrets.put(`github-${user}`, { GITHUB_TOKEN: token });
```

## Static egress IPs

```typescript
// src/Network.ts
import * as Modal from "@alchemy.run/modal";

export const Egress = Modal.Proxy("Egress", { ips: 1 });
```

Pass `proxy: egress` to `create`. Proxies need Modal's Team plan.
