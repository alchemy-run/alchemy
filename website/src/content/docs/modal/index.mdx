Modal is a cloud platform that runs your code in containers, with GPUs on demand. Functions and Servers scale from zero with traffic, and Sandboxes are containers your code creates while it runs, for code it doesn't trust. Images, Volumes, Dicts, Queues and Secrets live next to them, and you pay per second for what runs.

**New to Modal?** Start with [What is Modal?](/modal/what-is-modal).

## A quick example

An image is what every sandbox starts from. Modal builds it, so a deploy needs no Docker:

```typescript title="src/sandbox.ts"
import * as Modal from "@alchemy.run/modal";

export const Coder = Modal.App("Coder", {});

export const Node = Modal.Image("Node", {
  app: Coder,
  image: "node:22-bookworm",
  commands: ["RUN apt-get update && apt-get install -y git"],
});
```

A Worker creates a sandbox from it on each request, runs a command, and stops it when the request ends:

```typescript title="src/api.ts"
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Modal from "@alchemy.run/modal";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/http/HttpServerResponse";
import { Node } from "./sandbox.ts";

export default class Api extends Cloudflare.Worker<Api>()(
  "Api",
  { main: import.meta.url, compatibility: { flags: ["nodejs_compat"] } },
  Effect.gen(function* () {
    const sandboxes = yield* Modal.CreateSandbox(Node);
    return {
      fetch: Effect.gen(function* () {
        const sandbox = yield* Effect.acquireRelease(
          sandboxes.create({ timeout: "5 minutes" }),
          (sandbox) => Effect.ignore(sandbox.terminate()),
        );
        const result = yield* sandbox.exec(["git", "--version"]);
        return yield* HttpServerResponse.json(result);
      }).pipe(Effect.scoped, Effect.orDie),
    };
  }).pipe(Effect.provide(Modal.CreateSandboxHttp)),
) {}
```

And the Stack deploys both:

```typescript title="alchemy.run.ts"
import * as Alchemy from "alchemy";
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Modal from "@alchemy.run/modal";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import Api from "./src/api.ts";

export default Alchemy.Stack(
  "MyApp",
  {
    providers: Layer.mergeAll(Cloudflare.providers(), Modal.providers()),
    state: Cloudflare.state(),
  },
  Effect.gen(function* () {
    const api = yield* Api;
    return { url: api.url };
  }),
);
```
