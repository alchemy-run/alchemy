An App is a globally unique namespace. A Machine is a Firecracker VM
running a container. A Service is an Effect program running in a Fly
Machine. Set `count` to scale it up or down.

Disks, secrets, IPs, and certificates are declared in the same
TypeScript program.

[Set up your org and API token](/fly/setup), then start the
[tutorial](/fly/tutorial/part-1).

## Compute

- **[Apps](/fly/compute/apps)** — the parent for every other
  resource. Alchemy generates a globally unique name unless you pass
  one. `https://{appName}.fly.dev` is the public URL.
- **[Machines](/fly/compute/machines)** — a Firecracker VM running a
  container image. Use this when you already have an image
  (`nginx:alpine`, a registry tag). Region, guest size, proxy
  services, env, and mounts are all props.
- **[Services](/fly/compute/services)** — an Effect program running
  in a Machine. Alchemy bundles `main`, builds the image, and
  updates in place when the hash changes. Set `count` to scale.

## Storage

- **[Volumes](/fly/data/volumes)** — region-local block storage.
  Mount one into a Service with `MountVolume({ path, sizeGb })`, or
  pass `mounts` on a Machine. A Volume attaches to **one** Machine;
  `count: N` creates N disks, not one shared disk.

## Secrets

- **[Secrets](/fly/data/secrets)** — `Config.redacted` in a Service
  for values from `.env`. `Fly.Secret` when Fly should own a value
  shared across Machines. KMS keys are `SecretKey` plus `Encrypt` /
  `Decrypt` / `Sign` / `Verify`.

## Networking

- **[IPs & certificates](/fly/networking)** — shared or dedicated
  addresses (`IpAssignment`) so `{app}.fly.dev` answers over IPv4,
  plus ACME or uploaded TLS certificates for your own hostname.

## What are you building?

| You're building              | Reach for                                                                 |
| ---------------------------- | ------------------------------------------------------------------------- |
| An HTTP API on Fly           | [App](/fly/compute/apps) + [Service](/fly/compute/services)               |
| A raw container              | [Machine](/fly/compute/machines) with an `image`                          |
| A background worker          | [Service](/fly/compute/services) with `ServerHost.run`                    |
| Persistent disk              | [MountVolume](/fly/data/volumes) or Machine `mounts`                      |
| N replicas behind fly.dev    | Service / Machine `count`                                                 |
| Restore a disk               | [VolumeSnapshot](/fly/data/volumes#snapshots) + mount `snapshotId`        |
| Config / API tokens          | [`Config.redacted`](/fly/data/secrets). [`Fly.Secret`](/fly/data/secrets) when Fly should own it |
| Sign / encrypt in-app        | [SecretKey](/fly/data/secrets#kms-keys) + `Encrypt` / `Sign`              |
| `{app}.fly.dev` over IPv4    | [IpAssignment](/fly/networking) `type: "shared_v4"`                       |
| Your own domain              | [Certificate](/fly/networking#certificates) (ACME)                        |
