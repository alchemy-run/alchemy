Each [Service](/fly/compute/services) is its own Fly App. A private
Service (`public: false`) has no internet address; other Apps call it
at its `privateUrl`, `http://{appName}.flycast`, through Fly's proxy.

Who can reach that address depends on the private network the App is
on:

- **The organization's default network.** Every App in the org joins
  it unless told otherwise, so every App in the org can call a
  private Service.
- **A network of your own.** Set `network` on each Service. Only Apps
  on the same network can resolve its `privateUrl` or `.internal`
  name. `Fly.stackNetwork` names a network unique to the current
  stack and stage, so a stage's Services reach each other and nothing
  else does.

This guide builds the
[fly-microservices example](https://github.com/alchemy-run/alchemy/tree/main/examples/fly-microservices):
a private `Users` Service, a private `Orders` Service that calls
`Users`, and a public `Gateway` that forwards to both. All three join
`Fly.stackNetwork`.

## Create the Users Service

`Users` is private: `public: false` gives its App a Flycast address
and no internet address. Its props are an Effect so later steps can
`yield*` inside them.

```typescript
// src/users.ts
import * as Fly from "alchemy/Fly";
import * as Effect from "effect/Effect";
import { HttpServerRequest } from "effect/unstable/http/HttpServerRequest";
import * as HttpServerResponse from "effect/unstable/http/HttpServerResponse";

export const USERS = [
  { id: "u1", name: "Ada" },
  { id: "u2", name: "Grace" },
];

export default class Users extends Fly.Service<Users>()(
  "Users",
  Effect.gen(function* () {
    return {
      main: import.meta.url,
      public: false,
    };
  }),
  Effect.gen(function* () {
    return {
      fetch: Effect.gen(function* () {
        const request = yield* HttpServerRequest;
        const id = new URL(request.url, "http://users").pathname.slice(1);
        if (id.length === 0) return yield* HttpServerResponse.json(USERS);
        const user = USERS.find((candidate) => candidate.id === id);
        return user === undefined
          ? HttpServerResponse.text("not found", { status: 404 })
          : yield* HttpServerResponse.json(user);
      }),
    };
  }),
) {}
```

`/` lists every user and `/{id}` returns one. `Users` now answers at `privateUrl` for every App in the
organization.

## Put Users on the stack's network

Add `network` to restrict `Users` to this stage's Services:

```diff lang="typescript"
Effect.gen(function* () {
  return {
    main: import.meta.url,
    public: false,
+    network: yield* Fly.stackNetwork,
  };
}),
```

`Fly.stackNetwork` is an Effect that yields a network name built from
the stack and stage (`flymicroservices-dev`, for example). Fly creates
the network with the first App that names it. Apps on any other
network, including the org default, cannot resolve `Users`.

:::caution[Changing `network` replaces the Service]
Fly cannot move an App between networks. Alchemy creates the Service
on the new network, then deletes the old App. `network` only applies
when the Service owns its App; combining it with `app` fails with
`Fly.InvalidServiceProps`.
:::

## Reference Users from Orders

`Orders` is a second private Service on the same network. Yield
`Users` inside its props and pass `users.privateUrl` through `env`:

```typescript
// src/orders.ts
import * as Fly from "alchemy/Fly";
import * as Effect from "effect/Effect";
import Users from "./users.ts";

export default class Orders extends Fly.Service<Orders>()(
  "Orders",
  Effect.gen(function* () {
    const users = yield* Users;
    return {
      main: import.meta.url,
      public: false,
      network: yield* Fly.stackNetwork,
      env: { USERS_URL: users.privateUrl },
    };
  }),
  Effect.gen(function* () {
    return {};
  }),
) {}
```

Alchemy writes `USERS_URL` onto the `Orders` Machines once `Users` is
deployed.

## Call Users from Orders

Read `USERS_URL` with `Config` and fetch each order's user from it:

```diff lang="typescript"
// src/orders.ts
+import * as Config from "effect/Config";
+import * as FetchHttpClient from "effect/unstable/http/FetchHttpClient";
+import * as HttpClient from "effect/unstable/http/HttpClient";
+import * as HttpServerResponse from "effect/unstable/http/HttpServerResponse";
// ...
+const ORDERS = [
+  { id: "o1", userId: "u1", item: "keyboard" },
+  { id: "o2", userId: "u2", item: "monitor" },
+];
// ...
Effect.gen(function* () {
-  return {};
+  return {
+    fetch: Effect.gen(function* () {
+      const usersUrl = yield* Config.String("USERS_URL");
+      const orders = yield* Effect.forEach(ORDERS, (order) =>
+        HttpClient.get(`${usersUrl}/${order.userId}`).pipe(
+          Effect.flatMap((response) => response.json),
+          Effect.map((user) => ({ ...order, user })),
+        ),
+      );
+      return yield* HttpServerResponse.json(orders);
+    }).pipe(Effect.provide(FetchHttpClient.layer), Effect.orDie),
+  };
}),
```

The request goes to `http://{users-app}.flycast/u1` over the private
network.

## Add the public Gateway

`Gateway` yields both backends and joins the same network. It leaves
out `public: false`, so it is public:

```typescript
// src/gateway.ts
import * as Fly from "alchemy/Fly";
import * as Effect from "effect/Effect";
import Orders from "./orders.ts";
import Users from "./users.ts";

export default class Gateway extends Fly.Service<Gateway>()(
  "Gateway",
  Effect.gen(function* () {
    const users = yield* Users;
    const orders = yield* Orders;
    return {
      main: import.meta.url,
      network: yield* Fly.stackNetwork,
      env: { USERS_URL: users.privateUrl, ORDERS_URL: orders.privateUrl },
    };
  }),
  Effect.gen(function* () {
    return {};
  }),
) {}
```

A public Service on the network still serves `url`, so `Gateway` is
the stack's single entry point from the internet.

## Route requests in the Gateway

Forward `/users` and `/orders` to the matching private URL:

```diff lang="typescript"
// src/gateway.ts
+import * as Config from "effect/Config";
+import * as FetchHttpClient from "effect/unstable/http/FetchHttpClient";
+import * as HttpClient from "effect/unstable/http/HttpClient";
+import { HttpServerRequest } from "effect/unstable/http/HttpServerRequest";
+import * as HttpServerResponse from "effect/unstable/http/HttpServerResponse";
// ...
Effect.gen(function* () {
-  return {};
+  return {
+    fetch: Effect.gen(function* () {
+      const request = yield* HttpServerRequest;
+      const path = new URL(request.url, "http://gateway").pathname;
+      const upstream =
+        path === "/users"
+          ? yield* Config.String("USERS_URL")
+          : path === "/orders"
+            ? yield* Config.String("ORDERS_URL")
+            : undefined;
+      if (upstream === undefined) {
+        return HttpServerResponse.text("try /users or /orders");
+      }
+      const body = yield* HttpClient.get(upstream).pipe(
+        Effect.flatMap((response) => response.json),
+      );
+      return yield* HttpServerResponse.json(body);
+    }).pipe(Effect.provide(FetchHttpClient.layer), Effect.orDie),
+  };
}),
```

## Wire the Stack

Yield the three Services and return the public and private URLs:

```typescript
// alchemy.run.ts
import * as Alchemy from "alchemy";
import * as Fly from "alchemy/Fly";
import * as Effect from "effect/Effect";
import Gateway from "./src/gateway.ts";
import Orders from "./src/orders.ts";
import Users from "./src/users.ts";

export default Alchemy.Stack(
  "FlyMicroservices",
  { providers: Fly.providers(), state: Alchemy.localState() },
  Effect.gen(function* () {
    const users = yield* Users;
    const orders = yield* Orders;
    const gateway = yield* Gateway;

    return {
      url: gateway.url,
      network: gateway.network,
      usersPrivateUrl: users.privateUrl,
      ordersPrivateUrl: orders.privateUrl,
    };
  }),
);
```

## Try it out

```sh
curl https://flymicroservices-gateway-dev-a1b2c3d4.fly.dev/users
# → [{"id":"u1","name":"Ada"},{"id":"u2","name":"Grace"}]

curl https://flymicroservices-gateway-dev-a1b2c3d4.fly.dev/orders
# → [{"id":"o1","userId":"u1","item":"keyboard","user":{"id":"u1","name":"Ada"}}, ...]
```

The second request crosses two private hops: Gateway → Orders →
Users.

## How deploy order works

Yielding a Service inside another Service's props makes it a
dependency. `Orders` yields `Users`, and `Gateway` yields both, so
Alchemy deploys `Users`, then `Orders`, then `Gateway`. Each caller's
`env` receives the resolved `privateUrl` of the Services it yielded.

The order of `yield*` in the Stack does not matter; the dependencies
come from the props.

## Public `url` and private `privateUrl`

| Service   | `url`                          | `privateUrl`                      |
| --------- | ------------------------------ | --------------------------------- |
| `Users`   | `undefined`                    | `http://{users-app}.flycast`      |
| `Orders`  | `undefined`                    | `http://{orders-app}.flycast`     |
| `Gateway` | `https://{gateway-app}.fly.dev` | `undefined`                      |

`url` is the internet endpoint and is set only for a public Service.
`privateUrl` is set for a Service that publishes plain HTTP, which
every private Service does. Fly issues no certificate for `.flycast`,
so calls between Services are plain HTTP on the private network.

Prefer `privateUrl` over `{appName}.internal`. Both resolve on the
network, but `.internal` goes straight to Machines and skips the
proxy, so it ignores service checks, `autostart`, and the traffic
switch of a [blue/green deployment](/fly/compute/deployments).

## What an outside App sees

An App that is not on the stack's network cannot resolve the private
names at all. From a Machine in an App on the org's default network:

```sh
wget -qO- http://flymicroservices-users-dev-e5f6a7b8.flycast
# wget: bad address 'flymicroservices-users-dev-e5f6a7b8.flycast'

wget -qO- http://flymicroservices-users-dev-e5f6a7b8.internal
# wget: bad address 'flymicroservices-users-dev-e5f6a7b8.internal'
```

Other stages of the same stack get their own `Fly.stackNetwork`, so
`dev` and `prod` Services cannot call each other either.

## Defense in depth

The network keeps other Apps out, but everything on it is trusted:
`Gateway` can call `Users` directly, and so can any Service you add
to the network later. If some Services on the network should not call
others, add an application-level check, such as a shared token that
`Users` requires in a request header and only the allowed callers
send. Read the token with `Config.Redacted` in each of those Services;
see [Secrets](/fly/data/secrets) for how Config values reach the
Machine.
