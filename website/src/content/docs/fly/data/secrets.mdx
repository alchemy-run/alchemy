title: Secrets
description: Fly App secrets and KMS keys — manage values as resources, read and write them from Services and Actions.
---

A [`Secret`](/providers/fly/secret) is an App-level value Fly
injects into Machines as an environment variable (unless the Machine
sets `skip_secrets`). The plaintext is never stored in attributes or
logged — wrap it with `Redacted.make`.

## Create a Secret

```typescript
import * as Fly from "alchemy/Fly";
import * as Redacted from "effect/Redacted";

export const ApiToken = Fly.Secret("ApiToken", {
  app: Site,
  name: "API_TOKEN",
  value: Redacted.make("…"),
});
```

`name` is the env-var Machines see. Omit it and Alchemy generates an
ownership-stamped name. Updating `value` is in place
(`secretsUpdate`). Changing `app` or `name` replaces.

## Read at runtime

`ReadSecret` is a binding. Pass the Secret declaration into a
Service (or Action) and provide `ReadSecretHttp`:

```typescript
export default class Api extends Fly.Service<Api>()(
  "Api",
  { app: Site, main: import.meta.url, port: 3000 },
  Effect.gen(function* () {
    const secrets = yield* Fly.ReadSecret(ApiToken);

    return {
      fetch: Effect.gen(function* () {
        const got = yield* secrets.get().pipe(Effect.orDie);
        return HttpServerResponse.json({ name: got.name });
      }),
    };
  }).pipe(Effect.provide(Fly.ReadSecretHttp)),
) {}
```

`get()` defaults to the bound Secret's name; `list()` lists the App.
Fly only returns plaintext from a Machine in the same App. From
deploy-time Actions you get metadata (name, digest, timestamps).

`WriteSecret` / `ReadWriteSecret` cover create, update, and delete.
Provide `WriteSecretHttp` or `ReadWriteSecretHttp`.

## KMS keys

[`SecretKey`](/providers/fly/secretkey) is an App KMS key
(generate / set / get / delete). Some orgs are not entitled — the
live tests skipIf-gate that path and keep an ungated probe for the
typed rejection.
