A [`Secret`](/providers/fly/secret) is an App-level value Fly
injects into every Machine as an environment variable. A
[`SecretKey`](/providers/fly/secretkey) is Fly KMS — private
material never leaves Fly. Alchemy models both as **resources** for
values that belong to your stack, plus **bindings** for code that
reads, rotates, encrypts, or signs at runtime. Wrap env values with
`Redacted.make`.

## Create a Secret

```typescript
import * as Fly from "alchemy/Fly";
import * as Redacted from "effect/Redacted";

export const ApiToken = Fly.Secret("ApiToken", {
  app: Site,
  name: "API_TOKEN",
  value: Redacted.make("…"),
});
```

`name` is the env-var Machines see. Omit it and Alchemy generates an
ownership-stamped name. Updating `value` is in place
(`secretsUpdate`). Changing `app` or `name` replaces.

The resolved resource exposes `name`, `digest`, `createdAt`, and
`updatedAt` — never the plaintext. See the
[`Secret` reference](/providers/fly/secret).

## Read at runtime

`ReadSecret` is a binding. Pass the Secret declaration into a
[Service](/fly/compute/services) (or an Action) and provide
`ReadSecretHttp`:

```typescript
export default class Api extends Fly.Service<Api>()(
  "Api",
  { app: Site, main: import.meta.url, port: 3000 },
  Effect.gen(function* () {
    const secrets = yield* Fly.ReadSecret(ApiToken);

    return {
      fetch: Effect.gen(function* () {
        const got = yield* secrets.get().pipe(Effect.orDie);
        return HttpServerResponse.json({ name: got.name });
      }),
    };
  }).pipe(Effect.provide(Fly.ReadSecretHttp)),
) {}
```

`get()` defaults to the bound Secret's name; `list()` lists the App.
Fly only returns plaintext from a Machine in the same App. From
deploy-time Actions you get metadata (name, digest, timestamps).

## Query & mutate from Effects

For secrets that aren't a declared resource — seeding, rotation,
lookups — bind a typed client to an App. Three bindings, each with
a matching layer:

| Binding | Layer | Client |
| --- | --- | --- |
| `Fly.ReadSecret(secret)` | `Fly.ReadSecretHttp` | `get`, `list` |
| `Fly.WriteSecret(secret)` | `Fly.WriteSecretHttp` | `create`, `update`, `delete` |
| `Fly.ReadWriteSecret(secret)` | `Fly.ReadWriteSecretHttp` | both |

The App is fixed when you bind — pass the Secret declaration
directly, and calls never pass an `app_name`:

```typescript
import * as Alchemy from "alchemy";
import * as Fly from "alchemy/Fly";
import * as Effect from "effect/Effect";
import * as Redacted from "effect/Redacted";
import { ApiToken } from "./app.ts";

const Seed = Alchemy.Action(
  "Seed",
  Effect.gen(function* () {
    const secrets = yield* Fly.WriteSecret(ApiToken);

    return Effect.fn(function* () {
      yield* secrets.update("API_TOKEN", Redacted.make("sk_live_rotated"));
    });
  }).pipe(Effect.provide(Fly.WriteSecretHttp)),
);
```

Inside a Service, Alchemy mints an App deploy token for the Machine.
Inside an Action, the ambient `FLY_API_TOKEN` is used instead.

## KMS keys

[`SecretKey`](/providers/fly/secretkey) is an App KMS key, not an
env secret. Generate a random key or set raw material. Private
bytes never appear in attributes.

```typescript
export const Signing = Fly.SecretKey("Signing", {
  app: Site,
  type: "nacl_sign",
});

export const Box = Fly.SecretKey("Box", {
  app: Site,
  type: "nacl_secretbox",
});
```

`type` is Fly's key type (`nacl_sign`, `nacl_box`, `nacl_secretbox`,
`hs256`, `es256`, `xaes256gcm`, …). Changing `app`, `name`, or
`type` replaces the key.

## Encrypt, Decrypt, Sign, Verify

One `Binding.Service` per operation, same granularity as AWS KMS.
The key is fixed when you bind — calls take no `app_name`:

| Binding | Layer | Distilled op |
| --- | --- | --- |
| `Fly.Encrypt(key)` | `Fly.EncryptHttp` | `secretkeyEncrypt` |
| `Fly.Decrypt(key)` | `Fly.DecryptHttp` | `secretkeyDecrypt` |
| `Fly.Sign(key)` | `Fly.SignHttp` | `secretkeySign` |
| `Fly.Verify(key)` | `Fly.VerifyHttp` | `secretkeyVerify` |

```typescript
const encrypt = yield* Fly.Encrypt(Box);
const decrypt = yield* Fly.Decrypt(Box);

const { ciphertext } = yield* encrypt({ plaintext: bytes });
const { plaintext } = yield* decrypt({ ciphertext });
const raw = Redacted.value(plaintext);
```

```typescript
const sign = yield* Fly.Sign(Signing);
const verify = yield* Fly.Verify(Signing);

const { signature } = yield* sign({ plaintext: bytes });
yield* verify({ plaintext: bytes, signature });
```

Provide the matching `*Http` layer on the Service or Action
(`Layer.mergeAll` when using more than one). Generate / set / delete
stay on the `SecretKey` resource.

Decrypt wraps plaintext in `Redacted` so it never logs. Fly crypto
ops need a KMS token — org API tokens are typed `Forbidden`. An
ungated probe pins that tag; a full round-trip is behind
`FLY_TEST_KMS=1`.
