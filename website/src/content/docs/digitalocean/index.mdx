DigitalOcean gives you plain Linux virtual machines. With alchemy a
Droplet is a resource like any other: the host, the SSH key baked
into its root account, and the firewall in front of it are declared
together in one Stack, and a change to any of them is a reviewable
diff.

New here? [Set up credentials](/digitalocean/setup) first.

## Resources

A `Droplet` is the VM, an `SshKey` is a public key registered on the
team, and a `Firewall` is a free network-level allowlist applied to
droplets by id or tag:

```typescript
import * as Alchemy from "alchemy";
import * as DigitalOcean from "alchemy/DigitalOcean";
import * as Effect from "effect/Effect";

export default Alchemy.Stack(
  "MyStack",
  {
    providers: DigitalOcean.providers(),
    state: Alchemy.localState(),
  },
  Effect.gen(function* () {
    const key = yield* DigitalOcean.SshKey("deploy-key", {
      publicKey: process.env.SSH_PUBLIC_KEY!,
    });

    const host = yield* DigitalOcean.Droplet("app", {
      region: "sfo3",
      size: "s-2vcpu-4gb",
      image: "ubuntu-24-04-x64",
      sshKeys: [key.fingerprint],
      monitoring: true,
    });

    yield* DigitalOcean.Firewall("edge", {
      dropletIds: [host.dropletId],
      inboundRules: [
        { protocol: "tcp", ports: "22", addresses: ["0.0.0.0/0", "::/0"] },
        { protocol: "tcp", ports: "443", addresses: ["0.0.0.0/0", "::/0"] },
      ],
      // outboundRules omitted — allow all outbound.
    });

    return { ip: host.ipv4 };
  }),
);
```

Names are optional everywhere — omit them and alchemy generates
unique physical names from the Stack, logical ID, and stage.
`region`, `size`, and `image` take DigitalOcean slugs — list them
with `doctl compute region list`, `doctl compute size list`, and
`doctl compute image list-distribution` (or `list-application` for
Marketplace 1-Click images).

Droplets are cattle, not pets: `name` and `tags` sync in place (a
rename action, and tag assign/unassign); changing `region`, `size`,
`image`, `sshKeys`, `userData`, or anything else replaces the host.
Provision with `userData` (cloud-init) so a replacement converges on
its own, and set `replaceAfter: "30 days"` — a duration string or a
number of milliseconds — to have the next deploy rebuild the droplet
on a fresh image once it crosses that age, so kernel and base-image
updates arrive by replacement instead of in-place mutation. A
replacement gets a new public IP: pass `host.ipv4` through as an
`Output` rather than copying the literal.

Droplet names are not unique, so alchemy stamps an
`alchemy:{stack}:{stage}:{id}` tag on every droplet it creates and
re-finds the host through it after a lost state store. A same-named
droplet without that tag belongs to someone else — the deploy fails
until you re-run with `--adopt`; see
[Adopting resources](/cli/adopting-resources).

An `SshKey` is identified by its key material: DigitalOcean derives
the `fingerprint` from `publicKey`, so changing the key replaces the
resource while renaming it updates in place. Feed `key.fingerprint`
into a droplet's `sshKeys` to embed it in the root account. A key
you already uploaded through the DigitalOcean dashboard is not
automatically yours: identical key material proves possession, not
that alchemy registered it, so the deploy fails until you re-run
with `--adopt`. The same applies to an explicitly named `Firewall`
that already exists — firewalls carry no ownership marker, so a name
match proves nothing. Omit `name` and neither case can arise.

A `Firewall` is the opposite — the API takes a full desired
representation, so every property updates in place. Traffic not
matched by an inbound rule is dropped; omitting `outboundRules`
allows all outbound (pass `[]` to deliberately drop it all). Target
droplets by `dropletIds` for an exact set, or by `tags` to cover
every droplet carrying the tag as hosts come and go.

## Compose with your cloud

`providers()` merges like any other layer, so a droplet's public
address can be the content of a Cloudflare DNS record in the same
deploy:

```typescript
providers: Layer.mergeAll(Cloudflare.providers(), DigitalOcean.providers()),
```

```typescript
// `zone` is your Cloudflare.Zone resource (or lookup) for example.com
yield* Cloudflare.DNS.Record("AppA", {
  zoneId: zone.zoneId,
  name: "app.example.com",
  type: "A",
  content: host.ipv4.as<string>(),
  proxied: true,
});
```
