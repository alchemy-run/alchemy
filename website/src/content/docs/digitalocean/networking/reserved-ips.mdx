A **reserved IP** is a public address that belongs to the team, not to a Droplet. You assign it to a Droplet in its region, and when that Droplet is replaced you assign it to the new one, so DNS records and allow-lists pointing at it never change.

## Reserve an address

```typescript
const ip = yield* DigitalOcean.ReservedIp("Web", { region: "nyc3" });
```

## Assign it to a Droplet

```typescript
yield* DigitalOcean.ReservedIpAssignment("WebIp", { ip: ip.ip, dropletId: host.dropletId });
```

When `host` is replaced, its new `dropletId` moves the assignment on the next deploy. `ReservedIpv6` and `ReservedIpv6Assignment` do the same for IPv6.

## Limits

- A reserved IP and its Droplet must be in the same region.
- An unassigned reserved IP is billed by the hour.
