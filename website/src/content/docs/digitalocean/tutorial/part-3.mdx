A managed database cluster is a PostgreSQL server DigitalOcean runs for you, with backups and failover. The App will record the path of every request in a `visits` table.

:::note[Costs]
The smallest PostgreSQL cluster costs about $15 a month, billed by the hour.
:::

## Declare a cluster

```diff lang="typescript"
// src/resources.ts
import * as DigitalOcean from "@alchemy.run/digitalocean";

export const Registry = DigitalOcean.Registry("Registry", { tier: "starter" });

export const Uploads = DigitalOcean.Spaces.Bucket("Uploads", { region: "nyc3" });
+
+export const Db = DigitalOcean.Databases.Cluster("Db", {
+  engine: "pg",
+  size: "db-s-1vcpu-1gb",
+  region: "nyc3",
+});
```

A new cluster takes five to ten minutes to come up, and deploy waits for it.

## Write a migration

Migrations are plain SQL files, applied in name order:

```sql title="migrations/0001_create_visits.sql"
CREATE TABLE visits (
  id serial PRIMARY KEY,
  path text NOT NULL,
  at timestamptz NOT NULL DEFAULT now()
);
```

## Apply migrations on deploy

```diff lang="typescript"
// alchemy.run.ts
import * as DigitalOcean from "@alchemy.run/digitalocean";
import * as Alchemy from "alchemy";
import * as Effect from "effect/Effect";
import Api from "./src/api.ts";
+import { Db } from "./src/resources.ts";

export default Alchemy.Stack(
  "MyApp",
  { providers: DigitalOcean.providers(), state: Alchemy.localState() },
  Effect.gen(function* () {
+    const db = yield* Db;
+    yield* DigitalOcean.Databases.Database("App", {
+      clusterId: db.clusterId,
+      migrations: "./migrations",
+    });
    const api = yield* Api;
    return { url: api.url };
  }),
);
```

`Database` creates a database in the cluster and applies every migration it hasn't run yet. Alchemy records each applied file in an `__alchemy_migrations` table, so a later deploy runs only new files.

## Run a query

Add a small helper inside the Effect, after `conn`:

```typescript
const query = (sql: string, params: unknown[] = []) =>
  Effect.gen(function* () {
    const uri = yield* conn.connectionString;
    return yield* Effect.tryPromise(async () => {
      const client = new pg.Client({ connectionString: Redacted.value(uri) });
      await client.connect();
      try {
        return (await client.query(sql, params)).rows;
      } finally {
        await client.end();
      }
    });
  });
```

It opens a connection per query, which is enough for a small App. Import `pg` from `"pg"` and `Redacted` from `"effect/Redacted"` at the top of the file.
