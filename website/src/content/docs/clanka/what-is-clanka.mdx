Effect Clanka is a coding agent in two parts. The **agent loop** asks the model what to do next. The model answers with a **script**: JavaScript that calls functions such as `readFile`, `bash` and `applyPatch`. The **executor** runs the script and returns what it printed, and the loop asks the model again. The two parts speak a small RPC protocol, so they can run in different places.

Take one small app: a `Coder` Durable Object with a conversation `issue-42`. The loop runs in the object and asks the `Smart` model. The conversation's sandbox on Boat runs the executor, which runs each script next to the files it works on. A script's call to your `lookupOrder` tool comes back to the object.

## Scripts

The model has one tool, `execute`, and its argument is a **script**. One script can read a file, search the project and write a change, and only what it prints goes back to the model.

```typescript
const text = await readFile({ path: "src/price.ts" });
await applyPatch(patch);
console.log(await bash({ command: "npm test", description: "Run the tests" }));
await taskComplete("Fixed the rounding in price.ts.");
```

A script ends the task by calling `taskComplete` with a summary.

## The executor

The **executor** runs scripts. It is a Node program with Clanka's functions for files, search, shell commands and the web. It runs in the conversation's sandbox, because a Durable Object has no file system and cannot start a process.

See [The executor & sandbox](/clanka/sandbox).

## The harness

The **harness** is what runs Clanka in your runtime: the models a prompt may use, your tools, and where sandboxes run. You yield it in a Durable Object's outer Effect.

```typescript
const harness = yield* Clanka.Harness({ models: [Smart], tools: [LookupOrder] });
```

## Conversations

A **conversation** is a history of prompts, scripts and their output, with one sandbox. You name it, and each prompt continues it.

```typescript
const summary = yield* harness.conversation("issue-42").prompt("Fix the failing test.");
```

See [Conversations & prompts](/clanka/conversations).

## Tools

Clanka's own functions run in the sandbox. Your tools are functions a script calls the same way, and their handlers run in the Durable Object.

See [Tools](/clanka/tools).

## How @alchemy.run/Clanka models these concepts

`Clanka.Harness` is an Effect you yield where its Layers are provided. It builds Clanka's agent with the executor reached over Clanka's own RPC protocol, carried through the sandbox's command execution. Models, tools and sandboxes are the [`@alchemy.run/ai`](/ai) declarations. `ClankaCloudflare.DurableObjectStore` keeps each conversation in the Durable Object's storage. A conversation's sandbox is found by a key made from the object's id and the conversation's name.
