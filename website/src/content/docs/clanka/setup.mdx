You need:

- [Node.js](https://nodejs.org) 24.11.1+ or [Bun](https://bun.sh)
- An Alchemy app on Cloudflare. See [Cloudflare setup](/cloudflare/setup).
- An account on a sandbox platform: [Boat](/boat/setup), [E2B](/e2b/setup), [Daytona](/daytona/setup), [Modal](/modal/setup) or [Archil](/archil/setup)

Clanka needs no account. The sandbox it runs in needs Node and npm.

## Install

Install the harness, the shared AI package and your sandbox platform's provider:

<PackageManagers add="@alchemy.run/clanka @alchemy.run/ai @alchemy.run/boat" />

## Add the sandbox provider

Clanka's executor runs in a sandbox, so the Stack needs the platform's provider next to Cloudflare's:

```typescript title="alchemy.run.ts"
import * as Boat from "@alchemy.run/boat";
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Alchemy from "alchemy";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import Api from "./src/Api.ts";

export default Alchemy.Stack(
  "MyApp",
  {
    providers: Layer.mergeAll(Cloudflare.providers(), Boat.providers()),
    state: Cloudflare.state(),
  },
  Effect.gen(function* () {
    const api = yield* Api;
    return { url: api.url };
  }),
);
```

Sign in to the platform with your profile:

<PackageManagers run="alchemy profile edit --add Boat" />

## A model and sandboxes

A harness needs a model and an `AI.Sandboxes` Layer. See [Models](/ai/models) and [Sandboxes](/ai/sandboxes#say-where-sandboxes-run).

```typescript title="src/agent.ts"
import * as AI from "@alchemy.run/ai";
import * as AIBoat from "@alchemy.run/ai/Boat";
import * as AICloudflare from "@alchemy.run/ai/Cloudflare";
import * as Boat from "@alchemy.run/boat";
import * as Clanka from "@alchemy.run/clanka";

export class Smart extends AI.Model<Smart>()("smart") {}

export const SmartLive = AICloudflare.Model(Smart, {
  model: "@cf/moonshotai/kimi-k2.6",
});

export const Base = Boat.Snapshot("Base", { run: [Clanka.installCommand] });

export const Sandbox = AIBoat.Sandboxes(Base);
```

`Clanka.installCommand` installs Clanka while the snapshot is built, so a conversation's first prompt doesn't wait for it.

## A harness

Yield the harness in a Durable Object's outer Effect and provide its Layers once:

```typescript title="src/Coder.ts"
import * as Boat from "@alchemy.run/boat";
import * as Clanka from "@alchemy.run/clanka";
import * as ClankaCloudflare from "@alchemy.run/clanka/Cloudflare";
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import { Sandbox, Smart, SmartLive } from "./agent.ts";

const HarnessLive = Layer.mergeAll(
  SmartLive,
  Sandbox,
  ClankaCloudflare.DurableObjectStore,
).pipe(Layer.provideMerge(Boat.CreateSandboxHttp));

export default class Coder extends Cloudflare.DurableObject<Coder>()(
  "Coder",
  Effect.gen(function* () {
    const harness = yield* Clanka.Harness({ models: [Smart] });

    return Effect.gen(function* () {
      return {
        prompt: (name: string, text: string) =>
          harness.conversation(name).prompt(text).pipe(Effect.orDie),
      };
    });
  }).pipe(Effect.provide(HarnessLive)),
) {}
```
