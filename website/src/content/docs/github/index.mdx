GitHub hosts your code, and it's part of how your code reaches production. Actions builds, tests and deploys on every push, using credentials kept in its secrets and variables. Environments guard production behind reviews. Webhooks tell other systems when something happens in a repository, and pull requests are where changes, and their previews, are discussed.

## A taste

A repository, with its settings kept in code:

```typescript title="alchemy.run.ts"
const repo = yield* GitHub.Repository("api", { owner: "my-org", name: "api", autoInit: true });
```

Actions variables set from another resource's outputs:

```typescript title="alchemy.run.ts"
yield* GitHub.Variables({
  owner: "my-org",
  repository: "api",
  variables: { AWS_ROLE_ARN: role.roleArn, AWS_REGION: region },
});
```

And one comment per pull request, updated on every deploy with the preview's URL:

```typescript title="alchemy.run.ts"
yield* GitHub.Comment("preview-comment", {
  owner: "my-org",
  repository: "api",
  issueNumber: yield* Config.Number("PULL_REQUEST"),
  body: Output.interpolate`Preview: ${website.url}`,
});
```
