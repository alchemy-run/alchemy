A **stack** is the unit you deploy in Alchemy. It groups
[resources](/infrastructure-as-code/resource), registers the providers
that manage them, and records what it deployed in a
[state store](/state-store).

## Defining a stack

A stack is an Effect that you `export default` from a TypeScript file:

```typescript
import * as Alchemy from "alchemy";
import * as Cloudflare from "alchemy/Cloudflare";
import * as Effect from "effect/Effect";

export default Alchemy.Stack(
  // 1. name: identifies this stack in the state store
  "MyApp",
  // 2. options: `providers` and `state` are required.
  //    `secrets` (optional) chooses where `Config` values come from.
  { providers: Cloudflare.providers(), state: Cloudflare.state() },
  // 3. effect: declares resources and returns the stack's outputs
  Effect.gen(function* () {
    const bucket = yield* Cloudflare.R2.Bucket("Bucket");
    return { bucketName: bucket.bucketName };
  }),
);
```

See [State Store](/state-store) for the available `state` layers and
[Secret Providers](/environments/secret-providers) for `secrets`.

:::note[`alchemy.run.ts` is a convention]
The CLI looks for `alchemy.run.ts` by default. Any TypeScript file
with a default-exported stack works. Pass its path as the first
positional argument or with `--config` (alias `-c`), but not both:

```sh
alchemy deploy infra/my-stack.ts
alchemy deploy --config infra/my-stack.ts
```

See the [CLI reference](/cli/deploy) for the full invocation syntax.
:::

## Multiple providers

Providers are Effect layers. To deploy resources from several clouds
in one stack, merge their layers with `Layer.mergeAll`:

```typescript
import * as Alchemy from "alchemy";
import * as AWS from "alchemy/AWS";
import * as Cloudflare from "alchemy/Cloudflare";
import * as Neon from "alchemy/Neon";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";

export default Alchemy.Stack(
  "MyApp",
  {
    providers: Layer.mergeAll(
      Cloudflare.providers(),
      AWS.providers(),
      Neon.providers(),
    ),
    // one state layer, however many clouds the stack deploys to
    state: Cloudflare.state(),
  },
  Effect.gen(function* () {
    const db = yield* Neon.Project("Db");
    const queue = yield* AWS.SQS.Queue("Jobs");
    const bucket = yield* Cloudflare.R2.Bucket("Uploads");
    return { projectId: db.projectId };
  }),
);
```

Every built-in provider layer and your own
[custom provider](/infrastructure-as-code/custom-provider) layers merge
the same way:

```typescript
providers: Layer.mergeAll(
  Cloudflare.providers(),
  Planetscale.providers(), // built-in, like Docker.providers()
  MyApiProviders,          // your own provider layer
),
```

The type system tracks which providers the stack's resources need.
Declaring an AWS resource without `AWS.providers()` in the merged
layer is a compile-time error.

## Stack outputs

The value the effect returns becomes the **stack output**. The CLI
prints it after every successful deploy, and tests can read it too.

```typescript
Effect.gen(function* () {
  const bucket = yield* Cloudflare.R2.Bucket("Bucket");
  const worker = yield* Worker;

  return {
    bucketName: bucket.bucketName,
    url: worker.url,
  };
});
```

## Stages

Every deploy targets a **stage**, an isolated copy of the stack with
its own state and
[physical names](/infrastructure-as-code/resource#physical-name). See
[Stages](/environments/stages) for defaults and naming, and
[Profiles](/environments/profiles) for per-environment credentials.

## Accessing the stack

Inside a resource or layer, read the current stack's metadata from
the `Stack` service:

```typescript
import * as AWS from "alchemy/AWS";
import * as RemovalPolicy from "alchemy/RemovalPolicy";
import { Stack } from "alchemy/Stack";
import * as Console from "effect/Console";

Effect.gen(function* () {
  const stack = yield* Stack;
  yield* Console.log(stack.name); // "MyApp"
  yield* Console.log(stack.stage); // "live_sam"

  const queue = yield* AWS.SQS.Queue("Jobs").pipe(
    RemovalPolicy.retain(stack.stage === "prod"),
  );
});
```

### `Stack.useSync` for module-scope resources

At module scope, outside any `Effect.gen`, you can't `yield*` the
`Stack` service. A resource's props can be an Effect, and
`Stack.useSync` builds one that computes props from the current stack:

```typescript
import * as Axiom from "alchemy/Axiom";
import { Stack } from "alchemy/Stack";

export const Traces = Axiom.Dataset(
  "Traces",
  // runs once at plan time, after the stage is resolved
  Stack.useSync(({ stage }) => ({
    name: `${stage}-traces`,
    kind: "otel:traces:v1" as const,
    description: `OTEL traces for stage '${stage}'`,
    retentionDays: 30,
  })),
);
```

Use it anywhere a resource accepts a `props` object.
