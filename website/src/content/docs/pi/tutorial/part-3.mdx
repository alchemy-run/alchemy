The bot answers over `curl`. Now GitHub starts it, and the agent replies where the question was asked. Two pieces do that: an event source that calls the Worker when an issue opens, and a tool that comments on the issue.

## Declare a comment tool

A tool is a contract first: what the model sees, what it takes, what it returns.

```typescript title="src/Comment.tool.ts"
import * as AI from "@alchemy.run/ai";
import * as Schema from "effect/Schema";

export class Comment extends AI.Tool<Comment>()("comment", {
  description:
    "Post a comment on the issue you are working on. Call it exactly once, with your full answer in Markdown.",
  parameters: Schema.Struct({ body: Schema.String }),
  success: Schema.Struct({ url: Schema.String }),
}) {}
```

The tool takes no issue number. Each Durable Object is one issue, so the tool will know which.

## Implement it with a GitHub binding

`GitHub.CreateIssueComment` is a binding: it gives the Durable Object a client for one repository, and a token to call it with.

```diff lang="typescript"
import * as AI from "@alchemy.run/ai";
+import * as Cloudflare from "@alchemy.run/cloudflare";
+import * as GitHub from "@alchemy.run/github";
+import * as Effect from "effect/Effect";
+import * as Layer from "effect/Layer";
import * as Schema from "effect/Schema";
+import { Repo } from "./Repo.ts";

export class Comment extends AI.Tool<Comment>()("comment", {
  description:
    "Post a comment on the issue you are working on. Call it exactly once, with your full answer in Markdown.",
  parameters: Schema.Struct({ body: Schema.String }),
  success: Schema.Struct({ url: Schema.String }),
}) {}
+
+export const CommentLive = Comment.make(
+  Effect.gen(function* () {
+    const createComment = yield* GitHub.CreateIssueComment(yield* Repo);
+    const state = yield* Cloudflare.DurableObjectState;
+
+    return Effect.fn(function* ({ body }) {
+      const issue = yield* state.storage.get<number>("issue").pipe(Effect.orDie);
+      const comment = yield* createComment({ issue_number: issue!, body }).pipe(Effect.orDie);
+      return { url: comment.html_url };
+    });
+  }),
+).pipe(Layer.provide(GitHub.CreateIssueCommentHttp));
```

The outer Effect runs where the harness is yielded, so the binding is part of the deploy. The handler it returns runs for each call, and reads the issue's number from the object's own storage.

Comments are posted with a token for the account you signed in to GitHub with, so they appear as yours.

## Consume the repository's events

`GitHub.consumeRepositoryEvents` subscribes the Worker to the repository. At deploy it creates the webhook, pointed at the Worker, with a signing secret. While the Worker runs, it verifies each delivery and calls your handler with a typed event.

```diff lang="typescript"
import * as Cloudflare from "@alchemy.run/cloudflare";
+import * as GitHub from "@alchemy.run/github";
import * as Effect from "effect/Effect";
import { HttpServerRequest } from "effect/http/HttpServerRequest";
import * as HttpServerResponse from "effect/http/HttpServerResponse";
import Issue from "./Issue.ts";
+import { owner, repository } from "./Repo.ts";

export default class Bot extends Cloudflare.Worker<Bot>()(
  "Bot",
  { main: import.meta.url },
  Effect.gen(function* () {
    const issues = yield* Issue;

+    yield* GitHub.consumeRepositoryEvents(
+      { owner, repository, events: ["issues"] },
+      Effect.fn(function* (event) {
+        const { action, issue } = event.payload;
+        if (action === "opened") {
+          yield* issues
+            .getByName(String(issue.number))
+            .opened({ number: issue.number, title: issue.title, body: issue.body ?? "" }, event.id);
+        }
+      }, Effect.orDie),
+    );
+

```

`event.id` is GitHub's id for the delivery. GitHub sends a delivery again when the Worker doesn't answer in time, and as the submission's `requestId` it makes a repeat harmless.

The handler returns as soon as the input is submitted, so GitHub gets its answer in milliseconds. The agent's run continues in the Durable Object.
