The bot answers an issue once. A person who replies should reach the same conversation, with everything the agent already read. And an issue that closes should stop costing anything.

## Add a reply to the conversation

A reply is another input to the issue's conversation. `whenBusy: "steer"` adds it to a run that is still going, so the agent sees it before it answers:

```diff lang="typescript"
  yield* conversation.submit({
    type: "input",
    content: `Issue #${issue.number}: ${issue.title}\n\n${issue.body}`,
    requestId: deliveryId,
  });
}),
+commented: Effect.fn(function* (text: string, deliveryId: string) {
+  yield* harness.submit("issue", {
+    type: "input",
+    content: text,
+    requestId: deliveryId,
+    whenBusy: "steer",
+  });
+}),
```

The conversation still has the issue, the files the agent read and its first answer. The sandbox is the same one too, resumed if Boat had stopped it.

## Consume comments

Subscribe to `issue_comment` as well. `event.name` says which event arrived, and narrows `event.payload` to its type:

```diff lang="typescript"
import Issue from "./Issue.ts";
import { owner, repository } from "./Repo.ts";
+import { MARKER } from "./tools.ts";
```

```diff lang="typescript"
yield* GitHub.consumeRepositoryEvents(
-  { owner, repository, events: ["issues"] },
+  { owner, repository, events: ["issues", "issue_comment"] },
  Effect.fn(function* (event) {
-    const { action, issue } = event.payload;
-    if (action === "opened") {
-      yield* issues
-        .getByName(String(issue.number))
-        .opened({ number: issue.number, title: issue.title, body: issue.body ?? "" }, event.id);
-    }
+    const issue = issues.getByName(String(event.payload.issue.number));
+    if (event.name === "issues") {
+      const { action, issue: opened } = event.payload;
+      if (action === "opened") {
+        yield* issue.opened(
+          { number: opened.number, title: opened.title, body: opened.body ?? "" },
+          event.id,
+        );
+      }
+      return;
+    }
+    const { action, comment } = event.payload;
+    if (action === "created" && !comment.body.includes(MARKER)) {
+      yield* issue.commented(comment.body, event.id);
+    }
  }, Effect.orDie),
);
```

A closed issue's sandbox is no longer needed. Add a method that removes it:

```diff lang="typescript"

+closed: () => harness.removeSandbox("issue"),
```

And call it when the issue closes:

```diff lang="typescript"
  if (action === "opened") {
    yield* issue.opened(
      { number: opened.number, title: opened.title, body: opened.body ?? "" },
      event.id,
```

The conversation stays in the Durable Object. An issue that is reopened and replied to gets a new sandbox from the snapshot, and the agent still remembers the conversation.

## What you built

- A Durable Object for each issue, holding a Pi conversation that survives evictions.
- A sandbox for each issue, started from a snapshot of the repository and removed when the issue closes.
- A tool that comments through a GitHub binding, with the token kept in the Durable Object.
- An event source that turns issues and replies into inputs, each delivered exactly once.
