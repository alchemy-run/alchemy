The agent needs to read the repository to answer a question about it. A Durable Object can't hold a checkout or run `grep`, so each issue gets a sandbox. Every sandbox starts from a snapshot that already has the repository cloned.

## Install

<PackageManagers add="@alchemy.run/boat @alchemy.run/github" />

## Declare the repository

Declare the repository the bot works on. Use your own account as `owner`:

```typescript title="src/Repo.ts"
import * as GitHub from "@alchemy.run/github";

export const owner = "acme";
export const repository = "issue-bot-demo";

export const Repo = GitHub.Repository("Repo", {
  owner,
  name: repository,
  visibility: "public",
  autoInit: true,
});
```

The deploy creates the repository with a README. It is public, so a sandbox can clone it without a token.

## Clone it into a snapshot

An `AI.Sandboxes` Layer says where sandboxes run. Start with its snapshot: a Boat sandbox image with the repository cloned at `~/repo`.

```typescript title="src/Sandbox.ts"
import * as AI from "@alchemy.run/ai";
import * as Boat from "@alchemy.run/boat";
import * as Output from "alchemy/Output";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import { Repo } from "./Repo.ts";

export const Sandbox = Layer.effect(
  AI.Sandboxes,
  Effect.gen(function* () {
    const repo = yield* Repo;
    const checkout = yield* Boat.Snapshot("Checkout", {
      run: [Output.interpolate`git clone ${repo.cloneUrl} ~/repo`],
    });
    const sandboxes = yield* Boat.CreateSandbox(checkout);

    return {
      open: () => Effect.die("not yet"),
      suspend: () => Effect.void,
      remove: () => Effect.void,
    };
  }),
).pipe(Layer.provide(Boat.CreateSandboxHttp));
```

The snapshot is built at deploy, after the repository exists, because its command uses the repository's clone URL. `Boat.CreateSandbox(checkout)` lets the Durable Object create sandboxes from it while it runs.

## Open a sandbox by key

The harness asks for a sandbox by a `key`, one for each conversation. `open` finds the sandbox labelled with that key, or creates it:

```diff lang="typescript"
    const sandboxes = yield* Boat.CreateSandbox(checkout);
+    const find = (key: string) => sandboxes.list({ labels: { key } });

    return {
-      open: () => Effect.die("not yet"),
+      open: Effect.fn(function* (key) {
+        const [existing] = yield* find(key);
+        if (existing === undefined) {
+          return yield* sandboxes.create({
+            type: "small",
+            noEnv: true,
+            autoStop: "10 minutes",
+            labels: { key },
+          });
+        }
+        const sandbox = yield* sandboxes.connect(existing.id);
+        yield* sandbox.resume({ autoStop: "10 minutes" });
+        return sandbox;
+      }),
      suspend: () => Effect.void,
      remove: () => Effect.void,
    };
```

Boat stops a sandbox ten minutes after its last use and keeps its disk. `resume` starts it again when the conversation comes back.

## Suspend and remove

The other two operations stop a sandbox and delete it:

```diff lang="typescript"
        const sandbox = yield* sandboxes.connect(existing.id);
        yield* sandbox.resume({ autoStop: "10 minutes" });
        return sandbox;
      }),
-      suspend: () => Effect.void,
-      remove: () => Effect.void,
+      suspend: Effect.fn(function* (key) {
+        const [existing] = yield* find(key);
+        if (existing === undefined) return;
+        const sandbox = yield* sandboxes.connect(existing.id);
+        yield* sandbox.stop();
+      }),
+      remove: Effect.fn(function* (key) {
+        const found = yield* find(key);
+        yield* Effect.forEach(found, (sandbox) => sandboxes.delete(sandbox.id));
+      }),
    };
```

## Give the harness the coding tools

List the coding tools on the harness, and provide Pi's implementation of them with the sandbox Layer:

```diff lang="typescript"
+import * as AI from "@alchemy.run/ai";
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Pi from "@alchemy.run/pi";
import * as PiCloudflare from "@alchemy.run/pi/Cloudflare";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import { Fast, FastLive } from "./models.ts";
+import { Sandbox } from "./Sandbox.ts";

-const HarnessLive = Layer.mergeAll(FastLive, PiCloudflare.DurableObjectStorage);
+const HarnessLive = Layer.mergeAll(
+  FastLive,
+  PiCloudflare.DurableObjectStorage,
+  Pi.CodingTools.pipe(Layer.provideMerge(Sandbox)),
+);

export default class Issue extends Cloudflare.DurableObject<Issue>()(
  "Issue",
  Effect.gen(function* () {
-    const harness = yield* Pi.Harness({ models: [Fast] });
+    const harness = yield* Pi.Harness({ models: [Fast], tools: [AI.CodingTools] });
```

`AI.CodingTools` names `bash`, `read`, `edit`, `write`, `grep` and `glob`. `Pi.CodingTools` is Pi's implementation of each, and it needs the sandboxes, which `Layer.provideMerge` gives it.

## Let the conversation read, not write

The bot answers questions, so its conversation gets the tools that read. Tell the model where the repository is:

```diff lang="typescript"
-const instructions = "You answer issues on a GitHub repository.";
+const instructions = [
+  "You answer issues on a GitHub repository.",
+  "The repository is cloned at /home/user/repo. Read the files that matter with your tools before you answer.",
+].join("\n");
```

```diff lang="typescript"
        opened: Effect.fn(function* (
          issue: { readonly number: number; readonly title: string; readonly body: string },
          deliveryId: string,
        ) {
-          const conversation = yield* harness.createConversation({ name: "issue", instructions });
+          const conversation = yield* harness.createConversation({
+            name: "issue",
+            tools: [AI.Bash, AI.Read, AI.Grep],
+            instructions,
+          });
```

## Add the providers

The Stack now deploys to Boat and GitHub too, and declares the repository:

```diff lang="typescript"
+import * as Boat from "@alchemy.run/boat";
import * as Cloudflare from "@alchemy.run/cloudflare";
+import * as GitHub from "@alchemy.run/github";
import * as Alchemy from "alchemy";
import * as Effect from "effect/Effect";
+import * as Layer from "effect/Layer";
import Bot from "./src/Bot.ts";
+import { Repo } from "./src/Repo.ts";

export default Alchemy.Stack(
  "IssueBot",
-  { providers: Cloudflare.providers(), state: Cloudflare.state() },
+  {
+    providers: Layer.mergeAll(Cloudflare.providers(), Boat.providers(), GitHub.providers()),
+    state: Cloudflare.state(),
+  },
  Effect.gen(function* () {
+    const repo = yield* Repo;
    const bot = yield* Bot;
-    return { url: bot.url };
+    return { url: bot.url, repository: repo.htmlUrl };
  }),
);
```

## Deploy and try it

<PackageManagers run="alchemy deploy" />

The first deploy builds the snapshot, which takes a couple of minutes. Then ask about a file:

```sh
curl -X POST "$URL/issues/8" -d '{"title":"README","body":"What does README.md say?"}'
curl "$URL/issues/8"
```

The first answer on a new issue waits for its sandbox to start and for Pi's daemon to install there. The transcript then shows a `read` call on `/home/user/repo/README.md`, its result, and an answer taken from the file.
